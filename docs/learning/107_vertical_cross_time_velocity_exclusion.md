# 107. 跨时刻竖直速度投影排除Run169点

## 1. 证明目标与量词

Run171只证明Run169端点满足真实单步气动图。本章改从配置`initial_set`出发，对任意允许的
控制和风历史，证明每一步都满足同一个竖直加速度下界。结论覆盖至多15个Euler步，并要求
轨迹在每一步满足配置硬状态域；这正是安全MPC允许的轨迹类。

## 2. 全域竖直加速度下界

真值模型为

\[
v_z^+=v_z+h\left(T\cos\phi-g
-\frac3{20}r_z\sqrt{r_z^2+\frac1{25}}
+\frac1{50}r_x^2\cos\phi\right).
\]

由`|phi|<=9/20`，余弦交错级数给出

\[
\cos\phi\ge \cos(9/20)
\ge1-\frac{(9/20)^2}{2}+\frac{(9/20)^4}{24}
-\frac{(9/20)^6}{720}>\frac9{10}.
\]

状态域和风域给出`r_z=v_z-w_z<=3-(-1/2)=7/2`。负气动项在正`r_z`端最坏，且

\[
\sqrt{(7/2)^2+1/25}<351/100.
\]

最后一项非负，故对所有域内状态、输入和风，

\[
a_z\ge\frac{981}{200}\frac9{10}-\frac{981}{100}
-\frac3{20}\frac72\frac{351}{100}
=-\frac{28953}{4000}.
\]

## 3. 15步归纳与严格分离

初始`v_z>=-1/10`，`h=1/50`。逐步应用上界无关的同一加速度下界，15步后

\[
v_{z,15}\ge-\frac1{10}+15\frac1{50}\left(-\frac{28953}{4000}\right)
=-\frac{90859}{40000}=-2.271475.
\]

Run169端点为

\[
-\frac{170955031}{72000000}\approx-2.37437543,
\]

严格小于该下界。因此它不在从配置初始集出发、保持硬状态域的15步可达投影内。这个结论
比单步共享图检查更强，也说明早期独立残差外包在该方向引入了不可实现的跨时刻组合。

## 4. 仍未闭合的义务

本证书只排除一个竖直速度端点，并未计算完整六维可达集。其他可达的`(v_x,v_z,phi)`组合
仍可能使气动核心超过Run168门槛。下一步应在上述跨时刻速度界上联合传播横向速度和姿态，
直接求15步可达域上的气动支持；在此之前不能恢复“局部气动路线可行”的结论。
