# 106. 单步共享气动因子图不能排除Run169点

## 1. 问题边界

Run170指出Run169没有证明极端状态由真实非线性历史可达。自然的第一修复是把状态、风和气动
残差放入同一个factorable graph，避免把残差当作独立primitive。本章检查这种**单步**修复是否
已经足以排除Run169点。

答案是否定的。原因不是外包松弛，而是该点本身精确满足真实气动图。任何可靠的图外包都必须
包含真实图，因此不能删除它。

## 2. 精确共享因子

取Run169中的物理速度和风

\[
v_x=3,\quad v_z=-\frac{170955031}{72000000},\qquad
w_x=-\frac12,\quad w_z=\frac12,
\]

以及`phi=0`、`T=981/100`。所有量均在配置域内，共享相对速度因子满足

\[
r_x=v_x-w_x=\frac72,\qquad
r_z=v_z-w_z=-\frac{206955031}{72000000}.
\]

令`q_i=r_i^2+1/25`、`s_i=sqrt(q_i)`。检查器以纯有理数验证

\[
|r_i|^2<q_i<\left(|r_i|+\frac1{100}\right)^2,
\]

故`|r_i|<s_i<|r_i|+1/100`。在`phi=0`且`r_z<0`时，真实竖直气动图为

\[
a_z=-\frac3{20}r_zs_z+\frac1{50}r_x^2.
\]

其严格有理下界仍为

\[
a_z>\frac{51297584856210961}{34560000000000000}
\approx1.48430512>D_\star.
\]

## 3. 逻辑结论

设`Graph(f)`为真实单步计算图，`P`为任意可靠的CZ、SPZ、Taylor model或polyhedral outer
approximation。可靠性要求`Graph(f) subseteq P`。既然Run169点属于`Graph(f)`，它必属于`P`。

- 独立残差盒确实过宽，但把残差改为单步共享因子并不会排除该点；
- Run170提出的单步factorable CZ可行性查询在这个点上必然返回可行；
- 真正未决的是该输入状态能否从初始集经允许控制、风、测量和缺测历史到达；
- 下一证书必须从初始集跨时刻传播联合非线性状态，而不是只在J14末端补一层图约束。

这是精确单点图一致性结论，不是非线性历史可达性、15步tube或递归可行性证明。
