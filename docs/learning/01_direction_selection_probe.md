## 1 先验收什么

需要依次区分三个问题：有效方向能否去掉外包冗余；非学习规则是否已经实现目标上的最优收紧；只有存在剩余选择难题时，才研究学习收益。

本轮完成前两个问题的解析与有限实例核查。结论是：**方向选择确实影响冗余，但单目标、准确支持查询情形下，约束法向基线已最优。不能据此训练网络并宣称学习优势。**

## 2 单目标最优基线：必须先排除的简单情形

令 X 为共同信息下的非空紧相容集合，B 为其紧外包，X⊆B。固定一个已知非零目标方向 c。任何可靠改进 R 均须满足 X⊆R⊆B，因此：

```math
h_R(c)\geq h_X(c).
```

若一次查询可以准确得到 h_X(c)，直接添加目标法向的约束：

```math
R_c=B\cap\{x:c^\top x\leq h_X(c)\}
```

便得到 h_Rc(c)=h_X(c)。上界由新约束给出，下界由包含 X 给出。所以这个非学习规则用一次查询便达到目标支持值的信息下界，任何可靠学习方法在该指标上都不可能严格更好。

边界：这不是对所有算法和所有计算任务的不可能性定理。它假设目标固定已知，准确支持查询可用且纳入比较预算，新增约束被保留；如果只有保守上界、查询成本差异很大、目标多且预算不足或后续约简损失关联，仍需另行分析。

扩展：若目标方向固定为 c₁,...,cₘ，预算允许准确查询全部 m 个，保留这 m 条约束便同时达到各目标支持下界。这不意味着得到整个 X，也不意味着控制最优值已经相同。

## 3 八个精确几何实例

采用无量纲二维例子，明确不冒充冻结四旋翼模型的实际后验：

```math
B=[-1,1]^2,\quad c=(1,\sigma),\quad
X=B\cap\{|x_1+\sigma x_2|\leq s\},
\quad \sigma\in\{-1,1\},\ s\in\{1/4,1/2,3/4,1\}.
```

所有方法均知道同一 B、X 的描述和目标 c。每种方法仅允许一次支持查询；查询后只将被选择的单条支持约束加入 B。该限制用于隔离方向选择，不表示处理此简单条带的最佳算法：直接保留原条带的非学习实现更简单，必须承认这一点。

| 一次查询的方向 | 目标支持值（加入约束后） | 是否改善 |
|---|---:|---|
| x₁ 坐标轴 | 2 | 否 |
| x₂ 坐标轴 | 2 | 否 |
| 另一条对角线 (1,−σ) | 2 | 否 |
| 目标法向 c | s | 是，且达到最优下界 |

例如 s=1/2，目标支持从 2 降至 1/2，而两条坐标轴各自的支持仍为 1。说明逐坐标盒化会丢失控制相关关联，也说明只与坐标轴比较会把一个普通几何改进误判为学习贡献。

这个几何收益也能映射到一个明确的一步鲁棒约束例子：令共同标量动作 u∈[−1,1]，要求对全部相容 x 满足 u+cᵀx≤1。用 B 计算时只能接受 u=−1；加入准确目标约束后可接受 u∈[−1,1−s]，严格扩大共同动作区间。该例没有无人机动力学、终端或时序，不能据此声称实际 MPC 递归可行改善；它只说明所选指标有一个准确的约束解释，而该收益仍由非学习法向规则全部获得。

精确核对采用 Fraction，枚举二维有界多面体的交点顶点计算线性目标；没有浮点最优值判断。脚本还核对 X 的所有顶点保留在新集合内。

另设无收益负对照：如果验证器仅计算 h_B(a)，添加 aᵀx≤h_B(a) 对 B 恒为冗余。网络方向再好，也不能从相同外包中凭空获得已丢失的信息。

## 4 值得继续验证的唯一剩余机制

将下一步限定为：**同一一致性问题中，控制相关目标多于在线可验证数量时，是否存在无法由简单规则消除的验证预算分配差距？**

先使用控制基础给出的固定候选法向，不同时让网络生成任意连续方向。设候选库 A={a₁,...,aₘ}，预算 q<m。选择后仍由同一个可靠验证器签发支持上界，保留原物理基线。这样可以区分“搜索值得花时间的任务”和“正确计算边界”。

在训练前必须完成：

1. 从明确的估计/控制接口导出候选法向及其控制含义，不能人为增加大量无关方向制造优势。
2. 实测或分析验证成本，证实 q<m 是实际预算瓶颈；便宜地查询全部方向时，优先采用非学习全查询。
3. 给出强非学习规则仍有非零差距的非空实例，并识别差距来自信息结构、成本还是表示，而不是弱基线设置。
4. 验证同一允许输入特征能辨别有用方向。若两个问题给网络完全相同的特征却需要不同选择，不能要求确定性选择都正确。

如果这些条件不存在，结束“学习选方向”这条分支。可保留控制相关约束作为非学习估计改进，不换名称继续训练。

## 5 学习选择的条件命题，不是已经获得的优势

以单次选择为最小模型，冻结任务 I、验证器、每个候选预算和表示操作。令 g_j(I) 是选择任务 j 后、经验证输出在固定指标上的实际收益。评分网络只能依据获准特征预测 g_j，不能在推理时先计算全部真实收益当作免费输入。

若在声明任务域上有独立可核查的一致误差界：

```math
|\hat g_j(I)-g_j(I)|\leq\epsilon,\quad\forall j,I,
```

取 $`\hat j\in\arg\max_j\hat g_j(I)`$，则：

```math
g_{\hat j}(I)\geq\max_jg_j(I)-2\epsilon.
```

证明：真最优 j* 的真实收益至多比其预测高 ε；预测选择的分数不低于 j*；所选真实收益至多比所选预测低 ε，串联即得。

对固定非学习规则 j_b，只有在某个已证非空实例类中同时有：

```math
\max_jg_j(I)-g_{j_b}(I)>2\epsilon
```

才可推出该类上学习选择严格更好。此结论还要求相同总预算下两者确实能完成各自提议与验证；若网络占用额外时间，应在 g 与预算中计入。有限训练误差和平均测试误差不是上式的全域 ε 证书。

本轮未建立 ε 证书，也未发现真实物理任务上的严格差距。q>1 时多个约束存在相互作用，收益一般不能直接相加；没有证明次模性前，不套用贪心近似比例。

## 6 后续验收协议（不启动训练）

| 检查 | 基线/工具 | 通过标准 |
|---|---|---|
| 目标法向是否已足够 | 直接法向查询、已有关系直接保留 | 存在实质预算瓶颈，而非单目标已最优 |
| 选择是否有剩余收益 | 固定次序、当前最小余量、基于敏感度与估计成本的规则、离线全查询参照 | 相同信息下强规则仍有准确可核查差距 |
| 成本是否公平 | 记录提议、验证、集合维护；离线标签和预计算另列 | 学习推理不被当作免费，参照真值不上线 |
| 后续训练是否值得 | 先冻结特征和任务族；按轨迹/物理条件划分数据 | 不用同轨迹相邻样本随机拆分制造泛化 |
| 与 MPC 是否有关 | 固定模型和终端合同下的约束支持/可行性指标 | 不只展示面积缩小，更不宣称每条轨迹变好 |
