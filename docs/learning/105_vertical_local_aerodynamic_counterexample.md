# 105. J14 抽象残差外包中的局部气动反例（Run170纠错）

## 1. 为什么无需继续传播15步

Run168要求完整未来tube的竖直余项半宽不超过

\[
D_\star=\frac{89401829}{65520000}\approx1.36449678.
\]

Hu等的RFIT条件量化tube中每个状态和扰动。Run169原稿把cycle-lifted外包中的成员称为
“可达状态”，这一步过强：该外包把每条边的横、竖残差作为独立primitive传播，却没有保留
真实非线性plant中状态、风、气动残差及跨时刻演化的联合图。因此下述结果只否定当前抽象
独立残差外包达到该门槛，不能直接否定真实benchmark的局部tube路线。

## 2. 保留相关性的J14速度端点

从既有exact cycle-lifted zonotope恢复J14强制success后的tracking-error速度行，得到

\[
h(e_{v_x})=\frac{113619923}{40000000}\approx2.84049808,
\quad
h(e_{v_z})=\frac{152955031}{72000000}\approx2.12437543.
\]

横、竖速度行的非零源生成元列互不相交，两个抽象余项primitive也独立。因此可用同一个生成元
向量同时达到`+e_vx`与`-e_vz`：它是当前线性外包内的一致成员，不是非线性plant轨迹证书。

取合法nominal velocity

\[
z_v=\left(\frac{6380077}{40000000},-\frac14\right),
\]

则实际速度为

\[
v=\left(3,-\frac{170955031}{72000000}\right),
\]

仍在物理状态域内。再取允许风`b=(-1/2,1/2)`与`phi=0`，相对速度为

\[
r_x=\frac72,\qquad r_z=-\frac{206955031}{72000000}.
\]

## 3. 无浮点、无平方根的严格反例

在`r_z<0, phi=0`时，真实竖直气动项为

\[
a_z=0.15|r_z|\sqrt{r_z^2+0.04}+0.02r_x^2.
\]

由`\sqrt{r_z^2+0.04}>|r_z|`，严格有

\[
a_z>\frac3{20}r_z^2+\frac1{50}r_x^2
=\frac{51297584856210961}{34560000000000000}
\approx1.48430512.
\]

它超过`D_star`至少

\[
\frac{376792429915197451}{3144960000000000000}
\approx0.11980834.
\]

由于`phi=0`，推力余弦线性化误差恰为零；超限完全来自真实气动核心，不能靠姿态项重分配消除。

## 4. 证据等级与方向纠正

- **精确反例**：当前独立残差外包的J14成员、配置域与该点余项下界均用有理数核查。
- **未完成义务**：未给出从配置初始集出发、满足真实plant与因果输入时序的轨迹历史。
- **否定范围**：当前独立逐边残差盒外包不能达到Run166门槛。
- **不否定**：保留状态--风--残差和跨时刻依赖的联合物理可达外包可能排除该组合。
- **不声称**：一般RFIT不存在、递归可行性证明或六自由度四旋翼保证。

measurement-only与姿态项-only结论不变；Run169对local-aerodynamic路线的终止结论撤回。
