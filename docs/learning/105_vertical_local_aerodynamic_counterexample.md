# 105. J14 首个未来边的局部气动反例

## 1. 为什么无需继续传播15步

Run168要求完整未来tube的竖直余项半宽不超过

\[
D_\star=\frac{89401829}{65520000}\approx1.36449678.
\]

Hu等的RFIT条件量化tube中每个状态和扰动。因此，只要要求覆盖的J14 return族中有一个合法状态
在首个预测边违反该界，任何覆盖完整初始化族的15-tick局部tube都不能满足此必要门槛。

## 2. 保留相关性的J14速度端点

从既有exact cycle-lifted zonotope恢复J14强制success后的tracking-error速度行，得到

\[
h(e_{v_x})=\frac{113619923}{40000000}\approx2.84049808,
\quad
h(e_{v_z})=\frac{152955031}{72000000}\approx2.12437543.
\]

横、竖速度行的非零源生成元列互不相交，两个物理余项primitive也独立。因此可用同一个生成元
向量同时达到`+e_vx`与`-e_vz`，这不是把不相容的坐标盒端点拼在一起。

取合法nominal velocity

\[
z_v=\left(\frac{6380077}{40000000},-\frac14\right),
\]

则实际速度为

\[
v=\left(3,-\frac{170955031}{72000000}\right),
\]

仍在物理状态域内。再取允许风`b=(-1/2,1/2)`与`phi=0`，相对速度为

\[
r_x=\frac72,\qquad r_z=-\frac{206955031}{72000000}.
\]

## 3. 无浮点、无平方根的严格反例

在`r_z<0, phi=0`时，真实竖直气动项为

\[
a_z=0.15|r_z|\sqrt{r_z^2+0.04}+0.02r_x^2.
\]

由`\sqrt{r_z^2+0.04}>|r_z|`，严格有

\[
a_z>rac3{20}r_z^2+\frac1{50}r_x^2
=\frac{51297584856210961}{34560000000000000}
\approx1.48430512.
\]

它超过`D_star`至少

\[
\frac{376792429915197451}{3144960000000000000}
\approx0.11980834.
\]

由于`phi=0`，推力余弦线性化误差恰为零；超限完全来自真实气动核心，不能靠姿态项重分配消除。

## 4. 证据等级与方向纠正

- **精确反例**：J14生成元相关性、配置域与余项下界均用有理数核查。
- **否定范围**：当前J14 return seed、风箱、解析气动模型与Run166门槛的局部余项路线。
- **不否定**：更小且可可靠初始化的seed、新的物理风合同、更大输入权限或其他模型。
- **不声称**：一般RFIT不存在、递归可行性证明或六自由度四旋翼保证。

冻结合同主线至此已排除measurement-only、姿态项-only及local-aerodynamic-bound三条单项救援。
继续研究必须改变至少一个可靠物理/初始化合同，并重新完成同条件比较，不能继续局部调界。
