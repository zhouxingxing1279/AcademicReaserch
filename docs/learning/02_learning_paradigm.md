# 学习方法选型：监督学习、上下文老虎机与强化学习

**主方案已确定（2026-09-15）：[强化学习调度集合验证的输出反馈 MPC](03_selected_plan.md)。学习位置固定为离散验证任务调度，首版不学习动力学；小型精确序列验证后采用 Double DQN。下一步只交付控制接口与有限调度环境规范；历史候选比较及下一步指令以主方案为准，尚未证明学习优势或完整安全。**

日期：2026-09-15。根据用户“强化学习也可以考虑，不是一定要深度学习”的补充，方法不限定为神经网络。强化学习是决策学习范式，深度学习是函数表示/训练技术，二者可以结合，也可以使用表格、线性函数或树模型等非深度表示。

本文件是方法选择合同，不启动训练，不改变独立验证器和控制基础的证明义务。

## 1 按任务结构选择方法

| 可验证的任务特征 | 优先比较的方法 |
|---|---|
| 单个已知方向，准确查询可用 | 直接法向规则；01 已证明该指标无需学习 |
| 每个任务只选一次，有完整离线候选收益标签 | 简单评分回归/排序与监督学习 |
| 每个任务只选一次，主要获得被选动作反馈 | 上下文老虎机；仍须比较非学习规则与监督基线 |
| 同一任务内多次查询，结果改变后续选择或验证成本 | 序列规划/强化学习，与贪心、有限前瞻、动态规划比较 |

不能仅因 q>1 就断言需要强化学习。若每次查询收益固定、可加且已知，排序即可；若成本或收益具有组合结构，组合优化也可能足够。需要展示结果条件化或长程收益差距，再决定是否采用 RL。

## 2 首个 RL 候选只作用于计算调度

时间索引 t 表示一个控制周期内的验证决策，不是直接控制无人机的采样时刻。一次 episode 是固定相容问题与总预算下的一串验证动作：

- 可见信息：当前保留集合、已接受约束、各控制目标余量、已查询结果、验证器可见状态、剩余预算。
- 动作：选择下一个候选方向/合法细分任务，或停止；不能选择未经证明删除状态。
- 转移：运行相同独立验证器，记录结果、集合变化和实际耗时；未获可靠证书时不加入约束。
- 输出：已验证集合及日志，供原 MPC 接口使用；策略不直接输出推力或扭矩。

集合特征向量不自动是 Markov 状态。如果隐藏的原始约束、验证器缓存或查询历史影响后继，需要保留足够状态，或明确为部分可观测问题；不能靠将特征叫作 state 就获得 MDP 假设。

初步奖励候选为固定控制相关指标的改进减去计算成本。指标、法向归一化和成本权重必须在训练前确定。不得免费调用全部方向的准确支持或求解真实最优 MPC 代价来产生在线奖励；昂贵离线标签仅用于训练/评价，并单列成本。集合面积缩小不能直接当作控制性能改善。

## 3 可靠性与性能分开

独立验证器及表示操作正确时，任意合法查询策略——包括未训练策略——只能加入有效约束，因此可继承集合真值包含。超时只能返回已验证结果；不能把尚未验证的估计当作边界。

这不自动保证整个闭环安全：基线 MPC 必须覆盖返回集合、计算时限、实际更新与终端机制。奖励中惩罚违约不能代替上述证明。RL 的期望回报增加也不能改写为每个任务确定性更优。

01 的单目标最优法向结论对 RL 同样适用：换一种训练方法不会消除该信息下界。

## 4 下一步唯一新增验收问题

在原多目标预算瓶颈验证中加入“序列价值”检查：是否存在同信息、同预算的实际候选库，使自适应多步选择比固定顺序、当前余量贪心及有限前瞻有可核查的收益差距？

先对小型可枚举任务用全查询离线数据构造决策树/动态规划参照，检查哪些信息在每一步才可获得。若差距依赖免费真值标签或人为隐藏本来便宜可见的信息，任务不合格。若没有序列价值，则选择更简单的排序/老虎机方法或停止学习分支。

存在差距后再决定有限状态表格法、线性/树模型、或深度 RL；暂不指定 PPO、DQN 或网络结构。控制基础 F1 与集合/MPC 接口仍未完成，不扩展新的控制设计任务。

## 5 文献定位

[RL 分支变量选择](https://arxiv.org/abs/2005.10026) 和 [TreeDQN](https://arxiv.org/abs/2306.05905) 是学习计算策略的相关例子。本轮只核查作者摘要页，TreeDQN 当前为 2026-05-20 修订版。其结果针对各自优化问题，不直接提供本项目的收益、安全或 Markov 性证明。基础方法已有研究，创新必须来自当前估计/控制接口的实际问题与可复核贡献。
