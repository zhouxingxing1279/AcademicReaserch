# C2-R：模式条件半径核查与方向集合对照

日期：2026-09-16。承接 [06 C2](06_mode_dependent_nestedness.md)。

**结论：不经 Young 分离的模式条件半径具有可靠性与移位嵌套性，但仍不能用于当前完整椭球收紧。保留生成元相关性的同合同集合传播，在原初始误差盒、两种初始观测模式和全部允许测量路径下，25步内通过了状态坐标宽度必要条件。这个对照定位了表示压缩的损失，未证明控制可行、无限时域安全或学习优势。**

本轮是对已确定 C2-R 任务的通过/否定核查。噪声、输入、物理域、采样与预测时域均不修改，不搜索新控制增益，不训练 RL。

## 1. 为什么继续检查半径，而不直接恢复控制实现

06 的统一递推为 $e^+=0.99e+c_\Box$，$c_\Box=3.2980673638\ldots$。其全局噪声最大值和 Young 放大使零种子预测的第3步已经超过速度椭球可容纳的平方半径9。

本轮按原任务改为保留每条模式边的噪声能量，并使用范数三角不等式。随后以保留生成元的误差集合为诊断对照，区分以下层次：

- 椭球证书不满足约束宽度条件；
- 给定线性外包的误差集合是否仍存在相同宽度阻断；
- 控制器是否能在原域内递归可行。

只有第一、第二层在本轮计算，不能跨越到第三层。

## 2. 模式条件半径递推

沿用06的15模式、17条边、六维 $P_j,A_\gamma,\bar G_\gamma$，定义

```math
q_{ab}=\max_{\|\xi\|_\infty\le1}
\xi^\top\bar G_\gamma^\top P_b\bar G_\gamma\xi,
\qquad c=\sqrt{19/20}.
```

$q_{ab}$ 从同一解析物理外包计算，并逐边枚举盒顶点取得精确有理数最大值。模式边与误差齐次收缩关系不改变。由加权范数三角不等式，

```math
\|z^+\|_{P_b}\le\|A_\gamma z\|_{P_b}
+\|\bar G_\gamma\xi\|_{P_b}
\le c\|z\|_{P_a}+\sqrt{q_{ab}}.
```

令 $r_t$ 为当前可靠半径，在当前模式 $j_t$ 初始化 $R_{0|t}(j_t)=r_t$，其他模式标记为不可达。递推为

```math
R_{i+1|t}(b)=
\max_{a\in S_i(j_t):a\to b}
\left[cR_{i|t}(a)+\sqrt{q_{ab}}\right].
```

空前驱不产生一个半径为0的模式，而是保持不可达。否则会凭空引入不存在的路径。合并的是同终点模式路径的最大半径，不取平均值、最小值或“最可能路径”。

相应未来集合为

```math
\mathcal U^r_{i|t}=
\bigcup_{b\in S_i(j_t)}\mathcal E_b(R_{i|t}(b)^2).
```

它共享原 C2 的 observer 度量和物理信息，只减少传播中的外包损失。

### 2.1 对旧统一递推的非劣性

对任意 $r\ge0$，Young 不等式给出

```math
(cr+\sqrt{q_{ab}})^2
\le0.99r^2+(99/4)q_{ab}
\le0.99r^2+c_\Box.
```

从同一个初始半径出发，逐步归纳得 $R_{i|t}(b)^2\le F^i(r_t^2)$，从而本轮包络包含于06的可达模式统一标量包络。它保证不更松，不保证严格改善每个方向，更不保证实际闭环性能改善。

### 2.2 在线截断和移位证明

实际边为 $a_*=j_t\to b_*=j_{t+1}$ 时，新的有效半径采用

```math
r_{t+1}=\min\{r_{t+1}^{\rm cert},R_{1|t}(b_*)\}.
```

半径证书须针对更新后的实际估计中心和实际模式；无新证书时使用已预测半径。不同周期方向支持仍需重新计算或严格转换。

因为每个边映射对输入半径单调，从实际后继模式出发的新路径都能在前面补上 $a_*\to b_*$，对任意新可达终点 $b$，归纳得到

```math
R_{i|t+1}(b)\le R_{i+1|t}(b),\qquad
\mathcal U^r_{i|t+1}\subseteq\mathcal U^r_{i+1|t}.
```

比较是在同一终点矩阵 $P_b$ 中完成的，未比较不同模式的椭球大小。此证明仍只解决估计集合移位；控制中心 tube、实际执行输入、终端等义务保持独立。

## 3. 有理数区间核查：避免把浮点数当证明

除显示小数外，脚本不使用浮点数决定通过与否。对 $x\in\mathbb Q_{\ge0}$、$D=10^{12}$，计算

```math
m=\operatorname{isqrt}\!\left(\left\lfloor xD^2\right\rfloor\right),
\qquad \sqrt{x}\in[m/D,(m+1)/D].
```

若下端平方恰好为x，上下端相同。每次半径更新继续朝外舍入到 $D^{-1}$ 网格。最大值的下界取各下界之最大，上界取各上界之最大。

判定规则：支持下端超过约束半宽才证明阻断；所有此前步的支持上端不超过半宽，才称该步为“首次阻断”。若阈值落在区间内部，核查失败并要求加精度，不静默作出结论。

用于在线证书时固定采用上端更新 $\bar T_{ab}(r)=\lceil\bar c r+\bar d_{ab}\rceil_D$。同一单调舍入映射用于旧预测和新预测，故第2.2节的移位归纳仍成立。不能分别用不一致的舍入规则或误差容差比较。

## 4. 半径方案仍被否定

本轮分别核查两类种子。

**零半径：**它是用于否定方案的最有利种子，不是原初始不确定性。若它仍阻断，则该相同模式递推下所有更大半径也无法通过。

**原初始误差盒：**两种初始化均可由

```math
\mathcal B_0=[-b_0,b_0],\qquad
b_0=(0.02,0.02,0.1,0.1,0.005,0.01)
```

可靠覆盖。位置零时刻成功对应模式0，失败对应模式5；模式5不假定存在一次虚构的历史成功测量。角误差为当前直接测量噪声。与生成元对照公平比较时，半径初值必须覆盖同一个盒，其准确最大平方半径为

```math
r_0(j)^2=\eta_0^j
\left[180(0.02+jh\,0.1)^2+0.02\right]+0.005^2+0.01^2.
```

每个平移轴取位置与速度相反符号可达到其盒上最大值，两个轴及角噪声可同时选取，因此该盒的初始能量公式是精确最大值。

对未求交的完整椭球，水平/竖直速度支持为 $R_i(j)\eta_0^{-j/2}$，角度支持为 $R_i(j)$。原速度半宽为3 m/s，角度半宽为0.45 rad。

| 初始模式 | 种子 | 首次速度宽度阻断 | 该步支持下界 | 首次角度宽度阻断 | 该步支持下界 |
|---:|---|---:|---:|---:|---:|
| 0 | 零半径 | 17 | 3.096678873495 m/s | 4 | 0.462358899841 rad |
| 5 | 零半径 | 17 | 3.269156765865 m/s | 3 | 0.469440938696 rad |
| 0 | 原初始误差盒 | 14 | 3.222839259434 m/s | 2 | 0.513657952071 rad |
| 5 | 原初始误差盒 | 15 | 3.042768024441 m/s | 1 | 0.515530664108 rad |

每一项是所有允许路径中至少一个终点椭球的宽度阻断。实际误差没有被证明会达到这些椭球边界。未来全部模式鲁棒收紧必须容纳这个椭球，所以即便可自由移动中心，也不能把它放入更窄的坐标区间；添加控制 tube 不能补回这个宽度。

去掉 Young 放大解决了部分损失，但**把六维不确定性压成一个共同能量半径仍会把平移误差分配给角度方向**。实际角度每tick直接测量的 $0.005$ rad 界并未消失；完整椭球却忘掉了它。与直接测量条带求交可消除这一个角度问题，但不自动消除速度问题或完成控制闭合。

## 5. 保留生成元的同合同对照

为了判断前述失败是否来自线性外包本身，使用同一06的 $A_\gamma,\bar G_\gamma$，不改增益或扰动界，保留每条允许路径。初始

```math
Z_0=\operatorname{diag}(b_0),\qquad
\mathcal Z_0=\{Z_0\theta:\|\theta\|_\infty\le1\}.
```

对路径上的边 $a\to b$，递推

```math
Z^+=[A_\gamma Z,\bar G_\gamma],\qquad
\mathcal Z^+=A_\gamma\mathcal Z\oplus\bar G_\gamma[-1,1]^7.
```

同一测量噪声对位置和速度的作用保留在同一个生成元列中，不能在传播前拆成两个独立坐标宽度。对每条路径、任意方向c，支持为 $\|Z^\top c\|_1$；模式/路径并集的支持取所有路径的最大值。

这里“精确”指**声明的线性集合值外包**：该外包允许每步盒因子自由选取，放松了物理系统中当前角噪声与当前角误差等确定性相关关系。不作统计独立假设，不把其顶点当作真实气动系统可实现轨迹。物理真值包含仍以源状态域与实际输入域有效为条件。

### 5.1 与同种子椭球的集合关系

初始 $\mathcal Z_0\subseteq\mathcal E_j(r_0(j)^2)$。若某路径当前生成元集包含于对应椭球，第2节的范数界覆盖其全部后继，所以该路径后继仍包含于对应更新椭球。对路径归纳、再取并集，得到

```math
\bigcup_{\text{允许路径}}\mathcal Z_{i,\text{path}}
\subseteq\mathcal U^r_{i|0}.
```

该关系比较的是“原初始盒”这一相同种子。不能把非零盒产生的集合与第4节零半径种子的椭球比较包含性。

### 5.2 25步内的精确坐标支持

枚举两种原初始模式，各自覆盖0到25步的全部允许测量路径。到第25步，模式0有24条路径，模式5有20条路径；并非只检查固定周期缺测序列。

下表为两种模式及整个0–25步中，各坐标支持的最大值（各行的最大值可以在不同路径和时刻达到）。

| 误差坐标 | 生成元并集的最大半宽 | 原状态区间半宽 | 留给中心及其他 tube 的半宽差 |
|---|---:|---:|---:|
| $p_x$ | 0.388184884375 m | 5 m | 4.611815115625 m |
| $p_z$ | 0.336291439275 m | 1.5 m | 1.163708560725 m |
| $v_x$ | 1.968913625 m/s | 3 m/s | 1.031086375 m/s |
| $v_z$ | 1.665996345625 m/s | 3 m/s | 1.334003654375 m/s |
| $\phi$ | 0.005 rad | 0.45 rad | 0.445 rad |
| $\omega$ | 0.01 rad/s | 2 rad/s | 1.99 rad/s |

所有显示小数在此表均为精确有限小数，完整分数与达到峰值的模式路径保存在结果文件。对生成元计算选出的312个坐标最大值见证，脚本逐一用后向方向传播复核其支持值；此项复核没有独立重做所有路径的最大值枚举。

该表说明对这些坐标，误差集合自身没有把原状态区间侵蚀为空。在纯几何层面，存在可容纳它的中心位置。它**没有证明**实际估计中心/nominal轨迹可以到达这些中心、控制tube能被上述差额容纳、输入约束满足或状态始终不出域；也没有证明任意未来滚动窗口都具有这些数值界。

与第4节相同初始盒的椭球相比，这给出同一外包下的严格方向改进见证：原角度误差支持维持0.005，而完整椭球在模式0第2步至少0.513657952071。该改善来自几何表示，不是RL独立贡献，必须给所有非学习基线同样使用。

## 6. 对架构的影响与下一步

研究主线仍是“可靠SMF → 独立方向验证 → MPC；学习只调度验证预算”。但本轮证据不支持把单一二次标量作为唯一几何收紧接口。$e$ 可以继续作为辅助鲁棒界；不能只根据它下降就宣称实际约束收紧已经改善。

后续将优先保留经证明的方向几何，且只推进一个任务：**C2-G：有限复杂度的几何预测/更新合同。**

必须同时给出：

1. 实际在线后验误差集包含真值，且与上一时刻针对实际模式边的预测保持包含；估计中心改变时显式转换坐标。
2. 模式条件集合预测、路径合并和约简的规则，证明移位后不比旧预测更松。有限时域全路径生成元枚举只作为离线对照，不默认其20 ms实时可用。
3. 一组控制器实际读取的可靠支持/注入界，以及调度奖励。当前标量奖励若与最终支持收紧失配，应据真实接口修改；旧小实例不能直接算作新接口下的学习优势。
4. 若采用 $\Psi_{ab}(E)=A_\gamma E\oplus W_{ab}$，利用其单调性设计更新；但不能仅靠这一算子定义就声称测量修正、表示约简和实际中心转换已满足合同。

只有 C2-G 接口可用后，再进入控制侧增量反馈、终端与初始可行性 C3。现在仍不训练 Double DQN、不继续为已否定的完整椭球组合搜索终端证书。
