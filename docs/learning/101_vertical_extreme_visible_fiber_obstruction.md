# 101. 极端可见fiber的15-tick绝对中心反例

## 1. Run164没有解决什么

Run164证明每个固定观测fiber在方向 `a=e_p+14h e_v` 上的最坏半直径不超过
`16315003/75000000≈0.21753337`。这只消除了宽度阻塞；硬约束要求绝对support不超过1，仍须检查
fiber中心能否由有限输入平移回来。

## 2. 一个可达极端观测

令 `D xi=d_p=e_p-eta_p`。取所有 `D_i!=0` 的生成元原语为 `sign(D_i)`，得到可达观测

```math
d_p^{\max}=\sum_i|D_i|=\frac{24272147}{48000000}.
```

达到线性函数在盒上的最大值迫使所有非零 `D_i` 原语固定在该符号；只有 `D_i=0` 的原语仍可变。
因此极端fiber在14步端点方向的精确区间为

```math
e_p+14he_v\in
\left[
\frac{3745601423}{3600000000},
\frac{3889781459}{3600000000}
\right]. \tag{101.1}
```

值得注意的是整个区间的下端也严格大于1。这里没有把不同观测重新合并；式(101.1)只描述同一个
实际可见的极端fiber。

## 3. 任意有界因果策略仍失败

沿14次miss路径，选择每拍允许的正端 residual。其对最终位置的总平移为

```math
D_{14}=\frac{14\cdot13}{2}h g_r
=\frac{52065013}{400000000}.
```

进一步把控制器放宽为知道完整真实状态和过去扰动的任意因果策略。由于每拍
`delta T_j>=-U`，它对最终位置能产生的最负平移不小于

```math
-C_{14}=-\frac{14\cdot13}{2}h^2U
=-\frac{52065013}{400000000},
```

其中当前合同恰有 `g_r=hU`。因此环境取初始fiber的上端点和全部正端residual时，任何策略都满足

```math
e_{p,14}\ge
\frac{3889781459}{3600000000}+D_{14}-C_{14}
=\frac{3889781459}{3600000000}
=1+\frac{289781459}{3600000000}>1. \tag{101.2}
```

这与Run164不矛盾：失败来自可见fiber的绝对中心偏移，而不是同fiber隐藏宽度。控制器虽然知道
`d_p=d_p^max`，但当前执行器权限不足以同时抵消初始偏移和最坏未来残差。

## 4. 证据边界

证据等级为 `reachable_extreme_visible_fiber_full_state_fifteen_tick_obstruction`。它精确否定当前
`J14` seed、global residual、correction box和15-tick语言的安全保证，且已放宽到乐观全状态因果
反馈；但不否定改变seed中心范围、缩小有保证的未来residual、增加物理输入权限、修改经认证的通信
合同或完整六自由度系统中的其他设计。
