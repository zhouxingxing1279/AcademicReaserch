## 2. 一个可控制复杂度的候选研究合同

以单个状态方程为例，考虑离散系统

```math
x_{k+1}=f_0(x_k,u_k)+\theta_*^\top\psi(x_k,u_k)+w_k,
\quad |w_k|\le\bar w,\quad \theta_*\in\Theta_0.
```

向量系统逐行处理参数矩阵，但状态和噪声相关性应保留在联合关系中。psi是离线学习后冻结的特征映射；在线学习输出层参数及其可行集合。该选择便于先建立一致的参数坐标，不意味着它已优于GP或端到端网络。

必须明确：theta*在认证区间内固定；psi和f0在认证源域有有效Lipschitz界；未建模误差有独立有效上界barw。有限训练集残差最大值不能自动充当全域barw。如果无法建立这些条件，就只能改为带明确概率事件的保证，不能沿用确定性结论。

SMF给出包含真实状态的Xk，而不是准确训练输入。更理想的是给出包含真实相邻状态对的联合集合Kk⊆Xk×X(k+1)。这个联合集合必须由包含theta*的模型族传播和有效测量更新得到；不得先用不可靠点模型缩小X，再借缩小的X“证明”该模型可靠。

## 3. 辨识使用存在量词，控制安全使用全称量词

给定Kk，有效的局部一致参数集合为

```math
S_k=\{\theta:\exists(x,z)\in K_k,\ \exists w\in W,
\ z=f_0(x,u_k)+\theta^\top\psi(x,u_k)+w\}.
```

更新为Theta(k+1)=Theta(k)∩Sk。真状态对和真扰动提供存在性见证，所以theta*不会被排除。若用外包Sbar⊇Sk替代，仍保持包含与参数集合嵌套；不能由此自动推出收敛速度或可辨识性。

这里不是要求同一个theta解释K中的所有可能状态。相反，MPC安全检查必须覆盖保留集合中的所有可能真实状态和参数。辨识与控制的量词不同，不应混用。

**精确反例：** z=theta*x，theta∈[0,4]，X=[1,2]，Z=[2,3]，噪声为零。

- 存在一对一致状态的参数集合是[1,3]，包含真实theta=1、x=z=2。
- 用两个区间中心直接拟合，只得到theta=5/3，排除了真参数。
- 错误要求theta X⊆Z，得到theta≥2且theta≤3/2，即空集。

因此“中心拟合后缩小模型集”和“对全部可能训练状态施加一致性”均可能破坏可靠性。

## 4. 不丢失联合关系，可证明减少保守性

若K⊆X×Z，则对应存在性投影满足

```math
S(K)\subseteq S(X\times Z).
```

证明直接来自可行见证集合的包含；这是一条基础单调性质，不是首创定理。它指出方法设计应该保留什么信息。

在同一X=[1,2]、Z=[2,3]中，若另有独立有效的联合约束z=x+1，则一致参数集变为[3/2,2]，严格小于[1,3]。该联合约束是另一个示例的附加信息，不能把它强加到上一节theta=1的真轨迹；是否能得到类似信息取决于真实测量与滤波合同。

更强的全历史辨识必须让相邻记录共用同一个xk。逐对求Sk再相交可能让同一theta在相邻记录中使用不一致的状态见证，因此通常只是全历史参数集合的外包。它仍可安全，但不能称为精确联合辨识。反复维护完整历史又会导致复杂度增长——这才是固定复杂度压缩要解决的具体问题。

## 5. 可实现的安全基线：对中心回归显式补偿状态误差

假设|x−xbar|≤r、|z−zbar|≤rplus，且

```math
|f_0(x,u)-f_0(\bar x,u)|\le L_f r,
\quad\|\psi(x,u)-\psi(\bar x,u)\|_\infty\le L_\psi r,
\quad\sup_{\theta\in\Theta_k}\|\theta\|_1\le M_k.
```

由真实动力学和三角不等式，真参数必满足

```math
|\bar z-f_0(\bar x,u)-\theta^\top\psi(\bar x,u)|
\le\bar w+r^++L_fr+M_kL_\psi r.
```

右侧必须先由有效参数先验和状态外包计算，不能通过拟合误差反推。该式关于theta形成线性条带，可与参数多面体或CZ求交；保留旧条带可保证嵌套，但条带数量并不自动有界。

在第3节例子中，这个保守基线得到[0,10/3]，包含精确一致集[1,3]。它为联合约束方法提供公平的安全比较基线，避免仅与不可靠的中心拟合比较。

## 6. 特征在线变化时，旧证书不能直接沿用

即使函数未变化，参数坐标也可能变化：psi_old(x)=x、theta_old=1，与psi_new(x)=2x、theta_new=1/2表达同一个函数。若保留旧参数等式theta=1却切换到新特征，就会排除真函数。

因此第一阶段固定特征，仅在线更新输出层。若后续更新特征，须提供旧函数集合到新表示的认证映射，或从覆盖真函数的新先验重建证书。重建引起集合扩张时，还需重新处理MPC可行性，不能沿用嵌套归纳。该反例解释了为什么不应一开始就在线更新全部神经网络权重。

## 7. 与MPC滚动预测的连接，以及尚未闭合的部分

精确基准应维护状态—参数联合集合Jk。固定theta和psi后，以同一theta传播每条历史，利用下一观测求交，得到J(k+1)。只要真模型、真噪声与测量满足合同，真实(x(k+1),theta*)仍在集合中。参数投影相对于完整历史单调缩小。

给定旧预测的同一条因果输出反馈策略，实际测量到达后筛选相容的观测历史并保留其全部约束；新预测尾段是旧预测对应尾段的子集。这里策略必须随实际历史限制，而不是重设observer或任意更换控制律。

以下均不能由上述集合论自动获得：固定复杂度重建后仍滚动包含；有限时间内参数集合严格收缩；新追加末端安全；闭环递归可行性；采样期限内完成计算。尤其是只保留X和Theta的独立边际，会重新引入不可能的状态—参数组合。

参数漂移theta(k+1)∈theta(k)⊕Delta时，可以先预测参数集合再求交以保真，但当前参数集合不再必然嵌套。正确的未来预测要保留漂移转移合同；本文固定参数证明不能直接用于任意阵风或突变参数。

## 8. 创新候选与停止条件

**候选A：保留联合状态—参数关系的固定复杂度学习更新。** 学习特征/残差参数是功能模块，SMF提供集合值数据；目标是在认证误差下保持真模型，并相对安全中心条带基线减少控制相关支持上界。必须解决历史共享状态、压缩误差及滚动一致性。

**候选B：有限预算下学习选择认证收紧任务。** 固定可靠基础外包，学习选择额外方向、历史约束或乘积细化任务；每项任务必须返回独立可验的外包证书。安全性不依赖学习选择正确，收益在相同预算下评估。若简单贪心或固定排序效果相同，则没有理由加入RL。

两条候选都不是已确认原创。A需重点对比带测量误差的集员辨识、联合状态参数估计、learned-feature adaptive MPC；B需对比anytime估计、主动约束选择、学习优化及输出反馈可行热启动。当前近邻检索不足以排除这些已有工作。

下一阶段验收应包括：独立固定真实参数与噪声的保真测试；安全条带、边际集合、联合集合的同信息同预算比较；特征版本切换与参数漂移的负例；MPC控制方向的收紧量而非单看集合体积。四旋翼基准先用固定或有已知漂移界的气动参数；任意快速扰动另由有效W覆盖。

停止/转向条件：无法取得有效误差包络；近邻方法已有相同定理且无可证明差异；联合表示在同预算下无收益；闭环可行仅靠放宽约束或缩小测试扰动。不能为保证论文结论而修改对照条件。
