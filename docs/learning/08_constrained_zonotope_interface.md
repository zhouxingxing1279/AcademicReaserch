# C2-G/CZ：约束 zonotope 的可靠更新与有限试验

日期：2026-09-16。用户建议尝试 constrained zonotope，本文完成表示合同与有界试验。**CZ 适合作为下一阶段候选：仿射预测和线性测量修正可精确表示，保留约束可严格改善方向上界；有限复杂度、模式合并后的移位关系及 MPC 接入尚未闭合。**

## 1 表示、预测、测量和中心

记

```math
\mathcal C(c,G,A,b)=\{c+G\xi:A\xi=b,\ \|\xi\|_\infty\le1\}.
```

c 是仿射偏移，b≠0 时不一定是集合中心或集合成员。CZ 的等式把生成元系数相关性保留下来。普通 zonotope 是没有等式的特例；CZ 通常不中心对称。

对仿射外包 x⁺=Fx+f+Wη、‖η‖∞≤1，预测参数为

```math
c^+=Fc+f,\quad G^+=[FG,W],\quad A^+=[A,0],\quad b^+=b.
```

对 y=Hx+Rν、‖ν‖∞≤1，精确测量交集为

```math
G_y=[G,0],\quad
A_y=\begin{bmatrix}A&0\\HG&R\end{bmatrix},\quad
b_y=\begin{bmatrix}b\\y-Hc\end{bmatrix},\quad c_y=c.
```

这里“精确”相对于所声明的仿射集合模型；真实非线性预测仍需可靠余项外包。现有误差模型曾独立放宽的 nφ=−zφ 相关性，可以在增广潜变量中保留等式；本次直接维护物理状态的仿射外包及历史测量等式，避免把同一角度误差重复当作独立变量。

对实际观测器中心 x̂，误差集合必须取 E=X−x̂，即只将 c 改为 c−x̂。中心变动 Δ 后 E 改为 E−Δ；不能任意替换为 CZ 的仿射偏移而沿用旧观测器证明。本次零观测、悬停输入下中心固定为 (0,2,0,0,0,0)，不验证一般在线中心轨迹。

## 2 可复核的方向上界

给定方向 d，支持函数为

```math
h_{\mathcal C}(d)=d^Tc+\max_{A\xi=b,\ |\xi|\le1}(G^Td)^T\xi.
```

任意有理乘子 λ 都给出可靠上界

```math
U(d,\lambda)=d^Tc+b^T\lambda+
\|G^Td-A^T\lambda\|_1\ \ge h_{\mathcal C}(d).
```

证明只需将目标写成 bᵀλ+(Gᵀd−Aᵀλ)ᵀξ，再用 ‖ξ‖∞≤1。乘子无需满足额外可行条件。脚本用 SciPy/HiGHS 提议乘子，以分母不超过10⁹的有理数近似，再用 Fraction 精确计算 U；数值最优性和浮点不可行判定均不作为证书。求解失败时退回 λ=0 的可靠外包上界。本次所有集合 b=0、c=0，ξ=0 是精确非空见证，且中心对称，因此 ±d 共用同一半宽上界。一般非零观测必须分别查询正负方向。

对可靠验证器给出的 aᵀx≤u，取可靠下界 m=aᵀc−‖Gᵀa‖₁。若 u≥m，可追加零生成元和一个系数 s∈[−1,1]，用

```math
a^TG\xi+\frac{u-m}{2}s=\frac{u+m}{2}-a^Tc
```

精确表示求交。若 u<m 则交集为空，应报告合同不相容，不能把它当作零误差。此半空间更新公式已推导，尚未加入试验脚本。

## 3 25 步试验：同信息普通外包与 CZ

代码：[check_constrained_zonotope.py](../../verification/check_constrained_zonotope.py)；完整有理支持证书和乘子：[certificates.json](../../results/constrained_zonotope_20260916/certificates.json)。

沿用原六维状态、初始盒、噪声、dt=0.02、g=9.81 与原非线性余项域合同：

```math
D_x=1.880+4.905(0.45)+14.715(0.45)^3/6,
\qquad D_z=2.086+14.715(0.45)^2/2.
```

在 pz−2 坐标下，物理仿射外包为 p⁺=p+h v，vx⁺=vx−hgφ+h wx，vz⁺=vz+h wz，φ⁺=φ+hω，ω⁺=ω；|wx|≤Dx、|wz|≤Dz。实际输入固定 T=g、τ=0，处于原输入域。所有观测均取零偏差。每步测量角度/角速度，位置成功序列分别为 {0,5,10,15,20,25} 和 {0,15,25}，后一序列有连续两次丢包，均满足传感器合同。这里只比较这两条已实现的观测记录，不枚举未知未来观测。

CZ 保留全部等式，不降阶。普通 zonotope 采用同一物理预测与相同测量信息，通过

```math
G_Z^+=[(I-KH)G_Z,KR]
```

作可靠测量外包。K 对直接观测状态取1，位置到速度的增益分别取5和4.5，其余为0；任意 K 都保证交集包含在该外包内。这是固定增益对照，**不声称它是最紧普通 zonotope 方法**。tick 0 的条带与先验盒相同，对照保持先验即可。

初始集合相同，仿射预测与求交单调，对照测量公式可靠，故每步 CZ⊆普通外包。记录每个预测及后验的普通外包坐标支持，均在原状态域内，从而在这两条条件观测记录下逐步满足源域余项合同。此项证明不覆盖其他观测记录或闭环策略。每条记录在第5、15、25步查询六个坐标，共36个有理对偶上界。

第25步速度半宽（m/s）：

| 位置包序列 | 方向 | CZ 认证上界 | 普通外包精确支持 |
|---|---|---:|---:|
| 每5步成功 | vx | 0.66158704375 | 0.8788915296875 |
| 每5步成功 | vz | 0.5933483125 | 0.8038457717533594 |
| 两次连续丢包 | vx | 0.679576246875 | 0.679576246875 |

两条记录第25步的 px/pz 半宽均为0.02，φ为0.005，ω为0.01。36项比较中9项上界严格小于普通外包的精确支持，构成严格收紧见证。CZ 值是可靠上界，未提交全部精确最优原始见证，不能统称精确支持最优值。

这组结果**不能直接与07的全部路径误差集合峰值作性能比较**：07维护特定观测器的误差外包并覆盖全部允许路径；这里使用相容状态后验、两条固定观测记录与不同普通外包递推。物理参数一致不意味着估计集合或比较问题一致。

## 4 尚未解决的压缩与预测包含

第25步，正常包/丢包案例分别有120/114个生成元、64/58条等式；复杂度随时间增长。有限25步计算完成不证明20 ms实时门或固定存储界。

CZ 对两个集合的交集闭合：引入独立系数 ξ、ζ 并追加 G₁ξ−G₂ζ=c₂−c₁，即可表示 C₁∩C₂。但多模式可达集的并一般非凸，不能自动等于一个 CZ。保留多个 CZ 或取凸外包，都需要明确复杂度与后续测量求交的损失。

**外包降阶不自动保留移位包含。** 二维 CZ G=I、A=[1,−1]、b=0 是正方形内的对角线。删掉等式得到正方形，对 d=(1,−1)，旧支持0变为2。它仍包含真集合，却已越出旧预测集合。解析反例已在测试中复核。

要继承此前预测，必须在相同实际中心坐标和同一终点模式下满足

```math
X_{k+1}^{\rm consistent}\subseteq C_{k+1}^{\rm out}
\subseteq P_{k+1|k}^{\rm old}.
```

若已证明真集合同时在新外包与旧预测内，可取新外包∩旧预测恢复该夹逼；交集的 CZ 表示本身会继续增大，因而这不是有限复杂度问题的答案。普通 LP 数值不可行也不能触发丢弃真实分支。

MPC 尚需明确读取哪些误差/注入方向、中心与控制管如何组合。调度奖励应反映这些方向的已认证上界变化及验证成本；标量半径下降不能自动算作 CZ 收紧收益。支持界的计算和证书复算本身须计入总预算。

## 5 决策与下一步

保留 CZ 作为 C2-G 的候选表示；预测、测量求交、中心转换和方向证书具备明确合同。本次没有修改生产滤波器、训练 RL 或实现 MPC。

后续进展：[09 跨时刻可达集包含](09_shifted_reachable_inclusion.md) 已证明在绝对状态坐标、相同移位控制尾部和嵌套扰动集合下，新移位可达集包含于旧预测对应层；非零中心、位置成功/缺失及三个必要反例已有精确有理数核查。该结果闭合动力学层的受限仿射合同，但固定大小 CZ 编码、控制侧 tube 和终端证书仍未闭合。

下一项工作固定为：从状态/输入约束与候选 ancillary feedback 导出有限控制相关方向矩阵 $H$，检查固定模板收紧在整个 horizon 内是否非空，并设计满足20 ms预算的 CZ→模板超时返回规则。只有控制读取接口与终端义务闭合后，才评价学习调度相对有限前瞻的预算收益。

复现：

```bash
python -m unittest discover -s verification -p test_constrained_zonotope.py -v
python verification/check_constrained_zonotope.py --output /tmp/cz_certificates.json
```

三个解析测试覆盖非零测量与中心变换、任意对偶上界、删除等式的移位反例；六维试验另生成36项证书。输出路径必须不存在；physical_domain_gate 若为 blocked，不得将后续代数结果解释为完整25步物理外包证书。此脚本需要 verification/requirements.txt 中已有的 NumPy/SciPy。独立数学复核未发现阻断问题；已补齐物理配置冻结与初始条带冗余检查。
