# C2-G/T：固定维度 CZ 重建与滚动预测夹逼

日期：2026-09-17。承接 [09 移位可达集包含](09_shifted_reachable_inclusion.md)。

**本轮解决固定模板下的表示维度与跨时刻包含：只发布固定方向多面体，精确重建为固定大小 CZ；在旧预测仍有效的条件下，压缩不会突破旧预测。结论是集合接口的条件定理，不是六维 MPC 递归可行性或实时性证书。**

## 1. 固定模板的精确 CZ 表示

固定 H 的前 2n 行为 I、−I，余下 r 行为 aⱼᵀ；m=2n+r。令 P(b)={x:Hx≤b}，全部 b 有限。坐标约束给出

```math
\ell=-b_{n+1:2n},\quad u=b_{1:n},\quad
c=(u+\ell)/2,\quad v=(u-\ell)/2,\quad D=\operatorname{diag}(v).
```

对每个额外方向，定义盒上的准确下界和非负松弛半宽

```math
q_j=a_j^Tc-\|Da_j\|_1,\qquad
s_j=(b_{2n+j}-q_j)/2.
```

若 ℓᵢ>uᵢ 或 sⱼ<0，则 P(b) 已被精确证明为空，不能使用负半宽“重建”。在其余情况下，令 E 为额外方向矩阵，得到

```math
G=[D,0],\qquad
A=[ED,\operatorname{diag}(s)],\qquad
\widetilde b=(b_{2n+1:m}+q)/2-Ec.
```

**定理 1。** P(b)=C(c,G,A,b̃)，其生成元数 n+r、等式数 r，与递推次数无关。

**证明。** CZ 系数 ξ 对应 x=c+Dξ，故 x 在坐标盒内。额外系数 ζⱼ∈[−1,1] 满足 aⱼᵀx+sⱼζⱼ=(bⱼ+qⱼ)/2，等价于 qⱼ≤aⱼᵀx≤bⱼ；下界已由坐标盒保证。反之，任意 x∈P(b) 可用盒坐标 ξ 表示，并取 ζⱼ=(bⱼ−aⱼᵀx)/sⱼ−1。sⱼ=0 时 aⱼᵀx=bⱼ=qⱼ，取 ζⱼ=0；vᵢ=0 时取 ξᵢ=0。两侧包含成立。上述简单判空检查没有覆盖全部空集，余下空集仍由不相容等式精确表示；浮点 LP 失败不得被当成空集证书。□

这是从模板到 CZ 的**等价编码**；真正的近似损失发生在把一般后验替换为固定模板时。c、D、s 随 b 变化，矩阵数值也变化，所以只声称维度固定，不声称只更新右端项。固定格点限制分母，若集合幅值无界则整数位长仍可能增长；维度固定也不等于固定字节数或最坏执行时间。

## 2. 可靠压缩与有效旧上界

沿用08的任意有理乘子上界

```math
U(d,\lambda)=d^Tc+\widetilde b^T\lambda+
\|G^Td-A^T\lambda\|_1\ge h_C(d).
```

逐方向向上舍入到 10⁻¹⁰ 格点，得 βⱼ≥Uⱼ。若已经知道 C⊆P(bᵒ)，取

```math
b_j^n=\min\{\beta_j,b_j^o\}
\quad\Longrightarrow\quad
C\subseteq P(b^n)\subseteq P(b^o).
```

数值 LP 只提出乘子，最终 U 和舍入均以 Fraction 计算。LP 未成功时 λ=0 仍给出可靠但较松的上界。该操作**不能自行验证旧 cap 的有效性**：代码 compress 的前提就是目标集合已包含在 cap 内。它不接受“旧数据看上去更小”作为理由。

## 3. 为什么可以连续滚动，而不只做一次 min

从本接口启用起，保存并发布的未来集合统一为 P⁽ᵒ⁾₀,…,P⁽ᵒ⁾ᴺ，且旧链必须满足

```math
F_iP_i^o\oplus\{f_i\}\oplus W_i^o\subseteq P_{i+1}^o.
```

这是旧外包链的后继包含条件；旧集合不必等于准确可达集。不能把仅包含某次真轨迹的集合当成这样的预测链，也不能追溯把08任意未压缩 CZ 当作本接口的旧模板。

新时刻测量后令 C₀=P₁ᵒ∩M；无某个传感器测量时，只省略该通道的交集。本项目角度和角速度仍每步观测，位置包缺失不意味着省略所有测量。由第2节压缩，得到 P₀ⁿ⊆P₁ᵒ。

**定理 2（固定维度滚动链）。** 沿用09的匹配映射和移位输入尾部，扰动嵌套；对 i=1,…,N−1，先计算新链传播像

```math
C_i=F_{i-1}^nP_{i-1}^n\oplus\{f_{i-1}^n\}\oplus W_{i-1}^n,
```

再以旧 Pᵒᵢ₊₁ 为 cap 压缩。则新链每步都包含其前一集合的完整传播像，并且 Pᵢⁿ⊆Pᵒᵢ₊₁。最后追加第 N 层时没有旧第 N+1 层 cap，单独作可靠外包。

**证明。** 若 Pᵢ₋₁ⁿ⊆Pᵢᵒ，则同映射、同移位输入和嵌套扰动给出 Cᵢ⊆FᵢᵒPᵢᵒ⊕{fᵢᵒ}⊕Wᵢᵒ⊆Pᵢ₊₁ᵒ。因此第2节 min 的两个上界都有效，Cᵢ⊆Pᵢⁿ⊆Pᵢ₊₁ᵒ，归纳成立。下一次滚动仍可使用这条新链，故结论适用于任意有限滚动次数，只要假设持续成立。□

若改变控制尾部或扩大扰动集合，必须重新认证旧 cap 或重建新预测，不能强行截断。此次数值核查固定悬停输入和常矩阵，rollout 的旧链兼容性由调用流程保证，函数本身不验证旧链的动力学来源；它是研究核查器，不是可接受任意旧证书的生产 API。

一般中心变化可通过绝对状态模板比较，或精确转换误差模板 bᴱ=bˣ−H x̂；不能仅比较不同中心下的 bᴱ。此转换已有非零一维测试，未据此宣称观测器控制侧误差已闭合。

## 4. 预算耗尽的返回语义

- 后验查询可未完成：保留有效旧一步模板，或只提交已完成方向的可靠收紧；仍包含相容状态。
- 未来方向查询失败：λ=0 给出可靠上界，有合法旧 cap 的层仍可取 min。
- 若整个未来重算来不及，可移位已有 N−1 层，但第 N 层必须另行可靠追加；没有终端/追加策略时，不能声称保留了长度 N 的可行 MPC 方案。

脚本仅在 tick30 强制一整轮未来查询使用 λ=0，验证较松上界不会破坏合法 cap；没有实现抢占式计时器或硬实时返回。保守性可能明显增加。

## 5. 六维验证范围与复现

代码：[check_cz_template.py](../../verification/check_cz_template.py)；解析回归：[test_cz_template.py](../../verification/test_cz_template.py)。

沿用08的冻结物理参数检查、初始盒与仿射余项，输入为 T=g、τ=0。H 使用 ±6个坐标方向，再加 ±(px−0.2vx)、±(pz−0.2vz)、±(φ−hω)，共18行，因此重建 CZ 恒为12生成元、6等式。斜方向用于本轮几何探针，**尚不是由合格 K、L 推导的最终控制方向库**。

试验从一个非零的相容初始点出发，以零过程扰动生成仿射模型见证轨迹；测量加入正负半个噪声界，每15步位置成功，角度/角速度每步观测。所有未来预测忽略尚未发生的测量，所以不依赖猜测的未来包序列；这保守地覆盖任意未来测量的相容子集，但可能导致预测界过宽。

该轨迹只是仿射外包模型的成员见证，不是原非线性 plant 仿真。对每个模板构造精确潜变量见证，检查其范数、状态映射和等式；一般集合包含依赖前述定理及可靠上界，而不是靠单条见证轨迹证明。

### 5.1 已执行的结果与阻断项

[滚动检查摘要](../../results/cz_template_20260917/checks.json)记录：60次移位更新，加初始时刻共61轮，每轮保留25步预测；28,548项有理支持/舍入检查、27,000项移位方向界比较、1,586个精确潜变量成员见证，92项方向因合法旧 cap 得到更小发布界。六个回归测试通过。移位计数是模板界的逐项检查，完整传播包含仍依赖第3节归纳，不是27,000次独立集合包含求解。

发布 CZ 始终为12生成元、6等式；临时预测 CZ 为14/6，位置到包时临时测量 CZ 最大16/10。所有这些维度均有与运行时长无关的上限，未测试20 ms门。通用核查入口拒绝浮点矩阵，防止精确接受算术被隐式浮点运算替换。

**精度准入未通过。** tick9 的第25层预测发布水平速度上下界已超出原 ±3 m/s 范围，正方向为15238801721/5000000000。这表示现有坐标上界不能认证模型有效域，不证明真实轨迹越界，也不证明模板集合必然越界。后验的发布界在记录后段也不能认证原域。因此，整个60步结果只解释为仿射集合合同验证，不解释为原非线性物理模型的全程证书。

## 6. 对后续研究的约束

本轮不再把“CZ 等式不断增长”视为不可绕过的问题：固定模板可用等价 CZ 编码控制维度。但模板会损失相关性，不能继承08的紧度优势，更不能从固定维度推断20 ms达标。

下一项研究先做方向充分性：根据最长15tick的位置包间隔构造有限步传播方向，分析能否保留跨测量时刻的位置—速度相关性并避免后验界持续变宽；再与合格输出反馈接口的状态/输入/观测注入方向对齐。不能直接扩大训练规模或靠任意加方向回避此处的保守性机制。本轮12/6方案不进入MPC实验。

CZ 表示及有界多面体表达基础参见 [Scott等，Automatica 2016，公开作者版](https://iris.unipv.it/retrieve/e1f104fd-05da-8c6e-e053-1005fe0aa0dd/CZ.pdf)。固定模板、支持外包及等价编码并不作为新颖性主张；本轮贡献定位为当前研究接口的可复核条件构造。
