# 102. 可见中心、未来残差与输入权限的精确合同界面

## 1. 条件支持函数

令 `D xi=d_p=e_p-eta_p`，`F xi=e_p+14h e_v`，并把成功测量后允许的可见范围写为
`|d_p|<=r`。需要计算的不是无条件 seed 半径，而是

```math
H(r)=\max\{F\xi:\|\xi\|_\infty\le1,\ |D\xi|\le r\}.
```

对偶给出 `H(r)<=lambda r+sum_i|F_i-lambda D_i|`。取
`lambda=29/15`，截距为

```math
b=\sum_i|F_i-\lambda D_i|=\frac{16315003}{75000000}.
```

对偶次梯度区间与盒原始解同时证明，在

```math
0\le r\le\frac{20432147}{48000000}
```

上等号成立，即 `H(r)=b+(29/15)r`。所需安全阈值位于该仿射支内。这里的 `lambda`
是支持 LP 的最优对偶斜率，不是每个生成元逐项比例；后一错误表述已被 RED 测试排除。

## 2. 三因素必要条件

令 `beta` 缩放14次 miss 的有保证 future-residual 半宽，`gamma` 缩放物理 correction
authority。当前两项位置预算相等：

```math
D=C=\frac{52065013}{400000000}.
```

因此，在上述仿射支内消除 Run165 正侧反例的精确必要条件是

```math
b+\frac{29}{15}r+\beta D-\gamma C\le1. \tag{102.1}
```

保持另外两项为当前值时，三个单因素边界为：

| 修改因素 | 精确边界 | 相对当前合同 |
|---|---:|---:|
| 可见范围 `r` | `r<=58684997/145000000` | 从约0.505670降至0.404724，即最多保留约80.04% |
| future residual `beta` | `beta<=16254878/42598647` | 至少降低约61.84% |
| correction authority `gamma` | `gamma>=68942416/42598647` | 至少提高约61.84% |

三点代回式(102.1)均严格得到端点1；当前合同得到
`3889781459/3600000000≈1.08049485>1`。

## 3. 可实现性边界

`r` 是当前状态信息集的可见中心范围：只有新的可靠初始化/测量合同能保证所有允许观测满足该
上界，运行时拒绝大观测不能删除真实状态。`beta` 是未来过程余项保证，需要更紧但仍可靠的物理/
模型余项界；SMF后验本身不能推出它缩小。`gamma` 是执行器及推力分配权限，需要物理可用推力、
姿态/电机约束和 nominal allocation 共同认证；SMF不能创造权限。

因此式(102.1)是合同筛选界面，不是控制器、终端不变性或递归可行性证明。当前最接近SMF主线的
候选是先审计 `r` 能否由合法 measurement intersection 可靠保证；若不能，应优先回到物理 residual
建模，而不是继续调集合表示或局部 gain。
