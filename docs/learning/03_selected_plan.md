## 1 研究定位

题目暂定：**有限计算预算下强化学习辅助的集员输出反馈预测控制**。

唯一学习位置是每个控制周期内的集合验证任务调度。RL 决定下一次验证哪个控制相关方向及何时停止；独立验证器签发约束；物理 SMF 维护可靠集合；鲁棒输出反馈 MPC 生成实际输入。

首版不学习动力学、不学习噪声边界、不学习 MPC 权重或终端集，也不由 RL 直接输出推力。保留现有六维状态、两输入平面模型与原参数，完整三维作为后续扩展。改变物理合同必须另行记录。

## 2 固定模块方案

| 模块 | 选定方案 | 验收接口 |
|---|---|---|
| 基础动力学 | 物理离散模型与有界余项 | 有效域、执行输入、传感器时序明确 |
| 基线 SMF | 保留有限窗口一致性信息，以线性约束/生成元保留相关性 | 预测与校正真值包含；外包/约简后仍保持证明关系 |
| 候选库 | 从已选 MPC 收紧条件导出有限目标方向，控制周期内冻结 | 来源明确，归一化固定；不人为增加无关任务制造预算瓶颈 |
| 验证器 | 对同一窗口一致性关系计算方向支持的可靠上界 | 超时只返回已经认证的上界；无证书不收紧 |
| RL 调度 | 有限预算内选择尚未完成的验证任务或停止 | 只读取允许信息；实际计算和推理成本计入预算 |
| 控制 | 具有在线估计界接口的鲁棒输出反馈 MPC | 初始/终端/更新闭合与实际输入条件须逐条满足 |

线性松弛的支持验证先使用 LP 对偶可行证书及有理数复核；必要的非线性松弛必须有覆盖证明。不会默认现成浮点 LP 结果就是认证上界。保留集合约束的具体数据结构在接口阶段固定，不同时比较多种几何表示。

控制理论的主参考固定为 Köhler、Müller、Allgöwer 的在线估计界输出反馈 MPC 框架，先做其假设映射，不再寻找多个新控制分支。其 homothetic tube 使用的误差度量必须与方向收紧收益真正衔接：若集合改进没有改变控制器实际读取的估计界，则不能宣称控制收益。这一适配尚未完成，也不能直接把任意方向多面体替入原定理。

## 3 一个控制周期内的调度任务

一个 episode 对应固定物理信息 Iₖ 的计算过程，而非一段自由探索的飞行。输入是基线 Bₖ、窗口一致性描述、目标方向、约束余量及可用时间。每完成一次验证，记录返回界、实际成本和更新后的表示。

动作是离散的“选择任务 j”或“停止”。不选择控制量；无效/已完成动作被屏蔽。预算不足或到达截止时只返回已认证集合。基线估计、集合更新和控制求解必须预留时间；不能把整个采样周期全部用于 RL 查询。

完整环境状态包含窗口问题、已接受约束、验证历史及验证器状态。输入策略的摘要不自动满足 Markov 性；小型理论实例采用完整有限状态，规模化特征表示的泛化仅按实验评价，除非另外证明充分性。

首个最小实例至少包含两个有实际来源的目标方向和两次序列决策机会；规模必须小到可以精确枚举。若相同集合查询只产生固定可加收益、顺序没有价值，不人为隐藏信息来制造 MDP。

## 4 算法选择

小型有限实例先用精确枚举/动态规划提供最优序列参照，并用表格 Q-learning 检查任务定义。它是调度问题的机制验证，不是另开一条控制路线。

规模化首选算法固定为 **带动作屏蔽的 Double DQN**，用于离散验证任务选择；不同时实现 PPO、SAC 或连续方向生成。神经网络只近似动作价值，不负责物理安全证书。选择 Double DQN 是实现决策，不是已证优于其他算法；小型实例没有序列价值就不进入此阶段。

离线训练，按轨迹/物理条件划分训练与测试；评价时冻结策略。禁止在真实飞行中通过不受限动作探索学习。网络结构、训练步数与预算数值要在数据/计时接口固定后登记，不沿用旧训练配置。

## 5 奖励和总预算

在每个 episode 内冻结目标方向 cᵢ、归一化与非负权重 ωᵢ。以当前保留集合的控制相关支持指标为性能代理，例如：

```math
J(B)=\sum_i\omega_i h_B(c_i),\qquad
r_t=J(B_t)-J(B_{t+1})-\lambda C_t.
```

C_t 包括实际验证、策略推理和集合维护成本。有限步训练采用不折扣累计奖励作为目标，使增量指标望远镜求和等于最终收紧收益减总成本；计算预算另作为硬上限，而不只依靠成本惩罚。

这些 h_B 是当前已保存外包的支持，不是免费调用全部昂贵相容集合支持 h_X。计算 J 本身仍有成本，训练时单列，在线若用作策略特征也必须计时。J 是收紧代理，不是跟踪误差或实际最优 MPC 代价。

## 6 要证明与要实验的内容

理论主张分开：

1. 任意调度策略下，只接受有效约束，保证 Xₖᶜ⊆Bₖ⁺⊆Bₖ；表示约简、超时返回也需满足该关系。
2. 控制基础的假设成立且集合/未来更新接口相容时，继承相应闭环保证；不能仅由 Bₖ⁺⊆Bₖ 推出递归可行。
3. 对小型声明任务类，给出非空序列决策收益见证及其条件。规模化 RL 相对强规则的收益先定位为经验结论，不预先承诺普适严格优势。

公平基线固定为：无额外验证、固定法向顺序、当前约束余量贪心、有限前瞻、学习调度。全部使用相同信息、验证器和总预算。离线全查询/动态规划只作为参照，不把其成本隐藏成免费在线能力。

## 7 实施顺序与停止条件

**最初的唯一交付物是《控制接口与有限调度环境规范》（已完成；当前任务以顶部 C2-G 为准）**：逐条映射所选控制基础假设，列出它实际需要的集合量，固定候选任务、状态/动作/转移、计时与奖励定义，并给出可枚举小实例。

之后严格按顺序：小实例证实预算瓶颈和序列价值 → 表格验证 → Double DQN 离线训练 → 冻结策略的同预算重放 → 控制基础实例证书满足后接闭环验证。

停止或回退条件：目标查询本来便宜且全查询已最优；强规则不存在可改善差距；序列价值由信息泄漏制造；方向收紧不影响控制接口；验证与控制总时间无法满足预算。触发后记录原因，保留非学习方案，不通过堆叠模型或换 RL 算法回避问题。
