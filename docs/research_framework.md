## 1 唯一主问题与研究边界

**主问题：在相同物理知识、测量历史和计算预算下，学习动力学模型能否帮助减少可计算集员估计的外包冗余，并在既定鲁棒 MPC 框架中产生可验证的控制收益？**

研究对象不是“从零发明一个能控制全部非线性四旋翼的控制器”。控制基础、集合估计和学习贡献需要分别有明确验收；不能将设计备用控制器的所有困难都变成新的论文主线。

| 项目 | 当前框架决策 |
|---|---|
| 首个模型 | 保留仓库六维状态、两输入的平面四旋翼，避免同时更改模型和研究问题 |
| 全三维系统 | 后续扩展与验证对象；不计为当前必须完成的首个理论实例 |
| 控制保证 | 限定可核查运行域、初始集合、输入/噪声/观测合同；不承诺整个任务域都不变 |
| 主贡献 | 经过验证的集合改进及其控制意义；学习的独立作用必须单独证实 |
| 学习模型 | 学习动力学残差、提供预测及局部方向/求解初值；未经认证的预测不直接缩小安全集合 |
| 当前不决定 | 网络类型、层数、训练损失、采样预算、集合阶数、MPC 数值求解器 |
| 暂停分支 | 继续逐组调 PD 增益、枚举限幅控制器、扩展全自由度、恢复训练或闭环性能实验 |

不恢复用户早期的 jerk/Transformer 方案为默认前提。若后续改模型或缩小运行域，必须记录旧合同与新合同差异，不能将新问题的通过说成旧问题已解决。

## 2 模块职责与接口

| 模块 | 输入 | 输出及必须成立的关系 | 禁止承担的角色 |
|---|---|---|---|
| M0 物理与观测合同 | 动力学、噪声、输入、采样/缺测时序、初始先验 | 可靠集合值转移 F₀、有效域、测量关系 | 不以训练误差代替物理合同 |
| M1 非学习集员基线 | 先验、实际执行输入、已到达测量 | 包含真值的 Bₖ；明确预测、校正、约简与记忆遗忘规则 | 不依赖在线未知真值 |
| M2 学习动力学与提议 | 与基线相同的可用历史、获准训练数据 | 名义预测、候选支持方向、验证器初值 | 不独立签发安全边界 |
| M3 独立集合验证 | 共同一致性关系、候选方向、验证预算 | 有效支持上界、有效期及来源；不接受时保留 Bₖ | 不把局部最大值当全局上界 |
| M4 鲁棒输出反馈 MPC | 当前集合、未来集合关系、参考、控制基础合同 | 同一信息下的共同实际输入，及相应可行性证据 | 不把当前集合更小自动当作递归可行 |
| M5 执行与观测反馈 | 实际指令、饱和/执行误差、下一测量 | 实际执行输入及真实时序日志，返回 M1/M4 | 不让观测器继续使用未执行的指令 |

学习支路 M2→M3 附着于物理基线 M1。M4 使用 M3 接受后的集合，但必须保持既定控制证明所要求的动态关系。验证失败时保留集合基线，并不自动意味着上一动作已经保证下次能回退；动作接受也必须服从控制基础的闭合条件。

## 3 最小数学接口

记共同历史为 Iₖ，相容状态集合为 Xₖᶜ。基础合同要求：

```math
x_k\in X_k^c\subseteq B_k.
```

学习模块给方向 aⱼ，验证器必须依据同一物理信息证明：

```math
\gamma_j\geq\sup_{x\in X_k^c}a_j^\top x.
```

接受后的表示为：

```math
B_k^+=B_k\cap\bigcap_{j\in J_k}\{x:a_j^\top x\leq\gamma_j\},
\qquad x_k\in B_k^+\subseteq B_k.
```

这是可靠性与非劣包含接口。严格集合改进还需给出 Bₖ 中被有效约束排除的成员。若实现需要外包/约简，最终输出仍须同时包含 Xₖᶜ、位于 Bₖ 内；不能只对约简前集合证明关系。

控制接口还必须明确未来预测是否覆盖实际估计更新、终端入口、共同因果策略和备用输入。**Bₖ⁺⊆Bₖ 单独不足以证明闭环安全或性能提升。** 只有相同策略类、代价、原始不确定世界及可比较的终端约束满足嵌套条件后，才讨论鲁棒可行决策集与最坏代价比较。真实逐轨迹误差下降另作实验问题。

## 4 控制基础应作为合同选定，不作为无限扩张的创新任务

首先选择并核查一个已有鲁棒输出反馈 MPC 理论框架的适用性，不直接宣布某现成框架已经适配本模型。先做假设逐条映射，再确定具体实现。

控制基础必须交付：

1. 采用的模型与运行域，哪些非线性部分精确处理、哪些有可靠余项界。
2. 输入及执行关系；若采用姿态内环与位置外环，写明内环跟踪误差、参考变化限制及平移耦合，不能把内环当成瞬时无误差执行器。
3. 观测更新、最大缺测合同和集合接口，覆盖启动期与未来更新。
4. 终端/备用策略或其他递归可行机制的实际适用条件，标出已有结论、可计算条件及未满足项。
5. 原初始集合的覆盖依据，以及需要何种可复核证书才能从条件定理变成当前实例保证。

现有姿态证书可以作为候选构件，但不能因此承诺拼接后安全。09 的受限输入接口也仅归为备用工具；目前不继续沿它自动展开更多增益搜索。

## 5 论文主张与证据分级

| 层次 | 希望证明什么 | 必须拿出的证据 | 当前状态 |
|---|---|---|---|
| 基线可靠 | M1 输出始终包含相容真值 | 已定义合同下的估计递推证明及表示保持 | 条件结论已有；具体闭环合同待锁定 |
| 附加约束可靠 | M3 不排除任何相容状态 | 独立支持上界证书、有效域与时间索引 | 条件证明已有 |
| 集合严格改进 | 至少在明确非空实例类中消除外包冗余 | 同信息严格见证及约简后的关系 | 一般接口已有，主研究实例待确定 |
| 控制意义 | 可行性改善或最坏代价条件非劣 | 同策略/终端/未来关系下的比较定理 | 条件接口已有；不能直接实例化 |
| 学习独立贡献 | 相同总预算下更有效地提出值得验证的候选 | 与强非学习提议的公平比较，或可核查选择/复杂度界 | 未证明 |
| 完整闭环 | 所声明域内约束、递归可行及必要时稳定性 | 基线合同实例证书、策略移位与实际更新覆盖 | 未完成 |

可以先对一个固定合同完成条件学习命题，而不要求先从零合成整个四旋翼控制器；但报告必须显式保留其前提。反之，完整六维安全证明也不能替代学习贡献。

## 6 公平比较与评价

至少保留三条比较支路，数据、物理知识、历史长度、集合表示预算和总计算预算一致：

- B0：非学习物理集员基线。
- B1：同样的独立验证器，加确定性/优化驱动的非学习候选选择。
- B2：同样的验证器，加学习动力学提议。

B2 对 B0 的改进可能完全来自验证器；只有 B2 对 B1 的差异才支持学习独立贡献。物理窗口界、姿态不变约束等公共知识必须同时给三者。训练和预计算成本分别记录，在线预算包含提议、验证、集合操作和控制求解；不能只比较网络推理时间。

理论指标优先：真值包含、严格集合见证、可行性关系。经验指标随后：方向支持冗余、有效候选比例、完整计算时延、跟踪误差。经验结果不升级为确定性全域结论。
