# PX4 加速度接口辨识预登记

2026-11-04；在采集新辨识数据前冻结。目标是解释当前理想 ZOH 合同失配；不调整 CZ、Tube MPC 或 PX4 控制参数，不将预测误差下降当作抗扰验证通过。

## 旧日志诊断

保留原始飞行数据，另存四组日志审计。比较固定 T、实际 dt、实际 dt 加首样本真值初始化的离线位置可行性；初始盒仍为位置 ±0.005、速度 ±0.01。求使位置历史相容的最小分段常值加速度界，不把它当成物理扰动证书。全历史 LP 与原有限窗口估计器分别标识。

PX4 GZBridge 的 groundtruth 速度本身由同一位姿差分生成；它只交叉检查坐标/时钟/实现，不提供独立速度证据。原 trajectory_setpoint 日志为 200 ms 间隔，不能识别精确收包延迟。

## 新实验

- 原始已验证 X500 启动器、默认物理及控制参数、仅本地 MAVLink；无外力。
- 两次独立启动：calibration 与 validation，拟合只使用 calibration；validation 全部留出，不能用其调参。
- 每块之前由 PX4 位置保持回到同一锚点。至少保持 6 秒，且连续 1.5 秒满足三轴速度绝对值 <0.04 m/s、距锚点各轴 <0.15 m、姿态倾角 <0.04 rad、参考姿态变化率 <0.06 rad/s。最长等待 60 秒，未满足则保留失败并降落。
- calibration：每轴两个独立恢复后的块，幅值 0.4 m/s²，正反符号各一块；每块为零 0.4 s、正 0.8 s、反 1.6 s、正 0.8 s、零 0.4 s。总时长 4 s，理想模型净速度和位移增量均为零。
- validation：每轴一块，幅值 0.3 m/s²，零 0.4 s、反 0.6 s、正 1.2 s、反 0.6 s、零 0.8 s，总时长 3.6 s。轴顺序用冻结种子 20261104（验证加 1）打乱，保存展开后的序列。
- 位置保持与 acceleration-only 阶段分开保存；模型拟合不混合两种控制模式。激励期间三轴都启用 acceleration-only，非激励轴为零，不额外反馈速度。
- 参考状态偏离锚点水平任一轴 >1.5 m、垂直 >0.8 m、任一轴速度 >1 m/s、离开 Offboard、阶段超时即停止并正常降落。这是实验监督界，不是已证安全回退。
- 保存每次发送的单调时钟、最近参考仿真时间、MAVLink boot 时间、命令、阶段、发送前后时刻；动作切换显式立即发送。参考样本记录回调到达时间。ULog 临时启用命令/状态原更新频率，结束恢复原日志配置；不改变控制参数。

## 分析和边界

比较理想双积分、静态增益/偏置和一阶滞后/有效延迟候选。只用校准集拟合及选择参数；验证集评价 0.5 秒一步、完整激励块自由预测的位置/速度误差，分轴报告、保留交叉轴响应及最大值。延迟是包含记录、保持、内环、差分在内的有效延迟，不直接称网络延迟。模型阶次可因校准证据不足而被否定；验证失败照实报告。

新位置序列以原 T=0.5、原位置噪声合同重放 CZ，分离模型失配与反馈控制影响。真值初值/速度只用于辨识、诊断和监督，不能冒充最终位置输出反馈性能。

一次飞行的多个采样点和激励块不是独立重复飞行；两次启动只能提供初步可复现性证据。实测最大残差不等于确定性不确定集合。重新构造扰动集合、增广状态估计器、Tube/终端证明及抗扰对照属于下一阶段。
