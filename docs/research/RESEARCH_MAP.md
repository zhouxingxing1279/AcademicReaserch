# 研究路线图：间歇位置量测下的 CZ-SMF + 外环输出反馈 Tube MPC

当前阶段**先做理论研究，不处理 PX4/ArduPilot 具体指令接口**。成熟飞控承担姿态、角速度、控制分配和电机闭环；12 状态六自由度四旋翼作为后续高保真物理 plant。理论阶段使用抽象离散外环模型和有限测量语言，避免把某个尚未验证的飞控接口写成已知输入模型。

## 阶段 1：冻结抽象理论模型与信息合同

1. 以 \(x_{k+1}=Ax_k+Bu_k+Gw_k\)、\(y_k=C_px_k+v_k\) 为起点；首个状态候选 \(x=[p;v]\)，位置量测 \(C_p=[I_3\;0]\)。
2. 明确 \(u_k\) 只是抽象高层命令，不预设 position/velocity/acceleration 接口。
3. 明确有界过程残差 \(\mathcal W\)、位置噪声 \(\mathcal V\)、状态约束 \(\mathcal X\) 和命令约束 \(\mathcal U\)；参数不确定性不得未经外包证明就合并为常值加性噪声。
4. 用有限状态自动机/有限长度语言冻结 success/miss/delay、最大连续失测、最大时延和时间戳规则。

## 阶段 2：位置-only 观测的可观测性与有限误差界

1. 对候选常速度离散模型计算有限窗可观测矩阵；验证任意允许测量模式窗口是否具有统一秩/奇异值下界。
2. 推导有界噪声与有界加速度残差下的位置差分速度误差界，明确最大连续失测上界的必要性。
3. 区分无延迟丢包与 out-of-sequence delayed measurement；延迟读数必须按原时间戳更新并重新传播。
4. 若某些允许测量词导致隐藏速度误差无界，则先收紧测量语言或增广可用观测，不得直接进入硬安全 Tube 证明。

## 阶段 3：CZ 集员滤波

1. 实现/推导 CZ 的线性映射、Minkowski 和、位置量测条带交集。
2. 验证每一步真实状态包含、空集检测和外包降阶包含；空集必须触发模型/传感器合同违例诊断。
3. 对非线性或参数不确定模型，使用有证明的 mean-value/Taylor 余项外包；不把局部线性化残差当作已知界。
4. 比较精确 CZ 后验、CZ 外包降阶和较简单 Box/Zonotope 的集合紧致性与复杂度。

## 阶段 4：Equalized Recovery 与估计误差管

1. 从每个非空 CZ 后验中选取可验证的内部代表点 \(\hat x_k\)，定义 \(\mathcal E_k=\mathcal X_k-\hat x_k\)。
2. 在有限测量语言下，构造相位/模式相关误差外包 \(\mathcal E_i\)，覆盖所有允许的量测值、噪声和丢包路径。
3. 证明估计误差管满足 Equalized Recovery：中间误差可暂时扩大，但恢复周期末回到指定误差界。
4. 对照两条路线：精确 CZ 后验的最坏分支外包；路径相关动态 observer + CZ 误差集合。先做 worst-phase baseline，再证明更复杂模式索引确有收益。

## 阶段 5：共同因果输出反馈 Tube MPC

1. 以名义轨迹 \(\bar x\)、估计误差 \(\tilde x=x-\hat x\) 和跟踪误差 \(e=x-\bar x\) 建立 \( \hat x-\bar x=e-\tilde x\) 的关系。
2. 控制律只能使用估计器输出和已发生的观测历史；同一观测历史下所有相容真实状态必须共享同一个实际命令。
3. 构造估计误差管 \(\mathcal E_i\) 与跟踪误差管 \(\mathcal S_i^c\)，推导状态/输入 Pontryagin 收紧。
4. 先采用独立集合外包建立正确性基线，再考虑联合 CZ 保留 \(e,\tilde x\) 相关性以降低保守性。

## 阶段 6：终端条件与递归可行性证明

1. 求非空的共同终端集合 \(\mathcal X_f\) 和共同终端反馈 \(K_f\)，确保它跨所有测量相位不变并满足各相位收紧约束。
2. 验证终端代价下降条件；明确初始名义优化问题可行是递归可行定理的前提。
3. 用最优序列移位并追加终端反馈完成递归可行性证明。
4. 持续有界扰动下证明鲁棒实用稳定/收敛到误差管邻域，不宣称无条件渐近收敛到原点。

## 阶段 7：映射到 12 状态物理 plant，再处理具体飞控接口

只有阶段 1–6 的理论基线闭合后，才：

- 将抽象外环模型和残差集合映射到 12 状态六自由度物理 plant；
- 证明真实闭环轨迹被抽象模型/残差集合覆盖；
- 再选 PX4/ArduPilot 的具体高层命令接口并开展 SITL/HIL；
- 报告模型覆盖、集合包含、硬约束、最坏分支计算时间和实验结果。

## 禁止捷径

不把概率置信区间改写为确定性包含；不把 CZ 后验、估计误差管、跟踪 Tube 和未来可达集混为一谈；不允许控制器对同一观测历史下的隐藏状态分别选择不同输入；不把名义约束满足写成真实硬安全；不把初始可行性、终端不变性或递归可行性当成自动成立；不将旧平面直接控制实验结果移植到当前外环模型。
