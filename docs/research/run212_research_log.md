# Run212：三次位置返包的历史一致速度支持界（2026-10-30）

**基线 main：** `a7c240a085658337f22ed865f0eab1828a01358a`（Run211）。**唯一瓶颈：** Run210 的第192拍独立区间 SMF 速度下端 `-2.4931037251954926 m/s`，是否与过去真实可达控制轨迹的测量历史相容？本轮先构造可严格证明的**历史一致外包支持界**，不声称已构造完整 CZ。

## 1. 代数恒等式及严格外包

冻结四状态 Euler 动力学：`p[k+1]=p[k]+h*v[k]`，`v[k+1]=v[k]+h*a[k]`，`a[k]=-T[k]*phi[k]+r[k]`，`h=1/50`。利用时刻 150、165、180 的位置和 150..190 共41个加速度，消去未知初始速度，得到精确恒等式

```text
v[191] = (5/3)*p[150] - (20/3)*p[165] + 5*p[180]
         + sum_{i=0}^{40} w[i]*a[150+i]
w[i] = h - c15*h^2*(14-i) (i<15)
         - c30*h^2*(29-i) (i<30)
c15=-20/3; c30=5; absent terms are zero.
```

位置测量噪声 `|eta_p|<=1/50 m`，姿态角噪声 `|eta_phi|<=1/200 rad`，扰动 `|r[k]|<=47/25+(243/16000)*T[k]`。对观测 `y_p` 和 `y_phi`，定义

```text
C = (5/3)*y_p[150] - (20/3)*y_p[165] + 5*y_p[180]
    + sum_i w[i]*(-T[i]*y_phi[i])
R = (|5/3|+|20/3|+|5|)*sigma_p
    + sum_i |w[i]|*(T[i]*sigma_phi+rad(T[i]))
v[191] in [C-R, C+R].
```

这是所有满足所选测量、噪声及动力学的轨迹必然满足的**严格有理数外包**。独立放松每个 `phi/r` 的耦合与早期初始约束，只会放大可行集；故此界可能仍保守。它不是精确历史后验、不是完整 CZ 传播，也没有对任意观测序列宣称必然改善。

## 2. Run210 可达历史的复现与结果

在与仓库 Run206/208/210/211 核对的算法镜像中，从冻结初始状态重放 Run210 `positive_high` 策略，完整执行前191拍并在第192拍控制前取状态；按历史测量规则记录150、165、180位置包与150..190每拍姿态观测。所有动作由原两层backup+8拍必要guard选择，非人为拼接状态。

| 量 | 结果 |
|---|---:|
| 真实速度（仅离线核验） | -0.7331640043621591 m/s |
| 原独立盒速度下端 | -2.4931037251954926 m/s |
| 三包历史一致速度下端 | **-2.419767402278826 m/s** |
| 三包历史一致速度上端 | -0.01416327519549249 m/s |
| 严格下端收紧 | **7040287/96000000 m/s ≈ 0.0733363229167 m/s** |

旧独立盒速度下端严格小于这个**对历史一致集合仍然有效的外包下界**，故旧下端确实不可能与该历史中这些位置和姿态观测同时相容。这是对 Run211 “角点可能伪造”的局部严格回答：**含旧速度下端的联合角点必然不相容**，不需要假设其他状态坐标。未证明完整后验是否可生存，也未证明收紧后backup变为可行。真值只用于离线包含核验，算法计算界只使用可观测历史和冻结合同。
