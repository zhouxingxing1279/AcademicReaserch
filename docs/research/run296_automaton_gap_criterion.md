# Run296 — 有限测量自动机的失测间隔判据（理论 Gate T3）
日期：2026-11-03。基准 main: `8486cac146ddabbc30caf6cc2365831167acfed8`。

## 精确定义
有限有向图 G=(Q,E)，初态 q0，边标签为 S（成功接收到**新鲜且可用于当前更新**的观测）或 N（未获得新鲜观测，包括 miss；延迟到达事件是否算 S 必须由时间戳合同单独决定）。只考虑从 q0 可达的状态。每条无限执行路径的连续 N 长度记为 gap。

**命题（已证，图论条件）：** 对所有无限允许路径存在统一有限 gap 上界，当且仅当从 q0 可达的 N-only 子图没有有向环。若无环，则连续 N 边数最多为可达 N-only DAG 中的最长路径长度 H，特别 H<=|Q_reach|-1。证明：若存在可达 N-only 环，先沿可达前缀进入环，再无限重复该环，产生无界 gap；反之，任意长度大于等于 |Q_reach| 的 N-only 路径必重复顶点并形成 N-only 环，矛盾。有限路径上界可用 DAG 最长路精确计算。

**量词与限制：** 命题只认证自动机允许的边路径；若另有公平性、周期终止、时间戳约束、不可无限执行等语义，须先编码进自动机。它不证明 CZ/SMF Equalized Recovery；有限 gap 只是对双积分器有限窗恢复界有用的前提。延迟观测按原时间戳更新时，必须进一步证明时间戳跨度和到达延迟的统一界，不能把 delay 当成当前新鲜 S。

## 与 Run295 结合的条件性推论
对 T>0 的逐轴双积分器，已执行输入已知，逐拍加速度残差绝对值<=a，位置测量噪声<=nu，若所有路径的相邻成功测量时间戳间隔 d 属于 [1,H+1]，且接收延迟为零，则可用两次成功测量构造速度误差界 beta_d=2nu/(dT)+(dT/2)a；两次成功之间失测 h<=H，速度误差<=beta_d+hTa，位置误差<=nu+hT beta_d+(hT)^2 a/2（以第二次成功时刻为恢复锚点）。有限自动机本身不保证初始时刻已有两次成功观测；启动期需要有界初始集合或明确 warm-up。上述误差盒是保守的存在性构造，**不是**自动机相位相关 CZ 后验、固定 observer gains 或周期末 Equalized Recovery 的证明。
