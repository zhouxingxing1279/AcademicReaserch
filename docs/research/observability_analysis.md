# 阶段 5｜只测位置时，何时能辨识六个平移状态？

对[冻结的 ZOH 模型](mathematical_model.md)，已知实际输入、无未知扰动且量测无噪声时，两个**不同生成戳**的完整位置读数就足以确定六个平移状态。主合同从空队列启动，最迟第 5 拍保证拿到这两个戳。有界扰动和噪声下，问题转为这些已交付数据能把相容状态集合限制到多小。以下区分秩、时间覆盖与精度三种结论。

## 1. 在生成时刻构造观测矩阵

令两条读数的生成戳为 \(s<t\le k\)，二者都已在决策拍 \(k\) 交付，\(d=t-s\)。减去由 \(u_s,\ldots,u_{t-1}\) 产生的已知输出
\(\sum_{j=s}^{t-1}C_pA_T^{t-1-j}B_Tu_j\) 后，第二条无噪声读数对 \(x_s\) 的系数为 \(C_pA_T^d\)。两条读数的堆叠矩阵是
\[
\mathcal O_{s,t}=\begin{bmatrix}C_p\\ C_pA_T^d\end{bmatrix}
=\begin{bmatrix}I_3&0\\I_3&dT I_3\end{bmatrix}.
\]
下三行减去上三行即得块对角矩阵，行列式为 \((dT)^3\)。对于全部 \(d\ge1,T>0\)，秩均为 6。由此先恢复 \(x_s\)，再沿已知输入传播到 \(x_k\)。同一戳即使被交付多次也只给秩 3，零读数与没有读数是不同事件。量测同拍交付或乱序交付，只改变何时可用；构造 \(d\) 时取两次**生成**的拍差。

对一般 \(A\)，应按所有可用生成戳构造纵向堆叠的 \(C_pA^{s_i-s_1}\) 并逐允许模式检验。仅凭 \(C_p=[I_3\ 0]\) 无法推得满秩。例如取 \(A=I_6\)，任意多次位置读数对初始速度的列仍全为零。若每戳只收到部分坐标，须把该戳的实际选择行写入矩阵。[一般模型与观测接口](MODEL_CONTRACT.md) · [理论框架 §2.1](THEORY_FRAMEWORK.md)

## 2. 启动、截止与满秩的最早保证

对连续未生成上限 \(M\)、有限延迟上限 \(L\) 且生成必交付的信道，每段 \(M+1\) 个生成时刻至少有一包。到拍 \(k\)，生成时刻不晚于 \(k-L\) 的已生成包均已交付。记 \(Q=2M+L+1\)；当 \(k\ge Q\)，\([k-Q,k-L]\) 内有两个互不相交、长为 \(M+1\) 的连续时段，因此至少有两个已交付的不同戳；其中最新有效戳至多老 \(M+L\) 拍。[有限记忆覆盖引理 §2](proposal/FINITE_MEMORY_THEORY.md)

主合同 \(M=1,L=2\) 给出 \(Q=5\)。下表从空队列启动，取所有可延拓合法前缀的最坏值；秩列按第一节的无噪声条件计算。

| 决策拍 | 此时最少已收到的不同戳数 | 最少观测秩 |
|---|---:|---:|
| 0、1、2 | 0 | 0 |
| 3、4 | 1 | 3 |
| 5 | 2 | 6 |
| 任意 \(k\ge5\)，看最近六格 \([k-5,k]\) | 至少 2 | 6 |

可达的最慢启动为偶数戳未生成、奇数戳均延迟两拍。拍 4 只有戳 1，拍 5 才收到戳 3，因而统一满秩时刻 5 不能提前。**拍 4 可以在秩 3 的记录上通过误差预算**，原因是初始位置与速度已经给了紧先验；“能把误差限制在目标内”和“凭两条输出唯一重建状态”是不同的判定。[启动块末原始/对偶证书](stage4_critique_A/cdc22_reduction_certificate.json)

## 3. 有界误差时能辨识到什么精度

按轴取 \(x^u_0=0,\ x^u_{j+1}=A_Tx^u_j+B_Tu_j\)，从 \(y_j\) 减去 \(C_px^u_j\) 得残差读数 \(\check y_j\)。设 \(\tau=dT,\ H=(k-t)T\)。残差速度在戳 \(t\) 的一个估计为 \((\check y_t-\check y_s)/\tau\)。两端读数误差合计至多 \(2n/\tau\)；端点速度与区间平均速度之差是加速度的加权积分，其绝对值至多 \(a\tau/2\)。从 \(t\) 再传播 \(H\) 秒，加回已知输入响应，可得逐坐标半宽上界
\[
\beta_d=\frac{2n}{dT}+\frac{adT}{2},\qquad
r_v=\beta_d+aH,\qquad r_p=n+H\beta_d+\frac{aH^2}{2}.
\]
位置中心取 \(p_k^u+\check y_t+H(\check y_t-\check y_s)/\tau\)，速度中心取 \(v_k^u+(\check y_t-\check y_s)/\tau\)。这是两戳给出的外包，可用于界定后验的坐标半宽。若要求代表点属于完整后验，应另外在后验内选点。单轴平面紧凸后验可取两个坐标区间中点；三轴乘积可逐轴组合。只知一般六维集合的各坐标范围时，将各中点拼接后的可行性需要另证。[两戳推导 §3–4](proposal/FINITE_MEMORY_THEORY.md) · [平面代表点证明 §4](stage4_critique_A/CDC22_REDUCTION.md)

两个合法读数也能隐藏非零速度差。例如单轴 \(p_0=0,\ v_0=\pm1/100\) m/s，\(u=w=0\)。两条轨迹在拍 0 都给零读数；拍 1 的真实位置为 \(\pm1/200\) m，各自取相反的允许量测误差即可再次给零。其余两轴取零，就得到完整六维合同中的不可区分对。无论选择哪一个共同速度估计，这两条轨迹中至少一条在拍 1 的速度误差达到 \(1/100\) m/s。

**六格和七格的区别可直接验算。** 对 \(k\ge6\)，在每种允许的生成模式内，对已到期的戳对使用上式，各坐标分别取最紧界，再跨模式取最坏。六格窗口有四个已到期候选戳、8 种生成模式；七格有五个、13 种模式。位置和速度最坏半宽分别为六格的 \(13/200\) m、\(11/200\) m/s 与七格的 \(3/50\) m、\(31/600\) m/s。已有不可区分轨迹与第 8 拍证书给出相应下界。七格是固定原始时间窗达成所登记块末目标的最短长度；六格已能在理想情形保证满秩，但其最坏速度半宽 \(0.055\) m/s 高于目标 \(0.0525\) m/s。[紧性证明及信息限制](stage4_critique_A/PACKET_MEMORY_RESULT.md)

## 4. 适用边界与复算

**与 B26 的采样数对照。** Baranowski v1 第 3–6 页问：在一个给定时刻，能否从连续历史中选出若干标量读数，达到使用整段历史的最坏精度？本项目问：对每条允许的到包历史，只保留最近若干生成格内已交付的三维位置包，能否达到预定的块末位置、速度半宽？七格指 \([k-6,k]\) 的七个候选生成时刻，最老包龄为六拍。两项结论分别以可选样本数和固定窗口长度计量；峰值存储还要计入摘要和在途处理。[B26 定理 1 及命题 3 核读](../literature/PAPER_READING_LOG.md#b26-v1)

**本项目反例：零量测噪声也可能有传播误差。** 取空队列、零初态和零命令，偶数戳未生成，奇数戳均延迟两拍。拍 5 收齐的只有戳 1 和 3，两条位置读数均为零。一轴在拍 3 前取 \(w=0\)，此后两条轨迹分别取 \(w_3=w_4=+1/50\) 和 \(w_3=w_4=-1/50\) m/s²，另两轴始终为零。由两步 ZOH 得该轴 \((p_5,v_5)\) 分别为 \((1/100,1/50)\) 和 \((-1/100,-1/50)\)（m，m/s）。任一同历史估计的最坏速度误差至少为 \(1/50\) m/s。两戳在理想模型中满秩，但 B26 式 (10) 以量测噪声为唯一未知误差；令 \(\delta=0\) 所得的零半径只适用于其动力学条件。这里漏计的误差来自最新可见戳之后的过程扰动。拍 5 是块内拍，块末精度仍按第三节的证书核对。

若允许任意长时间收不到新的有效戳，取同一初态、零命令，在该段分别施加恒定 \(+a\) 和 \(-a\)。长度为 \(h\) 拍时，两条轨迹速度差为 \(2ahT\)，位置差为 \(a(hT)^2\)。在开放的估计模型中，这排除了与 \(h\) 无关的统一有限误差半径；用待验证的状态安全约束截断这些轨迹会改变问题。对于十二状态物理对象，位置对姿态、角速度的辨识还取决于刚体动力学、激励与低层输入，以上行列式仅对应六个平移状态。

启动表也可独立复算。以下代码枚举到第 5 拍的可延拓词；最后两个断言核查同到与严格越界，在有理数下核查已知输入的位移是另一项独立的矩阵检查。

~~~python
from itertools import product

def delivered(word, k):
    return {s for s, lag in enumerate(word) if lag >= 0 and s + lag <= k}

words = [w for w in product((-1, 0, 1, 2), repeat=6)
         if all(pair != (-1, -1) for pair in zip(w, w[1:]))]
minimum = [min(len(delivered(w, k)) for w in words) for k in range(6)]
assert minimum == [0, 0, 0, 1, 1, 2]
assert delivered((0, 0, 0, 1, 0), 4) == {0, 1, 2, 3, 4}
late = (0, 0, 0, 2, 0, -1)
assert 3 not in delivered(late, 4) and 3 in delivered(late, 5)
~~~
