## 唯一证明义务：success/miss/delay 的到达约束是否足以推出速度误差有界？

考虑每个坐标独立的离散 Euler 常速度模型（不是含半步加速度项的精确零阶保持模型）：

```text
p[k+1] = p[k] + T v[k]
v[k+1] = v[k] + T a[k],   |a[k]| <= a_bar
y[t]   = p[t] + n[t],      |n[t]| <= nu_bar
```

假设两个**不同生成时间戳** `t` 和 `t+d` 的位置量测都已经到达，`d>=1`，`T>0`，且对应控制引起的已知位置增量已经被扣除（若未扣除，则不能使用以下公式）。设 `z[t]` 表示扣除已知输入响应后的位置量测。

### 引理 1（有限差分速度包含；解析已证）

```text
vhat[t] = (z[t+d]-z[t])/(d*T)
|vhat[t]-v[t]| <= 2*nu_bar/(d*T) + (d-1)*T*a_bar/2
```

证明：展开 `p[t+d]-p[t] = d*T*v[t] + T^2*sum_{j=0}^{d-2}(d-1-j)*a[t+j]`；两端测量噪声差至多 `2*nu_bar`。对每个坐标取三角不等式，`sum_{r=1}^{d-1}r=d(d-1)/2`，即得。该上界在各加速度与两端噪声允许独立取盒顶点时可取到。若需当前速度 `v[k]`，还必须从 `t` 前推至 `k`，额外计入 `(k-t)*T*a_bar`（以及已知输入响应），不能把历史速度界直接当作当前误差管。

注：原 THEORY_FRAMEWORK.md 使用 `d*T*a_bar/2` 是此 Euler 合同下的**保守**上界，并非错误；上述是更紧的 Euler 专用表达。若采用 `p+=Tv+0.5*T²a`，对应系数改为 `d*T*a_bar/2`，须按离散化合同选用。

### 反例 1（有界连续 miss 不等于有界时间戳年龄；解析成立）

令接收器每拍都收到一个标为 success 的位置数据包，但它们全都带相同历史时间戳 `t=0`，或者只重发有限个旧时间戳。即使到达序列的最大连续 miss 数为零，`k-t` 仍无界。选择两条共享同一历史观测与所有接收数据的轨迹，`a[k]=+a_bar` 与 `a[k]=-a_bar`（`a_bar>0`），其当前速度差随 `2*k*T*a_bar` 增长。因此**仅约束包到达频率不能推出无限时域统一有限的速度估计误差**。要获得这样的结论，必须增加生成时间戳新鲜度/最大信息年龄及足够多不同时间戳的有效量测，或者引入独立的速度/状态硬界等其他假设。

### 条件 2（候选自动机合同，尚未证明足以闭合全部 Gate T3）

对所有允许的接收历史 `h_k`，要求存在不晚于 `k` 的两个**已收到且时间戳不同**的位置观测 `t_1<t_2<=k`，满足 `1<=t_2-t_1<=D`、`0<=k-t_2<=H`；`D,H` 是固定整数。则有限差分 + 前推给出当前速度的一个统一有限外包（可取所有 `1<=d<=D` 的上界最大值，再加 `(H+D)T*a_bar` 作为保守传播余量）。该条件只说明**存在有限误差外包**，尚不保证其小到能满足状态/输入收紧、Equalized Recovery 或共同终端不变性。

必须明确量测时间戳和**接收时间**：延迟包应先约束其生成时刻，再通过已知命令及有界扰动传播到当前；不得用延迟位置直接更新当前状态。

## 可复现有限顶点核对（已实际在独立 Python 3 环境运行）

参数：`T=0.1, a_bar=0.2, nu_bar=0.05`；`d=1,...,6`；逐一枚举 `2^d` 个加速度顶点和四种端点噪声组合；初始 `p=v=0`，已知输入为零。核对每个 `d` 的最大有限差分误差与引理右端。

```python
import itertools
T, a_bar, nu_bar = 0.1, 0.2, 0.05
for d in range(1, 7):
    worst = 0.0
    for acc in itertools.product((-a_bar, a_bar), repeat=d):
        for n0, n1 in itertools.product((-nu_bar, nu_bar), repeat=2):
            p = v = 0.0
            for a in acc:
                p += T*v
                v += T*a
            worst = max(worst, abs((p+n1-n0)/(d*T)))
    bound = 2*nu_bar/(d*T) + (d-1)*T*a_bar/2
    assert abs(worst-bound) < 1e-10
    print(d, round(worst, 12))
```

实际输出：`(1,1.0), (2,0.51), (3,0.353333333333), (4,0.28), (5,0.24), (6,0.216666666667)`；全部断言通过。此为**有限顶点核对**，不是完整有限自动机穷举、CZ 后验验证或四旋翼仿真。未执行仓库 CI。
