## 1. 新增真实论文：Lee、Leok、McClamroch的几何鲁棒跟踪

**题名：** *Nonlinear Robust Tracking Control of a Quadrotor UAV on SE(3)*。**作者：** Taeyoung Lee, Melvin Leok, N. Harris McClamroch。**正式发表：** *Asian Journal of Control*, 15(2):391–408 (2013)，2012-07-05在线，DOI https://doi.org/10.1002/asjc.567 。**实际阅读版本：** 2011-09-21公开arXiv:1109.4457v1，https://arxiv.org/pdf/1109.4457 ，本轮核对预印本PDF pp.1–6，§II动力学式(1)–(6)、§III姿态模式Propositions 1–2、§IV位置模式式(20)–(39)/Propositions 3–4、§V数值例子；**分节已读**，没有将2013期刊终版逐式核验或附录全文阅读伪称完成。期刊元数据来自 https://onlinelibrary.wiley.com/doi/abs/10.1002/asjc.567 。

**实际物理状态和输入：** 配置空间`SE(3)`；平移`x∈R³,v∈R³`、姿态`R∈SO(3)`、角速率`Ω∈R³`，局部共**12个独立状态坐标**（三平移＋三旋转自由度，不能把旋转矩阵9元素误作9个独立姿态自由度）。输入为总推力幅值`f`和三轴机体系力矩`M∈R³`，式(1)给出4个桨推力与`(f,M)`的混控映射；连续真值式(2)–(5)为`xdot=v, m vdot=m g e3-f R e3+Δx, Rdot=R Ωhat, J Ωdot+Ω×JΩ=M+ΔR`。姿态模式可仅使用`(R,Ω)`的6维局部旋转子系统，位置模式保留耦合全动力学。直接控制各桨推力、瞬时混控和已知`||Δx||≤δx, ||ΔR||≤δR`为假设；论文没有仓库的推力相关残差函数`R_z(T)`。

**实际观测/滤波：** §III/IV反馈显式使用`R,Ω,x,v`；未给有噪位置-only测量矩阵、失测/延迟模型、SMF/CZ状态或参数估计器。文中的“output tracking”是输出**跟踪目标**，**不是**在隐藏速度下的输出反馈估计器。**控制/约束：** 连续时间非线性几何反馈/姿态—位置模式切换，不是MPC/Tube MPC；Propositions 2–4在初始姿态误差、增益与有界扰动等前提下证明跟踪误差uniform ultimate boundedness，**没有**本仓库`T∈[4.905,14.715]`、`|τ|≤0.08`及全部状态硬盒的递归可行或约束保持定理；混控映射不等于已认证桨电机饱和。**实验：** §V为椭圆螺旋轨迹与倒置初态悬停恢复的数值仿真，未核验实飞/实时求解时延；不能将其小跟踪误差等同于本仓库鲁棒硬安全。

**迁移价值：** 其位置模式明确保留`fRe3`推力方向耦合，支持六状态平面`T cosφ`建模的物理必要性；姿态/位置模式的分工为分层架构提供经典依据，但需要独立认证内环误差界、执行器饱和和外环可生存核。既有四旋翼鲁棒跟踪和姿态/位置分层控制已成熟，不能作为本硕士课题“首次提出”的创新点。

## 2. 仓库六状态的严格一拍垂向信息状态必要条件（本轮独立推导）

仅对`configs/planar_baseline.json`定义的**离散Euler真值**成立；`h=1/50, g=981/100, T∈[4.905,14.715]`，`|φ|≤0.45`，`v_z^+=v_z+h[T cosφ-g+r_z]`，`|r_z|≤a+bT`，`a=1043/500=2.086`、`b=81/800=0.10125`。此处`r_z`是施加实际T后的对抗残差；每拍控制先于扰动。

**单个隐藏状态的必要前驱筛选：** 令垂向速度硬界`V=3`，要求对全部合法`r_z`下一拍仍`-V≤v_z^+≤V`，则同一个T必须满足
```text
T(cosφ-b) ≥ g+a + (-V-v_z)/h
T(cosφ+b) ≤ g-a + ( V-v_z)/h
T∈[4.905,14.715]
```
且位置Euler运动学另要求`p_z+h v_z∈[0.5,3.5]`。以上仅是垂向一拍必要筛选，非六状态充分可生存证明；横向、姿态、力矩与未来后继仍需检验。

**倾角边界的严格有理数筛选：** 在`v_z=-3`、最坏向下扰动下，最大可用向上加速度`a_up=Tmax(cosφ-b)-(g+a)`。`cosφ`在`|φ|≤0.45`上可用交错Taylor上下界`1-φ²/2+φ⁴/24-φ⁶/720 ≤ cosφ ≤ 1-φ²/2+φ⁴/24`。精确Fraction算得`|φ|=0.40`时`a_up∈[0.167518538,0.16760225]`（向上权限必要检查通过）；`|φ|=0.43`时`a_up∈[-0.0104631692261,-0.01033397636875]`，即使最大T也不能避免`v_z`下边界下一拍越界。故原硬倾角域包含一步不可生存区域，真实阈值介于0.40和0.43rad；这**不是**最优多步可生存倾角域。背景第6轮0.45rad反例继续成立。

**共享因果控制比逐个状态可控更严格：** 在`φ=0,p_z=2`、相同位置/姿态读数但隐藏垂向速度分别为`-3,+3`的候选信息纤维上，若同一T必须覆盖两状态及各自全部合法扰动，则`T≥(g+a)/(1-b)=47584/3595≈13.2361613352`且`T≤(g-a)/(1+b)=30896/4405≈7.0138479001`，**严格无交集**。两个状态单独各有合法一拍推力，合在同一观测纤维却无共享一拍安全动作。它是**候选信息状态反例**，不声称该极端纤维从仓库初始盒真实可达。

更一般地，对相同`φ=0`、隐藏速度对称`v_z=±q`，消去共同T得到**一拍共享鲁棒可行的充要阈值**（仅垂向速度约束，且`T=g`在合法输入域）：
`q≤V-h(a+bg)=11753659/4000000=2.93841475m/s`。当满足时共同`T=g`确实使两端下一拍都在`[-3,3]`；超过阈值时任意共享T均失败。若`p_z=2`，一拍位置仍在高度硬界内。该条件**不能**直接用于Run253的特定后验，因为其垂向速度纤维未被六状态可达性核验；也不意味着直径1.339m/s的Run252横向纤维有问题。

**计算核验：** 隔离容器Python 3，标准库`fractions.Fraction`，逐项断言推力上下界冲突、阈值精确值及0.40/0.43rad的Taylor上下界符号，输出`ALL_4_EXACT_ASSERTIONS_PASSED`。这仅认证上述代数/一拍模型合同；未运行全仓库控制回归、无新SMF后验或闭环算法。

## 3. 选型、硕士可行性及分工

- **条件性首选**：六状态平面`(p_x,p_z,v_x,v_z,φ,ω)`、双输入`(T,τ)`，其物理耦合闭合且可做局部可生存信息域筛选；但目前仅有必要条件/反例，没有六状态SMF+MPC控制器。
- **现成实现基线**：四状态固定T横向—姿态Run249有限55拍安全、Run253有限双轨迹桥接；它们不保证高度、不证明无限递归可行。
- **低风险备选**：2状态姿态；**延后**10/12状态与分层全模型，除非六状态局部信息核证失败或出现新的测量/算力证据。
- **创新边界**：Lee等已有全几何鲁棒跟踪、分层飞行模式；潜在硕士贡献应是间歇有噪位置SMF/CZ与共享因果鲁棒MPC、终端信息可生存域或明确有限时域安全过滤。**风险**：完整后验闭合、无限时域安全、20ms WCET仍未证；主任务Run253 Gate A blocked。若不能闭合，应收敛到有清楚条件的有限时域保证。

**下一轮唯一优先问题：** 将上述六状态垂向共享推力前驱条件作用于**仓库hover初始SMF盒与一次success/miss后验**，核验是否存在非空、对实际有噪观测可实现的局部信息状态内近似；只做模型可行性/证据审计，不与主任务重复构建控制器。
