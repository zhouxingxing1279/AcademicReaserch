- **估计器/优化**：式(5)是基于固定观测增益M的**点状态估计/二阶矩传播**，不是状态SMF/CZ或参数SMF；式(6)将未来控制写成收到的创新项的仿射因果函数，离线固定K/M，在线优化偏置与创新反馈增益。式(23)是凸矩约束/LMI的随机输出反馈MPC。
- **实际约束**：§2式(2)和§5式(22)–(23)约束的是**折扣二阶矩期望和** `sum beta^k E(||H x_k||^2) <= epsilon`，并非对每条轨迹强制`x∈X`或`u∈U`的逐拍硬盒；文中未提供本项目的物理推力/力矩饱和、执行器动态或硬速度/位置/姿态约束。不能因论文称“constraint satisfaction”就误写为硬约束安全。
- **重要定理/假设**：Assumption 1要求(A,B)可稳定、(A,C)可检测；Assumption 2假设已知且不变的成功率lambda；Assumption 3要求`A+BK`渐近稳定及随机观测误差动力学均方稳定。Theorem 7在初始(23)可行和上述设定下，利用候选策略移位与预算`mu_k`更新，保证**随机MPC优化递归可行及折扣期望约束(27)**。Theorem 9在额外矩有界、折扣因子和常数条件下给出**长期平均期望代价有限上界**，不是逐路径鲁棒不变集、渐近硬安全或本仓库20ms WCET。
- **实验/局限**：§9仿真双倒立摆，`N=5`、`lambda=0.6`、`beta=0.8`；Monte Carlo与LQG比较，未做无人机实飞。论文已经研究“间歇观测+输出反馈MPC”，因此不能把该词组本身写成创新。其概率合同不能代替本项目有界扰动/硬输入和确定性丢包合同。
- **可复用**：信息因果性、测量到达指示变量、优化控制策略移位的证明结构；仅可作为随机性能对照，不得移植其期望约束为确定性安全证明。**待查**：是否存在对最多连续2次丢包、带硬状态/输入约束、且保留噪声一致信息集合的输出反馈MPC递归安全定理？

## 3. 独立精确数学审计（不是论文定理）
- 在论文§9的`lambda=3/5`且每个位置机会独立的假设下，`q=1-lambda=2/5`，三个连续miss的概率 `q^3=8/125=0.064>0`。
- 取100组互不重叠的3次观测机会，至少一组全miss的概率为 `1-(1-8/125)^100≈0.998658517925`；随着组数趋于无穷，该概率趋于1。因此对任何`0<lambda<1`，i.i.d. Bernoulli模型**不能保证**“所有历史最多连续丢2包”。反过来，仓库的有界失测自动机也不等于i.i.d.随机模型，不能直接套用论文的概率权重/均方稳定条件。
- 复核命令（无新脚本）：`python3 - <<'PY'`；`from fractions import Fraction; p=Fraction(3,5); q=1-p; assert q**3==Fraction(8,125); assert 0<(1-q**3)**100<1; print(float(1-(1-q**3)**100))`；`PY`。Python3本地**2/2精确Fraction断言通过**，输出`0.998658517925`（显示12位）。该结果仅审计**概率模型差异**，不是任何SMF、MPC、六状态控制或终端安全测试。
- 另外，若噪声采用论文数值例的非退化Gaussian，任何有限硬误差盒外的概率一般大于0；期望二阶矩约束不能推导所有样本路径的确定性包含。
