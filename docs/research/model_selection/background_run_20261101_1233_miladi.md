# 背景研究第3轮：Miladi等(2020)仅测位置与角度的四旋翼观测器＋ENMPC（2026-11-01）

**基准main：** `b185569480e72d6ebb3c6a147755feacd954b20c`。**唯一问题：** 是否已有四旋翼论文仅用位置与角度观测、隐藏线/角速度而执行输出反馈MPC？其假设是否覆盖本仓库位置丢包、状态SMF和硬安全？

## 2. 实际模型、观测和控制权限

- **物理模型：** Newton–Euler四旋翼12状态，6个角度/位置分量和对应的6个线/角速度；文中按成对顺序 `X=(φ,φdot,θ,θdot,ψ,ψdot,z,zdot,x,xdot,y,ydot)`，不是6状态平面模型。式(1)的仿射非线性动力学含陀螺耦合、重力、旋翼推力/力矩及6维外部气动力/气动力矩。
- **控制输入：** `u=(U1,U2,U3,U4)`，`U1`为总推力，`U2–U4`为姿态力矩相关通道；论文追踪输出 `Y_t=(x,y,z,ψ)`，不应把四个受控输出误认为四个状态。
- **传感器输出：** §2明写 `Y=(φ,θ,ψ,z,x,y)=(x1,x3,x5,x7,x9,x11)`，**只测3个姿态角＋3个位置**，6个线/角速度均不直接测。其量测是连续可用的角度和位置；正文未给出本仓库“位置每5拍机会、最多连续2包miss”的网络模型，也未给出可直接复用的有界测量噪声条带和success/miss信息状态。
- **估计器：** 级联高增益近似微分器＋一阶滑模未知输入观测器，重构状态和外部扰动；**不是SMF/CZ集合状态后验**。§4将非线性项和扰动合为未知输入，因原`rank(CD)!=rank(D)`，引入辅助输出满足匹配条件。Assumption A1要求角速度有界，A2要求扰动有界且相对观测器变化缓慢（`d_dot≈0`）。
- **MPC/约束：** ENMPC使用输出Taylor展开构造解析控制式(9)/(18)，加入输入盒后Proposition 2把四输入的控制更新改写为在线凸QP式(35)，`u_min<=u<=u_max`。论文此处主要处理**输入约束**，没有给出本仓库全部状态硬界、每条对抗扰动/丢包路径的Tube收紧或集合终端递归可行证书。Remark 1说约束QP需在线求解，故“explicit”不能被误读成任何情况下都不在线优化。
- **理论保证：** Proposition 1在A1–A2及高增益/滑模观测器条件下给出跟踪误差趋入可调小紧集的**实际收敛/有界**结论；附录用`V=z^TPz`及估计误差界推导，**不是逐拍硬安全、无限时域输出反馈MPC递归可行或全局渐近零误差**。
- **实验：** §6使用m=0.468kg的12状态四旋翼数值模型，螺旋参考轨迹及在10/15/20s施加的分段气动力扰动；为数值仿真，未核验实飞、位置丢包实验、20ms WCET或完整硬约束统计。

## 3. 与仓库模型及最新Run249的实质比较

| 问题 | Miladi等(2020) | 仓库Run249及六状态候选 |
|---|---|---|
| 速度是否测量 | 不测，观测器估计 | 不测，SMF后验可靠包含 |
| 位置测量 | 连续可用，未设丢包自动机 | 每5拍一次机会，最多连续丢2包 |
| 角度/角速率 | 角度可测、角速率估计 | φ与ω每拍有噪可测 |
| 模型 | 12状态3D刚体，4输入 | Run249四状态冻结T、六状态平面双输入候选 |
| 估计 | 高增益＋滑模点估计/未知输入 | 有界扰动下区间SMF/CZ集合估计 |
| 约束/终端 | 输入QP、实用跟踪收敛；未核验硬状态终端证书 | Run249只证明固定55拍安全，无无限终端闭合 |

**重要创新性纠偏：** “四旋翼＋仅测位置/姿态＋隐藏速度＋输出反馈MPC”**2020年前已存在**，不能据此主张创新。剩余待检验的具体差异是：**有界噪声和间歇位置success/miss下，关联状态SMF/CZ如何驱动共享因果MPC，并形成硬约束终端/安全保证**。Miladi不证明这些性质，不能把其收敛结论移植到仓库的对抗扰动模型。

**对模型选型：** 这篇12状态工作说明高维观测器＋MPC可以研究，但不代表硕士必须做12状态。六状态平面模型仍为条件性物理首选，四状态Run249是目前真正可运行的55拍有限安全基线，姿态2状态是已证递归可行的保底。Run249平均单步求解约31.65ms，超过20ms目标；扩大维数前应先解决因果终端与计算预算。

## 4. 评估与唯一下一轮问题

**可行性：** 仅位置＋角度观测本身在已有文献中有先例；带丢包SMF硬安全终端仍未证明。**创新性：** 不在输出反馈或未测速度本身，而可能在有界集合后验＋丢包信息状态＋安全前驱的连接，须与现有安全游戏/Tube MPC文献比较。**难度：** 六状态双输入且残差大，仍为中高；12状态不是当前合理首个证明对象。

**下一轮唯一优先问题：** 找到并逐式核验一篇**含明确位置丢包/延迟或不规则观测时序的四旋翼MPC/估计文献**，确认其是否有硬约束与递归可行证书；优先GPS丢包＋IMU观测，避免将“只测位置”误当“间歇位置测量”。
