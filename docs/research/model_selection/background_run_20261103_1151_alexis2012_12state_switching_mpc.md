## 2. 物理模型：12状态、6物理自由度

原文式(3)状态：X=[φ,φdot,θ,θdot,ψ,ψdot,z,zdot,x,xdot,y,ydot]^T。

它描述三个平移自由度和三个转动自由度；状态维数12不代表12个物理自由度。模型采用刚体对称、质心与机体系原点重合、桨推力/阻力矩与转速平方成比例。坐标含地固系平移位置和速度、Euler角及Euler角速；式(1)明确将Euler角速转换到机体系角速度p,q,r。式(3)包含转子陀螺项J_r Ω_r和外扰加性项。小速度假设用于姿态/平移模型解耦。

本课题此前暂定状态顺序x=(p_I[3],v_I[3],η_ZYX[3],ω_B[3])。它与原文12维plant在物理自由度上等价，但坐标不完全相同：本课题用机体系角速度ω_B，必须采用Euler运动学矩阵dot(η)=E(η)ω_B，不能直接把机体系角速度当Euler角速度。

## 3. 输入与四电机映射

原文式(4)：
- U1=b(Ω1²+Ω2²+Ω3²+Ω4²)：总推力；
- U2=b(−Ω2²+Ω4²)、U3=b(Ω1²−Ω3²)：滚转/俯仰力矩通道；
- U4=d(−Ω1²+Ω2²−Ω3²+Ω4²)：偏航力矩通道；
- Ωr=−Ω1+Ω2−Ω3+Ω4：四桨残余转速组合，进入转子陀螺项。

因此U向量含5个派生量，但只有4个实际电机转速。Ωr不是第五个独立执行器。姿态MPC的输入列为[δU1,δU2,δU3,δU4,δΩr]；高度MPC只用δU1；水平MPC使用虚拟水平输入(ux,uy)。论文按通道给出区间/变化率限制；本轮未找到五维输入与四电机转速之间完整的联合非线性可行像集证明。

对本课题的直接结论：若控制输入选wrench w=[T,τx,τy,τz]^T，必须把实际电机约束写成W={Gf:f_min≤f≤f_max}，G为明确的旋翼布局/旋向混控矩阵；G可逆时可写f_min≤G^{-1}w≤f_max。独立矩形wrench盒不是一般情况下的真实四电机可行域。也可直接用四桨推力f作为优化输入，再通过B_wrench G建模。

## 4. MPC架构、传感器和实飞证据

论文提出Switching MPC（SMPC，此处不是stochastic MPC）。12状态非线性plant拆为：
- 姿态：10维积分增广PWA模型、9个工作区；
- 高度：3状态、2个工作区；
- 水平平移：6状态线性模型。

每个PWA模型在不同操作点局部线性化，按当前估计状态与工作点的距离选择控制器；Np=5、Nc=2；姿态更新120Hz (Ts=0.0083s)，高度/水平更新约33Hz (Ts=0.03s)。目标函数包含跟踪状态误差、控制变化率、输入误差二次项。状态/输入/输入变化率为约束，风阵最大影响由实验测量后作为加性扰动界。CPU为Atom Z530 1.6GHz、2GB；未报告独立可核验的最坏QP求解时间。

传感器：Xsens MTi-G IMU、Maxbotix EZ1 sonar、Tam2 16×16 optic-flow视觉芯片；用EKF和坐标修正EKF融合。无GPS和外部定位相机，室内定位由sonar+optic flow实现。没有位置success/miss自动机、最长连续失测、SMF/CZ状态后验。

真实UPATcopter约1.1kg；臂长0.21m，惯量Jxx=Jyy=0.0196、Jzz=0.0264 kg·m²，转子惯量Jr=8.5e−4 kg·m²。真实飞行覆盖位置保持、轨迹、悬停、风阵和姿态机动；作者报告水平位置保持通常在半径0.15m内，姿态MSE在风阵下仍可接受。

## 5. 关键理论边界

论文原文明确承认：多个PWA模型切换时，不能保证原非线性系统的稳定性；作者只报告在所做实验中没有观察到稳定性问题。因此：
1. 该论文是12状态6-DOF四旋翼MPC实飞先例；
2. 它不是统一12状态LTI Tube MPC；
3. 它没有SMF/CZ；
4. 它没有输出反馈递归可行/终端信息RCI定理；
5. 实飞表现不等于硬约束全扰动保证。

## 6. 对硕士课题的模型选择影响

尊重用户的毕业仿真需求：12状态完整六自由度非线性plant作为主仿真对象。推荐先在悬停附近构造单工作点12状态线性Tube MPC，并在12状态非线性plant上闭环验证；所有鲁棒保证限制在明示姿态/速度/输入包线内。若后续扩展多工作点PWA，必须额外证明切换一致Lyapunov/共同终端条件，不能照搬实验未见不稳。

四状态冻结推力保留为历史数学基线，六状态平面模型保留为降阶/鲁棒证明对照。12状态升级是用户研究范围与毕业交付要求驱动，不表示其可证明性成熟度高于六状态。

对Tube误差模型，若名义状态z、实际状态x、估计值xhat，令e=x−z、ε=x−xhat，实际控制u=v+K(xhat−z)，离散加性误差模型下：
e⁺ = (A+BK)e + w − BK ε。
w必须覆盖外扰、参数误差、非线性离散残差、ZOH误差和有界执行器误差；若SMF给出可靠ε∈S，则需验证：
(A+BK)E ⊕ W ⊕ (−BK S) ⊆ E。
该包含关系只是候选RPI条件，尚未构造数值E或证明终端递归可行。
