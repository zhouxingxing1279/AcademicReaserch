## 三种接口不可共用一个未辨识的 A/B
令外环真实平移状态 `x=[p_x,p_y,p_z,v_x,v_y,v_z]^T`。位置参考 `r=p_ref` 的候选辨识式 `x[k+1]=A_cl x[k]+B_cl r[k]+w[k]` 仅在固定飞控版本、固定模式、局部包线、给定参考更新周期和零阶保持下成立；若位置控制器积分器、限速器、前馈、轨迹整形器或内环状态使 x 非 Markov，必须增加**最少必要的闭环状态**或使用有记忆输入输出模型。六维不是先验精确阶数。

加速度参考 `a_ref` 的理想离散双积分式（零阶保持）
`p+=p+h v+(h²/2)(a_ref+e_a+d), v+=v+h(a_ref+e_a+d)`，要求在整个研究包线、每个允许参考序列和失测模式下 `e_a∈E_a` 有效；不能仅凭 PX4 接口支持就认定这一界。速度参考 `v_ref` 应另辨识速度闭环，不能把速度参考等同于真实速度。

若指令延迟固定为 d 个外环采样周期，正确模型需包含过去 d 个参考的移位寄存器，或使用具有历史输入的预测模型；不应将确定性延迟在没有证明的情况下直接塞入独立每拍的常数扰动盒。若延迟变化，则须以模式/集合不确定性处理。PX4 的速度/加速度前馈和位置优先级须固定具体消息 NaN 字段与固件版本后审计。

## Tube/SMF/CZ 安全合同（待验证）
在确有统一加性残差集合 W 的前提下，`X^-_{k+1}=A_cl X_k ⊕ B_cl {r_k} ⊕ W`。成功接收原始位置 `y=Cx+n, n∈V` 时 `X_{k+1}=X^-_{k+1}∩{x:y-Cx∈V}`；丢包时 `X_{k+1}=X^-_{k+1}`。若使用 PX4 EKF 输出，必须有**包含真实状态的联合误差合同**，不能把 EKF 协方差当确定性集合，不能把 EKF 与其已融合的 GNSS 当独立观测。

对于名义反馈 `r=\bar r+K(x-\bar x)`，只有**真实 x 可用**时，常规误差 `e^+=(A+BK)e+w` 才直接成立；位置间歇测量且 x 不可用时，不能在证明中偷偷使用真值反馈。应改为因果可实现的估计/集合反馈，明确同一观测纤维使用同一指令，并为估计误差、控制误差构造联合不变集合；终端可行性必须覆盖 success/miss 模式图。状态约束 `\bar X⊕E⊆X_safe` 与参考约束 `\bar U⊕KE⊆U_cmd` 只有在上述误差集合确实鲁棒正不变时才能声称硬安全。
