## 3. 模型、真实输入、量测与MPC

- **真实四旋翼6自由度/优化16维**：连续刚体模型为`p∈R³, v∈R³, η=(roll,pitch,yaw)∈R³, ω∈R³`，再加入4个逐桨推力状态`γ=(f1,f2,f3,f4)∈R⁴`，得到`x=[p3,v3,η3,ω3,γ4]∈R16`。物理自由度仍为6，不是16自由度。采用Euler 3-2-1最小姿态参数（俯仰±90°奇异，实验主动避开），连续模型用固定步长RK4离散；不是悬停LTI/四状态固定T模型。忽略旋翼陀螺、blade flapping及rotor-induced drag等效应（§2.1）。
- **实际执行链**：每桨`f_i=c_f w_i²`、`[F_body;τ_body]=Gγ`，标准单向推力四旋翼`rank(G)=4`且力方向仅机体系z轴。NMPC优化输入是`u=dot γ=(dot f1,...,dot f4)`，不是直接的总推力/三轴力矩，也不是PWM。将`dot γ`积分后反算转速命令`w_i=sqrt(f_i/c_f)`，经串行通信发送机载ESC转速闭环；每桨推力非负、上限和变化率由实测电机/ESC辨识。§2.2.1通过多转速斜坡测试、力跟踪误差阈值与插值获得状态相关的`dot f`上下限；其阈值为工程辨识准则，**不是所有扰动下的硬误差上界证明**。
- **OCP约束**：§3式(26)显式`γ_min≤γ_h≤γ_max`，式(27)显式`dotγ_min(h)≤u_h≤dotγ_max(h)`；成本跟踪`p,v,a,η,ω,dotω`与终端二次惩罚；没有为物理位置/姿态硬盒提供鲁棒收紧。**关键限制**：式(33)–(34)为保留QP线性约束，沿预测域用外部`tilde f`计算变化率边界；§4.1.1式(40)实验直接取`tilde f_{i,k+h}=f_{i,k}`常值，而非每个未来预测桨推力处的严格状态相关边界。另§3为实践求解使用slack软化略收紧约束，并承认未证明严格闭环稳定性和正式递归可行性；**优化中有物理来源约束≠实际全时域硬约束保证**。
- **MPC实现**：全耦合NMPC，multiple-shooting + RTI单次SQP + partial sensitivity update + dense QP/qpOASES；MATMPC/CasADi/RK4。预测域`t_H=1s,N=10,T_pred=0.1s`，而**控制更新频率>200Hz**（两种周期不可混淆）。四旋翼平均求解时间3.5ms，地面站Intel i7-6700HQ/Ubuntu16.04；**没有20ms最坏执行时间/WCET证明**，超时采用上一轮预测输入的下一项备份。
- **真实量测**：MoCap给位置与姿态、陀螺仪给角速度、ESC测速；线速度由动捕多样本最小二乘拟合求得，桨力由测得转速和推力系数换算；加速度计因噪声偏置而未用于速度融合。作者视为完整状态可测，**无SMF/CZ、无位置丢包、无隐藏速度可靠后验、无确定性测量误差合同**。机载ESC不等于全控制器板载执行；NMPC在地面站，经串行线通信。
- **真实四旋翼实飞**：§4.2横向chirp和突然位置阶跃；chirp中横向峰值加速度5.85m/s²且姿态必须倾斜以满足平移，说明欠驱动耦合。阶跃实验人为放大`dot f`允许区间的系数`ρ∈[0.125,1.75]`；当`ρ=1.75`时约84s发生失稳/中止，尽管桨力值未到饱和，桨力**变化率**接近界。是重要的实飞负面结果，但**不是严格的最坏扰动不可生存定理**。四旋翼与Tilt-Hex实飞分开，不混用其6桨18维与4桨16维。
- **终端/理论**：§3明确未建立本方法的正式闭环稳定性证明；终端二次成本并非终端鲁棒受控不变集。软约束与备用输入是实践策略，不能推出对有噪间歇观测的递归可行性或真实状态硬约束满足。

## 4. 与第18轮分层LMPC的同维度对照

| 维度 | Borbolla等(2024) QDrone 2 | Bicego等(2020)真实四旋翼 |
|---|---|---|
| 在线模型 | 2+4+6分块悬停LTI，外环虚拟姿态 | 全耦合16维（12刚体坐标+4逐桨推力状态）NMPC |
| 优化输入 | 高度总推力、位置期望角、姿态力矩 | 4桨推力导数，经过积分、转速反算和ESC |
| 电机限制 | 姿态命令外部饱和，混控PWM；预测内逐桨硬约束未证 | OCP显式逐桨推力值和导数边界，但导数界沿预测域冻结、可软化 |
| 量测 | OptiTrack/IMU，无失测SMF | MoCap/陀螺/ESC，无失测SMF；速度由动捕差分拟合 |
| 实飞/计算 | QDrone2真实飞行，控制周期25/50/250ms，WCET未报 | 四旋翼真实飞行，>200Hz更新，10Hz预测网格，平均求解3.5ms**地面站** |
| 安全保证 | 未证本课题终端信息RCI | 未证本课题终端信息RCI；松弛与冻结导数界限制硬约束含义 |

**新增选型判断**：本论文强力支持“真实执行器动态/推力变化率不能忽略”，但不能据此认定16维全耦合NMPC适合当前20ms+间歇测量+鲁棒终端安全的硕士主线。当前**6状态平面`(p_x,p_z,v_x,v_z,φ,ω)`、双输入`(T,τ)`仍为条件性物理首选**，需要显式加入/外包`(T,τ)`到逐桨`γ`及变化率的可实现域；4状态固定T只作有限安全基线，2状态姿态低风险保底，2+4+6级联及16维NMPC均作工程对照。禁止把实验识别阈值冒充集合有界误差保证。

## 5. SMF/CZ接口、风险与下一步

SMF+Tube MPC本身已有Le等(2011)、Qiu等(2020)等先例；Bicego也已做直接逐桨约束NMPC实飞。因此可能的新研究点不是“首次MPC四旋翼/首次执行器约束/首次SMF+MPC”，而是**在有噪间歇位置量测下，把可靠SMF/CZ后验、因果共享控制和经逐桨可实现域校验的状态/输入硬约束安全联立**。应先确认`(T,τ)`分配在当前四桨非负力与力变化率下的**共享可实现性**，并把电机实际跟踪误差、混控辨识误差作为有界不确定性显式声明；不能直接继承本文软约束当安全证书。

可行性：实飞执行器建模有真实论文依据；数学闭合和在线预算仍高风险。创新性：仅有差异假设，未做充分排他性文献证明。难度：六状态+失测SMF+真实逐桨约束+无限时域安全为高难；不得继续盲目扩到16维。

**下一轮唯一优先问题**：选定一篇直接研究四旋翼/多旋翼**逐电机分配可行域或推力变化率约束收紧**的原始论文，核验如何从外环`(T,τ)`命令推得联合可实现输入集合（含推力速率和跟踪误差），给主任务提供明确可验证接口；不开发控制器。
