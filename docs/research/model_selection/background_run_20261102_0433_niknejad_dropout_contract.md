## 新的模型假设审计：miss时的一拍收缩障碍（独立解析必要条件）
仓库四状态和六状态平面模型的局部位置-速度Euler子块，在无新位置测量且控制已知时，其线性误差传播为
A_pv=[[1,h],[0,1]], h=1/50 s。
连续两次miss：A_pv²=[[1,2h],[0,1]]。两个矩阵特征值均为1，故任何诱导矩阵范数都≥1；**不能要求每一个miss步对这个未观测p-v误差子块都有严格收缩因子lambda<1**。这仅排除“逐拍固定严格收缩”模板，不排除带扰动的有界集合、多拍成功测量条件下的收缩或信息状态终端可生存。
两次成功位置测量在理想无噪线性系统中，观测矩阵O=[C;CA]=[[1,0],[1,h]]行列式h=0.02≠0，说明在已知输入下跨时刻位置历史携带速度信息；**有噪/扰动下只支持集合收缩，不支持精确速度恢复**。这解释Run257成功条带的作用及miss时无法沿用成功证书。
- 验证环境：Linux，Python 3.13.5，SymPy 1.14.0。独立交互式命令用sympy.Matrix、Rational(1,50)断言A²、eigvals(A)={1:2}、det(O)=1/50、rank(O)=2，均PASS；本轮未新增或运行主任务控制回归。
- 六状态垂向p_z/v_z有相同无位置读数的运动学子块，但推力相关扰动、姿态耦合和控制权限必须额外认证；不能把上述线性必要条件当作完整六状态非线性系统的安全定理。
