## 2. 实际控制模型、输入、测量与约束

**物理模型不是外环12维**：§3式(16)四旋翼为 `p∈R³, v∈R³, R∈SO(3), ω∈R³` 的三维刚体（6自由度，姿态在SO(3)）；物理输入是**质量归一化总推力** `T≥0`（单位m/s²）与三轴力矩 `τ∈R³`（单位N·m）。`pdot=v; vdot=g e3-T R e3-D^T v; Rdot=R S(ω); J ωdot=S(Jω)ω-τ_g-A R^T v-Cω+τ`。物理推力合同 `0≤T≤Tmax`、参考推力严格留边界 `ε1≤Tbar≤Tmax-ε2`。此`T`**不能直接与本仓库N单位总推力比较**，应先 `F=m T`；论文未在优化式中给出逐电机分配、四电机饱和/变化率或三轴力矩盒的鲁棒保证。

**真正MPC预测状态**：§6式(30)是外环误差增广 `x_out=(pbar-p, vbar-v, a_d, η)∈R^{12}`，其中`a_d`是**虚拟加速度**，`η`为其动态滤波辅助变量，输入 `s∈R³`；不是12状态完整刚体或12自由度飞行器。三轴解耦后每轴 `x_i=(p_tilde_i,v_tilde_i,a_{d,i},η_i)∈R⁴`, `u_i=s_i`，因此`3×4=12`。式(30) `a_dot=-(a_d-η)/γ; η_dot=-(η-s)/γ`；§7精确ZOH离散，MPC的输入不是物理推力/力矩或电机转速。

**级联控制接口**：§4式(21) `a_d=T R e3 - Tbar Rbar e3`；§4式(23) `T=||a_d+Tbar Rbar e3||`，由`a_d`求期望推力方向、期望姿态`R_d`与角速度/加速度；§5式(28)使用几何非线性姿态反馈产生`τ`，**内环不是MPC**。姿态跟踪误差通过级联稳定性论证，不能将虚拟加速度瞬时等同于真实横向控制权限。

**时变物理约束的保守内近似**：§6式(31)–(33)将非零推力及上界转为 `||a_d||≤ρ(t)`, `ρ(t)=min(Tbar(t)-δ,Tmax-Tbar(t))`，再用内接立方体使每轴 `|a_{d,i}|≤Δ(t)=ρ(t)/sqrt(3)`。这是**参考推力相关的时变约束**，既保留了真实总推力可实现性的充分条件，也引入球→盒保守性；不等于对真实`p,v`施加硬安全盒。§7式(36)–(49)将辅助状态/输入的约束转为逐时变输入区间，Lemma 5考虑采样间隔内的约束。

**量测与估计**：理论外环控制律显式依赖`p,v`，内环依赖`R,ω`，即所需状态反馈；§10.2 Avular高保真**仿真**包含传感器测量、噪声、状态估计和电机动态，但公开正文未明确列出可迁移的IMU/GPS/Vicon具体测量噪声硬界、丢包自动机、SMF/CZ状态后验或滤波器集合包含保证。不得从高保真仿真推断所有传感器的有界误差模型。论文不含本仓库每5拍位置机会/最多2包失测的因果信息状态合同。

## 3. MPC、定理、数值证据及限制

- **方法**：三个独立4状态线性时变约束外环MPC，精确ZOH、`N=20`，非二次（含立方项）的终端Lyapunov代价，**凸但非QP**；内环几何非线性控制器。Theorem 8的时变可行性充分条件：`Δ(k+1)>exp(-h/γ)(1+h/γ)Δ(k)`；Theorem 10在可控、边际稳定、时变约束非空等条件下证明外环UGAS；§8处理采样间隔；Theorem 11结合内环与有界级联证明几乎全局一致渐近稳定UaGAS。**这些是论文给定状态反馈、名义模型和可行参考条件下的定理，不是有噪失测SMF、任意有界外扰、实际电机限幅或本仓库位置/速度硬盒的证明**。
- **§10.1数值**：MATLAB/CasADi多重打靶，`h=0.05s,N=20`（1s预测），新方法平均求解**3.3ms**，旧方法0.25ms；位置三轴RMSE新方法`[0.26,0.07,1.75]m`、基线`[0.48,0.14,2.43]m`。两种求解问题不同；没有20ms WCET严格上界。
- **§10.2高保真**：Avular Vertex One四旋翼仿真，`m=2.8kg,Tmax=80N`，`h=0.1s,N=20`（2s预测）；与PID比较三轴RMSE`[0.17,0.086,1.41]m` vs `[0.20,0.12,1.47]m`。高保真含噪声/电机模型但**不是实飞**，且理论保证不能自动覆盖未明确建模的随机噪声或电机动态。
- **数值单位检查**：该高保真物理总推力上限80N换成归一化加速度为`80/2.8≈28.5714m/s²`；悬停重量`mg=27.468N`。论文§10.1`Tmax=45.21m/s²`与§10.2`Tmax=80N`不能直接按同一单位比较。论文§11明确将真实飞行与板载耦合12阶优化留作后续工作。
- **文献证据等级**：已核验真实四旋翼动力学与数值仿真；已核验论文定理**陈述及假设**，没有独立重证定理；没有实飞、没有有噪丢包SMF/CZ、没有逐电机执行器硬安全、没有真实20ms WCET。不能把其“formal stability”当成Run246/261反例被消除。

## 4. 对模型选型、创新性与主任务的交接

1. **核心新增**：12维MPC状态可能只是`3×(位置误差、速度误差、虚拟加速度、辅助变量)`，而非完整刚体12状态；状态维数、物理自由度、控制接口必须分别记录。六状态平面`(p_x,p_z,v_x,v_z,φ,ω)`与`(F,τ)`仍是条件性物理首选，因为能保留垂向推力耦合与真实力矩权限；本轮没有足够证据改成12维级联MPC。
2. **新备选**：三轴解耦4状态/轴外环MPC可作为成熟轨迹跟踪**名义性能对照**，但其虚拟输入`s`与SMF后验/物理`(F,τ)`不同，若迁移必须增加`a_d→(F,R_d)→τ`的有界接口及传感器合同；不能直接继承Run260–264四状态安全证书。
3. **创新边界**：四旋翼级联MPC、时变推力收紧、非二次终端Lyapunov代价、全级联UaGAS已有2026 *Automatica*论文；不应把这些作为本硕士课题的新发明。真正可检验的缺口是**有界位置失测SMF/CZ状态集合、观测纤维共享因果反馈、真实推力/力矩/状态硬约束与可移位终端信息状态**的闭合；是否能证明仍待主任务研究。
4. **难度与范围**：2状态姿态低风险但任务较窄；4状态固定推力可继承有限安全但不能保证高度；6状态平面中高难度且物理闭合较好；8/9维级联来自Kamel六旋翼而非四旋翼；12维增广外环在本论文已有成熟名义稳定性但**并非SMF＋MPC更容易**；完整10/12/13坐标刚体SMF＋严格终端安全作为硕士主线暂不升级。
5. **与主任务分工**：向“无人机 MPC＋SMF 课题研究”提供可直接审计的接口需求：先冻结`F=mT`单位转换、`a_d`内接盒保守性、内环误差及观测权限；若考虑分层方案，必须独立验证`p,v`隐藏状态下的SMF/CZ输入与共享因果控制，而不是直接使用该文全状态定理。Run264 Gate A仍blocked。
