# 背景研究第2轮：Xue等(2024)输出反馈随机MPC的真实量测权限（2026-11-01）

**基准main：** `f908c383e70b6fc1e1eba5d219a24c25c309d5e0`；本轮只做论文/模型证据，不改主任务控制算法、Run248证明或当前检查点。**唯一问题：** 四旋翼输出反馈MPC论文是否已经解决本仓库的“仅有噪位置、位置包丢失、隐藏速度的状态SMF＋硬约束”？

## 1. 论文与实际阅读

Ruochen Xue, Li Dai, Peizhan Wang, Zhongqi Sun, Yuanqing Xia, *Output feedback stochastic MPC for tracking control of quadrotors with disturbances*, *IET Control Theory & Applications* **18**(5):566–580 (2024), DOI https://doi.org/10.1049/cth2.12588 ，期刊原文 https://ietresearch.onlinelibrary.wiley.com/doi/full/10.1049/cth2.12588 。线上首发2023-10-18，卷期为2024-03-11。**阅读日期2026-11-01；期刊开放正文分节已读**：§2.1–2.3式(2.1)–(2.15)、Assumption 1/2；§3.1式(3.1)–(3.5)、§3.2 Theorem 1及收紧式、§3.3 Problem 1/Algorithm 1/终端式(3.31)–(3.41)、§3.4 Theorem 2；§4 ESO与Theorems 3–4；§5数值配置及§6局限。非附录/全部推导逐式核验，未独立复现其证明或仿真。

## 2. 论文究竟控制了什么

- **物理分层**：平移外环 `xi_s=(x_p,x_v,y_p,y_v,z_p,z_v)∈R^6`，外加三维Dryden风滤波状态 `xi_w∈R^3`，外环**增广9状态** `x=(xi_s,xi_w)`，输入 `u=(u_x,u_y,u_z)∈R^3` 是由总推力/姿态映射出的**虚拟惯性系加速度**（式2.4），而非四个电机力矩；外环 MPC 用Luenberger observer+概率约束收紧、线性反馈加补偿 `u=K xhat+c`。内环另用滚转/俯仰/偏航各2状态的姿态子系统和三阶ESO扩张状态，ADRC追踪外环给出的期望姿态；内环不是同一9状态MPC。§3.42由虚拟加速度重建总推力及期望姿态，设 `psi_d=0`。
- **关键量测事实**：式(2.3)明写 `C_xi=diag(1,1,1,1,1,1)=I_6`；式(2.11) `C=[C_xi,0]`，故 **6个平移位置与速度分量每个采样时刻均有带噪输出**，只有3个风滤波状态隐藏。论文所谓“unmeasurable state/output feedback”不能误读成仅测三轴位置、隐藏全部速度；Algorithm 1每步 `Measure y(k)`，**没有success/miss丢包自动机**。状态估计为Luenberger observer，**不是SMF/CZ状态后验**；不涉及Sasfi(2023)的参数SMF。
- **随机性与约束**：§2.3式(2.14)–(2.15)为 `Pr(linear state/input constraint)≥p` 的**机会约束**，不是本仓库“所有合法有界扰动下逐拍硬约束”。§5示例每项阈值 `p_x=p_u=0.8`，允许非零违约概率；其三轴加速度虚拟输入界 `h_u=(35,35,35)` 不等同旋翼物理推力/力矩的联合可达域。
- **数学条件**：Assumption 1要求噪声已知分布、独立、紧支撑；式(3.2)需选择 `L` 使 `A-LCA` Schur，`K` 使 `A+BK` Schur。Theorem 1通过扰动分位数及最坏支持项构造机会约束的充分收紧，Problem 1以近似最大允许终端集 `S_{T_hat+T*}` 及shift可行性论证滚动可行；Theorem 2为期望时间平均二次成本上界，不应写成每条扰动轨迹渐近稳定/硬安全。内环Theorems 3–4依赖有界扰动导数及带宽条件。论文的“Gaussian with compact support”措辞应理解/澄清为§5实际使用的**截断高斯**，普通非退化高斯不具紧支撑；移植时必须明确这一假设。
- **实验**：§5 MATLAB/YALMIP/SeDuMi，`T_s=0.05s` 外环、`T_sr=0.01s` 内环，`T_p=7`、终端近似 `T_hat=8,T*=1`，100组扰动样本；示例称机会约束违约率小于20%，与硬约束零违约不同。未给本项目20ms最坏求解时间证书；没有位置失测实验或硬件实飞证据。

## 3. 与仓库模型的逐项对照

| 项目 | Xue等2024 | 当前仓库主问题 |
|---|---|---|
| 状态与动力学 | 外环6平移+3风滤波状态；内环姿态独立 | 四状态横向-姿态基线，六状态平面候选含俯仰耦合 |
| 传感器 | `y= [I6,0]x+noise`，含每轴速度带噪量测，每拍都有 | 位置每5拍有机会、最多连续丢2包；姿态每拍有噪，速度隐藏 |
| 估计 | Luenberger线性observer | SMF/CZ关联后验，保证真实状态包含 |
| 控制输入 | 三轴虚拟加速度，ADRC内环 | 实际 `T,τ` 或冻结T时 `τ`，执行器硬界 |
| 安全 | 机会约束、概率收紧 | 对所有合法扰动/丢包模式的硬约束 |
| 终端 | 线性增广系统最大允许集及shift条件 | 非线性/丢包信息状态共享因果终端尚未闭合 |

**新研究判断：** “四旋翼输出反馈MPC”已成熟，不能把output feedback/分层本身当作创新。真正仍需验证的缺口是：**仅有噪间歇位置＋姿态测量、隐藏速度、状态SMF/CZ、真实双输入和逐拍硬约束**的共同信息状态可生存性。Xue的9状态增广风模型不是必须采用12状态或完整六自由度的证据；其分层设计支持把六状态平面模型作为条件性首选、四状态保留理论基线。若改走分层路线，必须为内环跟踪误差提供外环可验证有界集合，而不是假设理想内环。

**与Run248关系：** Run248第14拍合法角点已不可生存，反映控制权限/早期因果决策不足；Xue的shift proof建立在每步六维输出、稳定observer和概率终端上，不能用来解除该硬安全反例。**证据等级**：文献正文核验+仓库历史检查点静态对照；没有本轮新算法、数值仿真、闭环安全或递归可行性证明。

## 4. 选题成熟度、未解问题和下一轮唯一任务

**条件性首选仍是六状态平面四旋翼 `(px,pz,vx,vz,phi,omega)` 与 `(T,tau)`**；四状态保留验证基线，2状态姿态保底。可行性：中（已有六状态配置，但有界极端扰动和丢包下非空安全核未证）；创新性：有潜力但未成立（已有输出反馈/SMF+MPC邻近论文）；工作量：中高，须避免将所有模块同时扩展至12状态。下一轮唯一优先问题：**在一篇位置-only/间歇位置量测的四旋翼控制论文中核对实际测量矩阵与缺测模型，并判定其是否已有可直接比较的硬安全输出反馈终端保证**；找不到时如实记录缺口，不得把本篇每拍位置+速度输出冒充位置-only。
