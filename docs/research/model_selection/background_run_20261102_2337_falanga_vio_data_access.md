## 2. 新增原始四旋翼MPC论文：PAMPC

Davide Falanga; Philipp Foehn; Peng Lu; Davide Scaramuzza, **PAMPC: Perception-Aware Model Predictive Control for Quadrotors**, *2018 IEEE/RSJ International Conference on Intelligent Robots and Systems (IROS)*, pp.5200–5207, DOI https://doi.org/10.1109/IROS.2018.8593739 。作者公开接受稿 https://rpg.ifi.uzh.ch/docs/IROS18_Falanga.pdf ，可解析同版arXiv v2 https://arxiv.org/pdf/1804.04811v2 ，开源实现 https://github.com/uzh-rpg/rpg_mpc 。2026-11-02阅读公开8页正文§I–VII、式(1)–(13)、§V实验和§VI计算；没有逐式验证所有四元数/视觉导数，也没有比对IEEE最终排版或构建ROS代码。**阅读状态：作者公开稿正文全篇分节阅读；公式/源码非全量复现。**

- **控制任务/层级**：真实健康单向四旋翼的机载视觉惯性定位、圆周飞行、悬停点间转移及低光视觉导航；NMPC同时优化轨迹/感知目标。实际机体6物理自由度；优化状态`x=(p_x,p_y,p_z,v_x,v_y,v_z,q_w,q_x,q_y,q_z)`为**10坐标**，四元数单位约束使其9独立运动学状态；**未把三轴角速度作为状态**。连续模型`dot p=v; dot v=g+R(q)(0,0,c); dot q=0.5 Lambda(omega_B)q`；`c=(f_1+f_2+f_3+f_4)/m`为质量归一化总推力，`u=(c,omega_x,omega_y,omega_z)`为4个**虚拟控制输入**，不是四桨推力、也不是`(T,tau)`。
- **物理与执行器假设**：忽略显式电机RPM、推力一阶动态、逐桨分配误差；实际飞控由机载控制栈执行体角速度和集体推力请求。§IV式(11)–(13)约束`c`上下限、体角速度及惯性速度，**未提供逐桨实际推力/速率/ESC残差硬证书**。小角度假设不是该四元数模型的必需条件；气动阻力/电机动态未显式建模。
- **量测/估计**：420g、对角220mm、推重比约2的实飞平台，Snapdragon Flight ARM、机载IMU与前视下倾45°全局快门相机；Qualcomm VIO给`x_est`，不是有界SMF/CZ后验；图像兴趣点质心投影和投影速度进入感知成本。没有给出逐次位置包成功/丢包自动机、可靠有界视觉测量误差集合、间歇量测状态包含率或状态SMF。视觉特征居中与降低投影速度是**软代价**，不是每时刻必满足的硬可见性约束。
- **MPC实现**：非线性多重打靶+Runge–Kutta，ACADO/qpOASES、SQP每次控制循环1次迭代并warm start；`dt=0.1s`、`t_h=2s`即20预测间隔，机载迭代100Hz（周期10ms），**离散预测步长不等于求解/控制周期**。目标为状态/输入跟踪与图像投影位置、速度的二次成本；式(10)有末端**代价项**，未见终端鲁棒不变集合、硬失测信息终端集或递归可行定理。
- **实飞/计算证据**：作者报告圆周1–3m/s、悬停到悬停（主动改变高度以减少俯仰）、暗光视觉特征导航三类真实机载实验，非Vicon闭环。平均单次迭代3.53ms，实测最大低于5ms；这是**论文报告样本最大值，不是形式化WCET**，也不能推出本仓库20ms周期和所有硬约束可行。未报告可独立复核的硬约束违约统计、逐桨真实推力误差或有噪失测安全定理。
- **复现**：公开`uzh-rpg/rpg_mpc` README确认ROS Kinetic/Ubuntu 16.04、ACADO生成代码/qpOASES、依赖`rpg_quadrotor_control`；本轮仅阅读README，**未构建、未运行SITL/飞行实验**。代码存在不意味着对本机体有可移植的最终执行器硬保证。

## 3. Elokda公开数据包：证据边界而非“已证实缺失”

Elokda等(2021)期刊全文Data Availability声明数据`paper-deepc-2019-for-ijrnl-data-gen`，DOI https://doi.org/10.3929/ethz-b-000490768 。本轮尝试DOI和ETH Research Collection历史handle及多个实体URL；当前可用网页检索返回403/无法读取，工作容器对ETH域名DNS不可达。**没有成功下载数据包、读取目录、文件清单或逐样本数据**，因此**不能声称数据包不含ESC命令/RPM/逐桨推力**。论文§2.1、§3.3确认实验对外可见信号为25Hz动捕位置/姿态及外环总推力/体角速参考，厂商内环黑箱；这仅证明论文**没有公开描述可认证的同步逐桨物理量**，不等于证明数据集文件不存在。若未来数据可访问，应先核验文件字段、同步时钟、采样率、实际测力传感器与机体配置，才决定是否可用于20ms残差辨识。

## 4. 数学/模型审计与主任务接口

独立Fraction算术：`2/0.1=20`预测间隔；`1/100=0.01s`控制更新；预测步长/更新周期=10；3.53ms/10ms=0.353。检查只验证单位和时间尺度，不是MPC求解器回归。PAMPC的软视觉目标在图像特征丢失时不提供集合包含、硬可见性或终端信息不变性；真实VIO导航说明感知与动作耦合有工程价值，但**不是**Run277间歇有噪位置SMF的定理。

模型矩阵结论：2状态姿态/高度仅内环或低风险备选；4状态固定推力仍是有限安全数学基线；**6状态平面`(T,tau)`仍为条件性首选**，需要真实共同逐桨执行域、总推力/力矩一致性、失测状态后验与信息终端可行性；PAMPC的10坐标四元数运动学+体角速度虚拟输入是**不同控制权限**，不升级主模型；12状态完整刚体及电机级NMPC继续作为计算/执行器对照。创新边界：已有视觉感知感知NMPC、四旋翼参数SMF-RAMPC及一般状态SMF+MPC，不能声称首次；可研究的是**可靠后验+因果可执行输入+确定性间歇量测安全**的严格组合与计算预算。

**主任务建议（不在本背景任务实现）**：把“感知特征可用性/丢包”与“状态后验可靠包含”分开建模；若引入视觉特征软代价，仍需独立的硬安全可行域。若Elokda数据无法获取或不含同步物理通道，目标1kg机体应台架同步采集`ESC command, RPM, actual thrust, voltage, temperature, timestamp`，并给测量误差、延迟和带宽/速率先验；采样率≥50Hz只是分辨20ms变化的必要工程建议而**非充分认证条件**。不允许将420g机载PAMPC、28g Crazyflie或其他桨台架参数直接迁移成1kg硬界。

**可行性/创新性/难度**：开源视觉NMPC具有工程可复现线索但依赖老ROS与内环；本硕士主线应优先完成较低维可靠SMF→Tube MPC因果闭环，避免同时做视觉特征优化和电机级NMPC。创新性尚待直接四旋翼SMF/CZ+MPC文献对照；难度中高，Gate A仍blocked。

**下一轮唯一优先问题**：对`uzh-rpg/rpg_mpc`固定commit与其`rpg_quadrotor_control`接口进行逐文件源码审计，追踪`(c,omega_B)`输出到真实混控/饱和，并确认是否存在公开可核验的确定性最终执行误差界；若无，给出最小台架辨识合同，不写主任务控制器。
