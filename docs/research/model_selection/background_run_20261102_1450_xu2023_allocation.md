## 3. 本轮独立的四桨联合可实现域推导（论文矩阵的推论，非论文定理）

用论文十字型四桨编号，设`f_i=k_f ω_i²≥0`，`c=k_n/k_f>0`，`l>0`，则
`T=f1+f2+f3+f4`，
`τx=l(f2−f4)`，
`τy=l(f3−f1)`，
`τz=c(−f1+f2−f3+f4)`。

对仓库平面绕y轴`τ=τy`、并要求`τx=τz=0`，四条线性等式唯一解为
`(f1,f2,f3,f4)=(T/4−τ/(2l),T/4,T/4+τ/(2l),T/4)`。
该解的存在要求`l,c>0`及标准混控矩阵满秩；等式证明由`f2=f4`、`f1+f3=2f2`及`f3−f1=τ/l`直接得到。对称单桨`0≤f_i≤f_max`下，上述解在盒内**当且仅当**`0≤T/4±τ/(2l)≤f_max`、`0≤T/4≤f_max`。不对称单桨界需逐桨分别检查。

若上一拍实际分配也在同一零滚转/偏航子空间，则`Δf1=ΔT/4−Δτ/(2l)`、`Δf2=Δf4=ΔT/4`、`Δf3=ΔT/4+Δτ/(2l)`。在每桨每秒变化率上界`r_i^+,r_i^-`及采样`h`下，必要且充分的**定义的离散速率盒**约束是逐桨`−h r_i^-≤Δf_i≤h r_i^+`。若实际上一拍桨力未知，则要对**整个可靠上一拍集合**验证同一命令；不能由前一拍`(T,τ)`中心替代。若存在执行误差、桨推力滞后、非标混控或偏航/横滚命令，上述简式不再直接充分，须用实际`G`和动态误差集合。

对仓库`T∈[4.905,14.715]N, |τ|≤0.08Nm`，全输入盒的**静态**可实现充分且必要条件（上述对称四桨、所有角点）为`l≥0.16/4.905≈0.03262m`、`f_max≥14.715/4+0.08/(2l)`。示例`l=0.1m,f_max=4N`时，合法虚拟角点`T=14.715N,τ=0.08Nm`需要`f3=4.07875N>4N`，因而不可实现。**此为假设性参数反例，不是仓库已确认的真实平台参数**。仓库没有冻结`l,f_max,r_i^±`，故目前不能对原始虚拟盒给出真实硬安全证书。

**独立代数检查**：在本地Linux Python 3.13.5、SymPy 1.14.0执行`sympy.solve`求四个线性混控等式，返回`f1=(T*l−2τ)/(4l), f2=f4=T/4, f3=(T*l+2τ)/(4l)`；逐项符号等价断言通过（`symbolic allocation exact: PASS`）。这是静态代数一致性检查，不是主任务控制器回归、执行器实测或飞行实验。

## 4. 模型选型与SMF/CZ接口

与Borbolla(2024)实飞2+4+6级联LMPC、Bicego(2020)实飞16维逐桨推力变化率NMPC对照：Xu(2023)是12维**snap外环**＋SO(3)姿态内环＋后置加权分配，**仅仿真**。三者均未提供仓库间歇有噪位置下可靠状态SMF后验＋真实逐桨联合可实现域＋共享因果终端信息RCI的现成证明。SMF+MPC已有Le(2011)、Qiu(2020)、Ping/Sun(2015)等先例，不能声称首次组合。

首选不变：六状态平面`(p_x,p_z,v_x,v_z,φ,ω)`、物理`(T,τ)`为**条件性**目标；四状态固定推力为有限安全/反例基线（倾斜时垂向漂移），二维姿态为低风险备选；12维snap与16维NMPC仅对照。当前主任务Run246、Run261、Run267仍提示终端可生存/闭合缺口，Gate A=blocked。

**交给主任务的接口提案（不在本任务开发）**：提供实际四桨`G`、桨臂长`l`、旋翼力/反扭矩系数、`f_i^{min/max}`、`r_i^±`、上一拍逐桨推力集合`F_{k-1}`、ESC/混控有界跟踪误差`E_{alloc}`。主任务给定同一观测纤维共享的`(T,τ)`，判定所有合法`F_{k-1}`及执行误差下的可实现性，并将残差`Gf−w_d`纳入SMF/Tube扰动外包；该合同尚待辨识/验证，**不是已有安全证书**。

可行性：静态线性映射易实现、物理参数未冻结；创新性：已有分配QP和逐桨NMPC先例，差异仅在有噪失测与严格安全接口，仍需进一步排他性检索；难度：加入速率、上一拍推力不确定性与终端因果回返后高。未新增控制器、SMF递推、MPC求解、飞行或稳定性证明。
