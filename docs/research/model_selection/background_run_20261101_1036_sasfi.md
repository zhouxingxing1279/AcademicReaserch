# 背景研究首轮：平面四旋翼6状态与SMF含义核验（2026-11-01）

**基准main**：`d5a8cd049fd57aa9b35750551abf83f3607321cd`；**唯一问题**：已有四状态固定推力的可生存性反例是否意味着必须扩展到12状态？本轮只核对六状态平面模型的真实文献与仓库六状态配置，不开发第二套控制器。

## 1. 实际阅读及书目信息

András Sasfi, Melanie N. Zeilinger, Johannes Köhler (2023), *Robust adaptive MPC using control contraction metrics*, *Automatica* 155:111169，DOI https://doi.org/10.1016/j.automatica.2023.111169，arXiv:2209.11713v2（2023-07-11），全文 https://arxiv.org/html/2209.11713v2 。本轮实际阅读§2.1、§3.1（Assumption 1）、§3.2（Theorem 6）、§3.3（Proposition 7）、§3.4（Assumption 10）、§3.5（Theorem 12）、§4（完整模型、约束、数值实现），不是全文附录逐式复核。正式期刊与arXiv书目信息核对一致；期刊终版细节未逐式比较。

论文§4的**六状态**为 `(p1,p2,phi,v1_body,v2_body,omega)`，输入是两旋翼推力 `(u1,u2)`，不是六自由度；`p1,p2`为惯性系位置，`v1,v2`为机体系速度。参数SMF更新 `theta=1/m` 的多面体不确定集，要求**完整状态和控制精确可测、状态导数带界噪声**，不是本项目仅有位置/姿态观测时的状态SMF。风扰 `d∈[-0.1,0.1]`，质量倒数初始±1%；角度±π/3、角速率±π、机体速度 `|v1|≤2,|v2|≤1`、旋翼输入 `u_i∈[-1,3.5]`。负推力数学下界不应未经硬件解释直接复制。使用CCM的homothetic Tube MPC；Theorem 12在Assumption 1/10与初始可行等条件下给出递归可行、硬约束及名义收敛；没有证明离散有噪丢包状态SMF的安全性。

数值部分用RK4、Ts=0.15s、N=25、CasADi/IPOPT、MATLAB笔记本仿真，比较参数更新与不更新以及刚性/可变tube；没有实飞或20ms WCET。其约束在离散采样点数值实施，不能据此自动声称两采样点之间的数值安全保证。文章指出较大的扰动/参数不确定集会导致障碍环境中可行性问题。该论文已在仓库READ_PAPERS.md以书目条目出现，但本轮首次补入**实际分节阅读的可核验内容**，统一阅读日志需去重。

## 2. 模型对照的可验证新发现

仓库 `configs/planar_baseline.json` **原本已配置**六状态 `(px,pz,vx,vz,phi,omega)` 和双输入 `(T,tau)`，故并非需要新建“六状态模型”才能研究。它使用惯性系速度，与Sasfi的机体系速度不同。若按常规旋翼分配，`T=u1+u2`、`tau=l(u1-u2)`，需分别核对执行器推力与力矩约束，不能直接把论文的负推力区间照搬。

当前四状态冻结 `T=mg`，`phi≠0` 时即使垂向残差为零，`pz_ddot=g(cos(phi)-1)`，不可能自动保持高度；这意味着四状态认证只能描述明确的横向—姿态子系统，不能直接推出整机安全。仓库六状态的推力相关扰动在悬停处约为水平±2.029、垂向±3.079 m/s²，远大于Sasfi的±0.1；必须检查鲁棒控制权限与可生存域，而不是引用论文数值结果替代证明。

Run247在四状态合法极端扰动下发现固定倾角策略第26拍已不可恢复，说明主要瓶颈是**扰动、执行器和信息权限的共同可行性**，不单纯是维数不足。Run221已有孤立姿态SMF-MPC正向递归可行基线；Run235的四状态RCI依赖全状态反馈，Run237排除了某个后验纤维对原F的一步共享输入。此轮没有重做这些证明。

## 3. 课题判断与工作边界

**首选候选**：六状态平面四旋翼作为最终物理背景（平面3个自由度、6个状态），四状态作为已有严格理论/反例基线，二维姿态作为保底闭环。此为模型选择的**条件性建议**，不是已通过Gate A的最终锁定；10/12状态和分层控制仅保留对照，避免扩维替代论证。

**可行性**：原仓库已有六状态配置，复用性高；但极端扰动和位置丢包下的可生存性未知。**创新性**：CCM+参数SMF+Tube MPC+平面四旋翼已由Sasfi等实现，不能重复宣称组合创新；真正可能的差异是有噪间歇位置测量下**状态**SMF与因果终端安全合同。**难度**：中高；先用有限信息状态安全前驱的可行性判据排除不合理任务域，再扩展MPC，不并行开发新算法。

**新增工件**：`docs/research/model_selection/MODEL_SELECTION_EVIDENCE.md`；本独立日志；统一`docs/literature/PAPER_READING_LOG.md`补入分节阅读（如成功并发安全合并）。没有新增控制代码、数学证书或闭环仿真。文档自检包括状态/输入顺序、单位、引文、原仓库配置对照；不将文档检查说成算法回归测试。

**下一轮唯一优先问题**：选一篇真正以**有噪部分观测状态估计**而非参数SMF为核心的四旋翼输出反馈MPC论文，逐式核对它的量测矩阵、模型维数和递归可行条件，判断六状态平面模型的间歇测量假设是否需要调整。
