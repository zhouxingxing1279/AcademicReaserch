## 关键模型证据：物理plant不等于优化器可用输入
- §2.1：连续非线性四旋翼刚体plant为**12状态**，惯性位置3、惯性速度3、ZYX Euler姿态3、机体系角速度3；对应六个物理自由度。原始物理plant的输入为**四个桨各自推力**，参数包括质量、惯量、桨力作用位置、阻力矩/推力系数。模型有机体和惯性坐标系。
- §2.1：**实际商用四旋翼闭环架构**保留厂商IMU内环，外部优化器不能直接命令四桨；外环只有**3输入**：机体两轴角速度参考 + 总推力参考；外环反馈是外部运动捕捉系统提供的位置与姿态共**5输出**，维持偏航的内环由厂商实现。
- §2.2：若将厂商内环和电机电流视为未知动态，外环黑盒实际状态**不止12维**（包含电机电流与内环状态）；因此“论文使用12状态plant”绝不意味着“该论文用12状态、四个wrench输入的Tube MPC”。本文主要算法是**DeePC**，比较基线有model-based MPC，**不是Tube MPC、不是SMF/CZ**。论文报告实机nano-quadrotor轨迹跟踪；本轮未复核其求解器、预测时域、采样周期、数值误差或实时耗时。
- 量测：外部motion capture位置与姿态；厂商IMU用于内环。未核验论文对间歇位置丢包、确定性有界量测噪声、终端信息RCI或鲁棒Tube硬约束的保证；不能从实飞效果推断这些保证。

## 对用户当前12状态选择的条件性影响
用户选择**12状态完整六自由度非线性plant作为仿真主对象**合理，且有该原始论文直接模型先例；但**MPC是否有4个独立输入**必须在仿真架构中显式规定：
(A) 直接wrench模式：控制器输出 (T,τx,τy,τz)，用明确布局/旋向/力臂/反扭矩系数的可逆分配矩阵映射到4个非负、限幅的桨推力；实际可行wrench集合为分配矩阵作用于桨推力盒得到的耦合多面体，不能简单采用4个独立wrench盒。
(B) 商用级联模式：若复用厂商内环，则MPC输出可能只有角速度参考与总推力等3输入；需要对内环跟踪误差与延迟给出界，不能直接借用(A)的全权限可控性/硬安全论证。
Euler角状态在pitch=±π/2附近运动学奇异；局部悬停Tube必须限定姿态包线。对非线性plant做悬停线性化时，残差界必须在整个候选状态/输入管束上验证，才可能从线性模型的硬安全推到真实plant。
