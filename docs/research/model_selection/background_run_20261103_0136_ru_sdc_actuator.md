## 新论文原文阅读证据
Pengkai Ru, Kamesh Subbarao, *Nonlinear Model Predictive Control for Unmanned Aerial Vehicles*, *Aerospace* 4(2):31, 26pp (2017), https://doi.org/10.3390/aerospace4020031 。MDPI出版社页面请求429，实际读作者上传开放全文 https://www.researchgate.net/publication/317686529_Nonlinear_Model_Predictive_Control_for_Unmanned_Aerial_Vehicles ，§2式(3)–(7)、§3式(8)–(11)、§4式(41)–(44)、§6–7及附录A；标记**部分全文阅读**，没有假称逐式通读稳定性证明。

- 物理6自由度、控制模型12状态 x=(p_I[3],V_B[3],Euler角[3],机体角速度[3])；直接输入u=(F1,F2,F3,F4)逐桨推力，式(3)映射合推力和三轴力矩。与仓库平面6状态(p_x,p_z,v_x,v_z,phi,omega)、双输入(T,tau)不同，速度坐标亦不同。
- SDC伪线性NMPC、SQP，悬停LMPC对照；采样0.05s、预测25/控制25（1.25s），m=0.8kg、J=(0.0224,0.0224,0.0436)kg m²、L=0.165m、Q=I12、R=I4。控制输入仿真盒[0,mg]每桨。终端集合、WCET、确定性失测鲁棒约束在本轮已读范围未确认。
- **关键方程核验**：式(7) `dFi/dt=lambda_F*(Fci-Fi)`，附录A `lambda_F=50 s^-1`；作者明确写“Actuator dynamics is ignored for prediction, but is used for state propagation.” 因此模型内一阶推力响应不能自动认证优化得到的逐桨推力每拍真实可执行。时间常数1/50=0.02s，采样0.05s/0.02s=2.5；这是单位/时间尺度算术，非ESC误差证书。
- 数值实验为螺旋、球面螺旋、折线轨迹及扰动的仿真LMPC/NMPC对照，非四旋翼实飞。实际传感器、间歇位置、SMF/CZ状态集合、ESC RPM测量、逐桨真实速率硬界均未报告或本轮无法确认。论文有跟踪有界性讨论，但未迁移为本仓库的确定性安全定理。

## 模型矩阵变化与主任务接口
六状态平面双输入仍条件性首选；四状态有限数学基线、2状态姿态保底、10/12状态/分层作为架构对照。直接逐桨NMPC也必须核验执行器真实推力响应，维数增加并不能绕过硬件不确定性。SMF/CZ可以考虑扩展执行器状态集合和收紧，但创新性未证。

建议主任务只接收一个接口问题：给定实际上一拍逐桨推力集合、命令盒及有界参数，推导下一拍施加(T,tau)的**共同可靠可达外包**；先核验物理可行性，不把本背景任务当作控制器实现。
