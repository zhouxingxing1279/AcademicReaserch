## 2. 真实模型、控制输入、传感器与MPC

**动力学背景**：§3式(1)–(3)列出三维位置`p∈R³`、速度`v∈R³`、`R∈SO(3)`、机体系角速率`ω`的刚体运动；推力与旋翼转速平方相关，考虑集中气动阻力和外力`F_ext`、惯量与分配矩阵。该**物理模型**不等于优化器的实际状态；内环低级姿态控制器仍独立运行。

**内环闭环辨识**：§3式(4)以`φdot=(kφ φcmd−φ)/τφ`、`θdot=(kθ θcmd−θ)/τθ`表示一阶姿态响应，偏航角速率命令假设瞬时跟踪。Table 2实机辨识`τφ=0.1901 s, τθ=0.1721 s, kφ=0.91, kθ=0.96`。**外环优化的是角度命令，不是实际电机力矩**；不包含内环PID的逐扰动硬误差保证。

**LMPC**：§4式(5)–(10)为**8维状态**`x_L=(p_x,p_y,p_z,v_x,v_y,v_z,φ_I,θ_I)`；`φ_I,θ_I`是去偏航耦合的惯性系heading-free倾角。**3维优化输入**`u_L=(φ_I,cmd, θ_I,cmd, T_cmd)`；悬停点小角度、`ψ=0`线性化并离散化，使用`x+=Ax+Bu+B_d F_ext`。二次阶段/终端**代价**、输入盒`U`、预测期扰动力常值假设；未见终端受控不变集合或逐扰动状态硬约束。§4式(11)有倾角引起升力变化的非线性推力补偿；原式排版涉及归一化推力，**不得未经单位复核照搬成N单位力**。

**NMPC**：§5式(13)–(15)为**9维状态**`x_N=(p_x,p_y,p_z,v_x,v_y,v_z,φ,θ,ψ)`，**3维优化输入**`u_N=(φ_cmd,θ_cmd,T_cmd)`。保留三维非线性平移动力学和辨识的一阶内环姿态动力学；偏航命令另由低级接口处理，优化式未将三轴力矩或四/六个电机速度作为决策输入。多重打靶、隐式RK4、SQP/高斯牛顿实时迭代、ACADO。虽然文章说full system dynamics，这**不是12状态刚体力矩NMPC**，也不直接控制`ω`或各旋翼。

**实际量测与估计**：§6、§7.1使用IMU与外部Vicon动捕融合的EKF，并增广外力`F_ext`估计作偏差消除；是**概率点估计/扰动估计**，不是SMF/CZ状态集合后验或参数SMF。未给有界位置噪声、位置包丢失自动机、最多连续失测次数或因果集合控制保证。本文实验风速约11m/s是实测场景，不等于所有`|r|≤R`的严格鲁棒保证。

**约束/时间/求解器**：Table 2六旋翼质量3.42kg、倾角命令±45°、总推力命令13.5–40.3N；电机/力矩分配的逐旋翼饱和与变化率硬约束未在外环式(9)/(15)显式建立。两外环均100Hz更新，内部预测10Hz、N=20、预测2s。LMPC使用CVXGEN QP，NMPC使用ACADO SQP/RTI。阶段与终端二次代价并非终端安全集合；论文未给间歇量测输出反馈的递归可行性或RPI/RCI证明。

**实验/计算证据**：§7实飞Asctec NEO六旋翼，ROS、Intel 3.1GHz i7/8GB。无风悬停RMSE：LMPC 1.84cm、NMPC 2.05cm；约11m/s风中悬停：LMPC 2.7cm、NMPC 2.5cm；激进轨迹风中RMSE：LMPC 10.8cm、NMPC 7.1cm；阶跃上升时间1.6s vs 1.0s。§7.5**平均**优化耗时LMPC 2.35ms、NMPC 0.45ms，因实现求解器不同（CVXGEN vs ACADO RTI），**不能据此断言NMPC一般比LMPC计算更便宜**；未报告WCET严格上界。公开代码 https://github.com/ethz-asl/mav_control_rw ，本轮只核对仓库公开说明，未clone、构建或复现。

## 3. 证据对模型选择的影响

1. **本轮核心新增**：8维LMPC与9维NMPC都只是**外环位置/轨迹控制状态**，三维优化输入为期望滚转、俯仰与推力，内部有辨识的姿态一阶动态；六旋翼实飞并不等于四旋翼`(T,τ)`可执行硬安全。姿态时间常数约0.17–0.19s说明不能把命令角度当作立即实现的物理倾角。与Run262冻结四状态三拍`τ→v`时滞属于**不同控制接口/平台**，不能互相替换参数。
2. **六状态平面条件性首选保留**：`(p_x,p_z,v_x,v_z,φ,ω), u=(T,τ)`具有明确垂向耦合与力矩权限，便于研究有噪位置SMF及安全前驱；但它不是Kamel论文的降维版实飞证书，需明确真实推力/力矩分配、内环执行误差与噪声合同。
3. **分层MPC上升为认真保留的备选架构**：外环若改用`(φ_cmd,T_cmd)`，必须引入辨识的内环角度动态和可认证误差界，不能沿用`τ`物理模型或默认虚拟加速度可独立执行；改变接口须与主研究任务协调、重新定义合同。
4. **2/4状态与10/12状态**：2状态只支持姿态；固定T的4状态无法严格保证高度；10/12/13状态维数不自动带来更可靠的SMF或终端安全。Kamel的8/9维与Carlos的13坐标是**不同外环接口与平台**，不能做维数直接排名。
5. **创新边界**：成熟的多旋翼LMPC/NMPC、级联辨识、EKF风扰估计和实飞轨迹跟踪已有证据；真正待研究的是在有界噪声位置失测、物理输入约束、因果SMF/CZ状态后验下能否得到可实现的输出反馈安全保证。Run246不可生存反例、Run260有限桥、Run261固定零力矩失效、Run262时滞、Run263仅速度宽度界均未被这篇论文解除。**Gate A仍blocked**。

**可行性/创新性/工作量**：2状态低风险但弱物理外推；4状态可复现但仅有限安全；6状态中高难度、可作为物理目标但须阶段门槛；8/9维辨识级联外环具有实飞/代码先例但需重做执行误差合同；完整12/13坐标SMF+NMPC+严格终端安全对硕士主线过重。文献结果是名义性能与计算成本证据，不是本仓库的闭环代码或稳定性证明。
