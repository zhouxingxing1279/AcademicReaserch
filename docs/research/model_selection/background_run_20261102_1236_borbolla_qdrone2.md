## 1. 论文真正控制什么
- **平台**：Quanser QDrone 2 **四旋翼**，质量1.5kg，4个电机、每电机最大标称升力8.5N；OptiTrack Flex13动捕120Hz提供位置，机载IMU提供角状态；NVIDIA Jetson Xavier NX上运行控制、PWM变换和电池电压下降补偿，QUARC/Simulink生成实时代码（§4、§5.1）。真实飞行而非纯仿真；**位置不是仅每5拍有机会且可丢2包的传感器合同**。
- **非线性物理模型**：pp.4–6式(1)–(22)给出四桨力f_i=kω_i²、总推力U1=Σf_i、力矩(U2,U3,U4)由桨差/转速差产生；完整物理坐标可表为(p_xyz,v_xyz,φθψ,角速率pqr)，**6自由度/12个二阶状态坐标**。非线性方程包括姿态耦合、空气阻力、陀螺项；这不是MPC在线使用的完整非线性预测模型。
- **在线MPC模型**：pp.6–8式(29)–(38)在悬停附近做小角度线性化、去耦：x¨=gθ、y¨=−gφ、z¨=U1/m−g，φ¨=U2/Ixx、θ¨=U3/Iyy、ψ¨=U4/Izz。分为**高度2状态**(z,ż)，输入U1；**XY平移4状态**(x,ẋ,y,ẏ)，输入虚拟姿态(θ_d,φ_d)；**姿态6状态**(φ,φdot,θ,θdot,ψ,ψdot)，输入真实广义力矩(U2,U3,U4)。这是2+4+6状态**分解的线性级联**，不能将XY虚拟姿态输入直接当成可立即执行的电机力矩；与仓库平面6状态(x,z,vx,vz,φ,ω)不是同一状态/控制接口。
- **真实执行链**：§4.2/式(55)明确XY MPC输出(φ_d,θ_d)经±45°饱和后由姿态MPC跟踪；高度MPC输出U1，姿态MPC输出U2,U3,U4，再经Quanser给定4×4混控矩阵转PWM、经电池补偿送四电机。式(55)矩阵行：
  [0.0489,-0.4581,0.5566,5.1335],
  [0.0489,-0.4581,-0.5566,-5.1335],
  [0.0489,0.4581,0.5566,-5.1335],
  [0.0489,0.4581,-0.5566,5.1335]。
  **混控矩阵不是对每电机单向推力、饱和、变化率和延迟的鲁棒可实现性证明**。论文未给可用于本仓库的每电机有界混控误差或姿态跟踪误差管束。
- **量测/估计**：§4、§4.2使用动捕位置/IMU角状态；优化反馈使用位置、速度、角度和角速度。正文未核验到可直接复现的速度估计误差有界合同、丢包自动机或状态SMF/CZ。§5.2.1记载35s附近一次通信异常，属于实验现象，**不是**理论上处理有界间歇量测的算法。

## 2. MPC和实验具体证据
- **类型**：LTI分块、离散有限时域二次型滚动优化，代价为输出跟踪Q+输入参考偏差R，§3式(39)–(54)给出堆叠预测和闭式u*=-H^{-1}(...)，式(54)优化域为R^(N n_u)。正文明确姿态命令外部饱和，但**未发现预测内逐电机硬约束、终端集合/终端RPI、鲁棒收紧或递归可行性定理**。不能把“实时MPC实飞成功”升级成鲁棒输出反馈安全证明。
- **表4**：高度MPC N=10、Ts=0.25s；XY MPC N=10、Ts=0.05s；姿态MPC N=15、Ts=0.025s。不同子控制器的采样周期不同；正文没有给20ms最坏优化求解耗时。实验采集5ms并**不等于**三个MPC均以5ms求解。
- **表2**：QDrone 2质量1.5kg，电池14.8V、3700mAh，4电机各最大标称8.5N。四桨标称总推力上限34N与悬停mg≈14.715N有名义余量，但**并不**证明任意力矩命令同时可行，也不能把此机参数复制到仓库1kg配置。
- **§5.2**：QDrone 2实飞螺旋、8字轨迹及吹风机扰动，PIV对照；文中给螺旋轨迹RMSE MPC0.17 vs PIV0.495、8字MPC0.095 vs PIV0.315（按论文位置轨迹量纲理解为m，未重算图8）；风测试风机额定177km/h、3m距离，风作用时长PIV15.96s、MPC13.355s，**非同一扰动序列、不能据此构造统一最坏风扰上界**。实飞性能改进是经验结果，未报告形式化稳定性/递归可行性或20ms WCET。

## 3. 模型选型与SMF接口判断
- **保留**：仓库平面6状态真实T/τ仍为条件性物理首选；四状态固定T理论基线、2状态姿态低风险备选。新增这篇**真实四旋翼2+4+6分块级联MPC**为重要实飞对照，支持“低维分解可实飞”，但不证明本项目的失测SMF/终端可生存性。不是因维数更多而升级12状态全耦合。
- **创新性边界**：级联LMPC+PWM映射+电池补偿+实飞已有公开先例；创新不应仅声称“在四旋翼上采用分层MPC”。有潜力但尚未证明的研究缺口：在间歇有噪位置、速度隐藏情况下，给出集合状态后验到物理T/τ或姿态内环的**可验证误差/输入权限合同**，再证明收紧约束和共享因果终端安全。
- **与主任务**：Run246真实可生存反例、Run261固定零力矩无限失效、Run262三拍力矩延迟、Run263速度宽度界、Run264有限安全桥、Run265绝对速度必要筛选均不被该实飞论文推翻。Gate A仍blocked。提供给主研究任务的接口需求：给出外环虚拟倾角→实际φ/τ的跟踪误差集合Eφ、混控/电机饱和可行域U_phys、失测位置后验X_k及多速率时序，才能评价是否值得从6状态物理MPC改为级联结构。
- **难度/可行性**：实飞级联LMPC可实现性有证据；间歇位置+SMF/CZ+真实执行器硬约束+无限时域递归安全仍为高难未闭合问题。不要把QDrone实飞结果当作本仓库闭环复现。

## 4. 下一轮唯一优先问题
全文核验Bicego等 *Nonlinear Model Predictive Control with Actuator Constraints for Multi-Rotor Aerial Vehicles* 的**四旋翼实飞子实验**，查清其电机推力导数/混控约束是否在优化中直接处理、与本轮后饱和级联LMPC相比能提供何种真实物理约束基线；不另写主任务验证脚本。
