## 2. 论文实际物理模型、传感器、估计器与控制器

- **物理真值**：§II-C式(6)为12状态刚体 `s=(x,y,z,vx,vy,vz,roll,pitch,yaw,p,q,r)`，总推力`T`与三轴力矩`(tau_roll,tau_pitch,tau_yaw)`，式(7)平动、式(8)旋转；数值仿真IMU 200Hz。
- **控制**：§II-C式(9)外环PID加速度指令、式(10)小角度映射姿态与总推力、式(11)内环PD力矩；**不是MPC、Tube MPC或SMF控制**，也未建立鲁棒状态/执行器硬约束的终端递归可行证明。任务规划是A*和minimum-jerk参考轨迹，不等于MPC优化。
- **估计器与量测**：§III-A式(12)使用**9状态EKF** `x_est=(p_3,v_3,b_3)`，其中`b_3`是GNSS偏置；IMU提供高频加速度用于预测，GNSS只提供`z=p+b+nu`的位置观测，**不直接测速度**。式(14) NIS与式(15)–(21)自适应信任度`beta`调节协方差；这是**概率EKF点估计及协方差**，既不是有界状态SMF也不是参数SMF。
- **时序与退化**：§IV Algorithm 1在GNSS延迟到达时对历史`k-d`状态更新并重传播；§V-A仿真IMU 200Hz、控制/GNSS 20Hz、延迟上限1.2s、空间相关多径偏置标准差上限1.2m。**有延迟/多径，未建立仓库每5拍测量机会、最多连续miss两包的确定性丢包自动机**；不能将20Hz GNSS或延迟直接写作该自动机。
- **不确定性**：§III–IV为零均值随机过程噪声、随机多径偏置与随空间变化的协方差；没有给出覆盖全部合法扰动/噪声样本的有限确定性支撑界。论文的`beta`可信度与EKF协方差**不能直接充当SMF的硬集合包含证书**。
- **结果/边界**：§V用Python模拟10个城市任务，论文报告估计误差下降80%、跟踪误差下降30%（相对其对照/仿真设置），未核验硬件飞行、独立重复实验或最坏时延。作者明确称控制器与规划器不是本论文新贡献；未见本仓库所需逐拍硬约束、终端信息状态可生存核或递归可行证明。

## 3. 对仓库的精确对照与模型选择

| 接口 | Panda/Guo 2026预印本 | 仓库当前冻结合同 |
|---|---|---|
| 物理状态 | 12状态完整刚体；估计器9状态p/v/GNSS偏置 | 六状态平面`(px,pz,vx,vz,phi,omega)`候选；Run249/250为四状态横向子系统 |
| 控制输入 | `T`与三轴力矩，分层PID/PD | 六状态`(T,tau)`；四状态固定`T=9.81`、优化`tau` |
| 可用传感器 | 高频IMU加速度、20Hz GNSS位置、可延迟 | 每拍有界`phi,omega`；每5拍有机会有界位置，最多连续丢2包；**未提供独立加速度观测** |
| 估计语义 | EKF协方差、GNSS偏置增广、历史重传播 | 区间/关联SMF有界真值包含；Run249严格仅固定55拍 |
| 证明 | 估计/跟踪仿真改善，无硬安全终端证书 | Run250证明零力矩备份全初始盒最多67拍；无无限递归可行 |

**重要信息权限纠偏：** 不能把该论文IMU高频加速度直接加入当前四/六状态控制器并继续宣称“同一量测假设”。若新设IMU辅助实验，必须定义`y^a=a(x,u)+b_a+n_a`的物理量、坐标变换、偏置/漂移/饱和界、时钟延迟、与姿态估计的相关性；然后重新证明SMF包含及控制约束。GNSS`z=p+b+nu`有偏置—位置混叠，仅凭单次位置测量不能独立辨识二者；需动态先验和偏置演化约束。

**模型选择结论：** 不因论文用12状态就升级硕士主模型。**条件性首选仍是六状态平面四旋翼**（两输入物理闭合）；**实际已验证的第一证明/闭环平台仍为四状态**（Run249/250），姿态2状态保底。将“高频IMU＋低频/延迟GNSS”作为**后续实验场景**而不是当前冻结合同；优先解决Run249/250的共享因果终端与20ms求解预算。该预印本强化了“有噪间歇位置/延迟”具有现实背景，却**没有证明**SMF＋MPC硬安全的创新性、可行性或该模型的完整闭环。

**创新性：** GNSS-IMU延迟融合、EKF和级联控制均非本项目可独占的创新；待验证的增量是有界状态后验、有限计算预算和因果安全前驱的接口。**可行性：** 四状态有限55拍可行，六状态/无限终端未知。**难度：** 加IMU偏置/延迟会扩大信息状态与时间索引，暂不应同步引入。
