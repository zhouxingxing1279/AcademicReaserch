## 2. 本轮正文核验：Sasfi、Zeilinger、Köhler (2023)

- 论文：*Robust adaptive MPC using control contraction metrics*, Automatica 155 (2023) 111169；DOI https://doi.org/10.1016/j.automatica.2023.111169；开放作者稿 https://arxiv.org/html/2209.11713v2 ，arXiv https://arxiv.org/abs/2209.11713 。核验§2.1、§3.1–3.5、§4及关键公式(1),(8),(14),(16),(18)、Theorem 6/12。
- **精确状态**：x=(p1,p2,φ,v1,v2,φdot)，其中v1、v2是**机体系速度**，而p1、p2是惯性系位置；不能误记为惯性系(vx,vz)。控制u=(u1,u2)为左右旋翼推力，合推力T=u1+u2，力矩τ=l(u1−u2)。论文动力学包含v2 φdot、−v1 φdot及位置旋转矩阵。
- **论文观测权限**：§2.1假设状态x(t)可测，§3.3进一步假设x和u精确测得、带有界误差的状态导数测量；SMF交集(14)更新的是固定未知参数θ=1/m的集合Θ_t，不是隐藏速度的状态后验。论文**没有本仓库的有噪位置丢包问题**。
- **不确定性和约束**：§4质量倒数θ初始±1%，风扰d∈[−0.1,0.1]；|φ|≤π/3、|φdot|≤π、|v1|≤2、|v2|≤1、u_i∈[−1,3.5]，以及避障几何。u_i负下限是该论文优化模型的数学输入域，不能不经物理解释直接当作真实单向推力旋翼执行器。
- **理论保证**：CCM Assumption 1+终端Assumption 10+初始MPC可行时，Theorem 12保证连续时间模型的递归可行与约束满足，并证明名义轨迹趋近参数依赖参考；不是对当前离散Euler、间歇测量、未知速度的现成定理。
- **计算和实验**：§4使用RK4、Ts=150ms、N=25、3.75s时域、CasADi/IPOPT，MATLAB笔记本仿真；仅在采样点施加数值约束；展示参数更新后更小的tube与路径变化，不是硬件实飞，也没有20ms最坏耗时证书。
- **物理转换**：仓库惯性系(vx,vz)与论文机体系(v1,v2)通过旋转矩阵相连，必须同步转换风扰和噪声，不能复制论文速度方程到仓库状态顺序。

## 3. 仓库六状态与四状态的模型闭合性差异

仓库连续基础模型：p̈_x=−(T/m)sinφ+r_x，p̈_z=(T/m)cosφ−g+r_z，φ̈=τ/J；配置m=1kg、J=0.02kg·m²、h=0.02s。四状态冻结T=mg、删除(p_z,v_z)，在r_z=0时仍有p̈_z=g(cosφ−1)；φ≈0.22rad时约−0.236m/s²（仅瞬时值，非完整轨迹证书）。若要严格保持高度，理想T=mg/cosφ，但必须检查推力上界、垂向扰动和失测。该式只在r_z=0、无推力误差时成立。

原始六状态配置的r_x界为1.88+(243/16000)T m/s²、r_z界为2.086+(81/800)T m/s²，且随实际推力变化；在T=9.81N时分别为2.028989375、约3.0792625m/s²。它们显著大于Sasfi §4的风扰±0.1，**不能用Sasfi的可行数值结果证明本仓库配置可行**。当前Run247已认证固定倾角策略在合法负向极端扰动下第26拍不可恢复；必须先验证非空双向鲁棒可生存域，不能只换成六状态便宣称问题解决。

## 4. 决策门槛（不并行孵化）

**当前首选：六状态平面四旋翼作为最终物理建模目标；四状态作为已认证理论/负面基线；姿态2状态作为闭环保底。** 暂不启动新的六状态控制器分支，待主控制任务完成最小因果信息状态可行性测试。

选型先过三道门槛：① 确认六状态初始集合和两侧持续扰动下，存在非空的可生存状态/信息集合（允许先在明确缩小的有依据扰动域探索，但不能偷改原证书）；② 给出位置缺测success/miss自动机下可实现的共享输入及状态SMF包含接口；③ 测定一个可运行的闭环基线及求解耗时，明确20ms目标是否可达。若①或②长期阻塞，退回可完成的姿态/4状态有限安全过滤课题，而不是继续扩维。

**创新性边界：** Sasfi 2023已有“CCM+参数SMF+Tube MPC+平面四旋翼”，因此本项目不能把这些词的组合视作新颖；可研究的差异在**有噪、间歇位置测量下的状态SMF、因果共享控制和可生存终端接口**，但是否可证明、是否优于简单基线均待验证。
