## 新增核验：多旋翼NMPC与不确定性避障
- Mina Kamel, Javier Alonso-Mora, Roland Siegwart, Juan Nieto, **Robust collision avoidance for multiple micro aerial vehicles using nonlinear model predictive control**, IEEE/RSJ IROS 2017, pp.236–243, DOI https://doi.org/10.1109/IROS.2017.8202163 ；作者预印本 https://arxiv.org/abs/1703.01164 ；TU Delft机构记录 https://repository.tudelft.nl/record/uuid:1d6d2497-a76b-42e0-8b15-88a1df89a0a4 。
- **核验日期**2026-11-03；**等级：书目与摘要核验，未读取全文**。尝试访问arXiv PDF/HTML失败，机构库页面超时。完整作者、出版信息、DOI、真实多旋翼实验（两台MAV）由机构记录支持；不能伪装为全文已读。
- **已确认**：多旋翼轨迹跟踪与分布式避障的NMPC，考虑自身状态估计不确定性及其他飞行器位置/速度不确定性；仿真及双MAV实验。
- **无法从全文确认**：状态向量逐项及维数、动力学离散化与采样周期、总推力/力矩或体角速度虚拟输入、执行器动态/饱和/变化率、具体传感器、估计器类型、概率或确定性不确定性语义、代价与约束精确表达、预测时域、求解器、最坏求解耗时、终端集合、递归可行性定理条件及硬安全证书。**不可由题名推断Tube MPC、SMF/CZ或确定性硬约束保证**。
- **对本课题的价值**：证明多旋翼NMPC在动态避障和状态估计不确定性处理方面有真实实验先例；但摘要所称“robust”不能直接支持本项目的有界噪声间歇位置测量、集合包含、共同因果输入、逐桨硬约束或无限时域安全。
- **下一步待核**：取得作者接受稿，逐式读取动力学、估计误差如何进入避障约束，以及是否给出确定性保证；在此之前不改变模型首选排序。

## 模型矩阵判断（本轮仅证据层增量）
- **条件性首选不变**：平面六状态`(p_x,p_z,v_x,v_z,phi,omega)`、物理抽象输入`(T,tau)`；尚需混控/推力动态外包、位置间歇后验及因果终端可行性。
- **备选不变**：四状态固定推力有限安全数学基线；二状态姿态闭环保底；分层MPC为待验证接口方案。
- **不升级**：多飞行器避障论文不是本项目单机平面模型的直接物理硬安全证明，也不因全状态维数更大而优先。
- **SMF/CZ新颖性边界**：估计不确定性参与NMPC并非新颖；需在全文确认其概率/集合语义后，才可比较SMF后验初始化、Tube收紧及终端信息集合的差异。
