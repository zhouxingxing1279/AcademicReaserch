## 3. 状态、输入、传感器与执行链
- 真实机体：标准单向推力四旋翼，6物理自由度，1.3kg AscTec Pelican；作者围绕悬停点采用偏航固定、水平轴解耦、姿态低层闭环经验二阶模型。
- **MPC状态10维** `x=(x_N, vx_N, θ, θdot, x_E, vx_E, φ, φdot, x_D, vx_D)`；其中2个横向位置/速度/角度/角速各4维＋竖直位置/速度2维。离散仿射 `x+=Ax+Bu+k+h(x,u)`，`A∈R10×10,B∈R10×3`；步长25ms。不是完整6DOF直接逐桨刚体模型，也不包含偏航、电机转速或实际逐桨推力状态。
- **优化/施加的上层输入3维** `u=(θ_s, φ_s, T_s)`，分别为期望俯仰、横滚和总推力**命令**；不是逐桨 `f_i` 或 `dot f_i`。优化后施加 `u_m=K xhat_m+c*_m`；底层专有飞控以1kHz实现姿态角闭环、推力开环，串口40Hz传命令。论文**未披露足以认证**四桨混控、每桨ESC最终指令、饱和后残差、单桨速率或确定性最坏误差集合。不能由 `u∈U` 直接推出逐桨硬约束。
- 观测 `y=(x_N,θ,x_E,φ,x_D)+ε`，`C∈R5×10`，速度/角速度隐藏；Vicon 120Hz提供三维位姿，EKF估计状态并在线学习12个模型修正参数。测量噪声按有界随机量建模；**无每5拍位置机会、连续双丢包自动机或状态SMF/CZ可靠后验**。EKF联合状态/参数估计 ≠ 参数集员滤波 ≠ 状态集合滤波。

## 4. MPC约束、理论/实验与时间
- **LBMPC**：名义模型用于约束，学习修正的oracle模型用于性能；在线QP，阶段/终端二次跟踪成本，`X,U`多面体，`X⊖D`收紧及近似最大允许扰动不变集合 `ω`；预测 `N=15`，25ms采样即名义预测0.375s。QP为LSSOL，在板载1.6GHz Intel Atom N270上40Hz执行；**25ms控制周期超过本仓库20ms目标**，不是论文报告的单次求解WCET。
- 论文§IV展示名义模型/学习模型分离及扰动不变集接口，但具体严格保证来自相应LBMPC理论条件；**本论文实飞不等于**所有有界位置丢包/执行误差下的递归硬安全。末端集合`ω`不是本项目带success/miss自动机的终端**信息状态**RCI。
- 真实四旋翼Vicon实验：近地悬停学习到约6%有效推力增益；指定水平阶跃案例相较线性MPC超调减少62%；恶意调错学习时高度明显下降但未触地，实验期间QP保持可行；接球实验作者报告>90%但未进行可控重复试验。上述均为**论文实飞观察**，不是确定性硬安全证明。
- 实际电机型号、桨臂、逐桨推力/变化率、ESC误差最坏界、真实最终逐桨命令、求解最坏时间、GPS/IMU型号、位置丢包策略、终端集合精确参数、公开完整复现配置：**未报告或无法从所读全文确认**。

## 5. 独立检查、模型矩阵变化与SMF/CZ边界
Python 3 `fractions.Fraction` 独立核对：`4+4+2=10`状态，`2+1=3`虚拟输入，`15×0.025=0.375s`预测域，`1/40=0.025s>0.020s`；**算术通过，不是MPC回归/飞行复现**。
本论文是**标准健康单向四旋翼真实机载LBMPC**，但约束权限仅到`(θ_s,φ_s,T_s)`；其1kHz专有低层姿态环和推力开环**不能被当作**已认证的逐桨 `(T,τ)` 共同行为。因此对第24轮Nan后置INDI问题形成互补：两类实飞架构都缺少本仓库所需“最终ESC命令+执行误差的确定性硬合同”，但**不能宣称它们已经违反硬约束**。
- 首选仍是**条件性六状态平面** `(p_x,p_z,v_x,v_z,φ,ω)`，输入`(T,τ)`；需执行器混控、上一拍推力集合、状态/量测后验及终端Gate A。4状态固定推力保留有限数学基线；2状态姿态/高度备选；10状态上层LBMPC是已有机载实飞架构对照，不因实飞自动升级。
- 创新性：学习型MPC、鲁棒收紧和在线状态/参数估计已有真实四旋翼实飞先例；不能声称“首次四旋翼输出反馈/学习MPC”。本项目可研究**有噪间歇位置状态SMF/CZ后验、共享因果输入、物理逐桨执行器合同与终端信息集合**，仍是待验证组合，非已证明创新。
- Run246可生存性反例、Run260/261终端阻塞及Run272隐藏速度重复混叠均不受该论文消除；Gate A=blocked。
