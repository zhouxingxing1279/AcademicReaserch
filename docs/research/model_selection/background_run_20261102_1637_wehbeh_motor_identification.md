## 2. 新核验原始四旋翼MPC论文（不是综述）
Jad Wehbeh, Inna Sharf (2024), *Nonlinear scenario-based model predictive control for quadrotors with bidirectional thrust*, *International Journal of Robust and Nonlinear Control* **34**(18):12450–12475, DOI https://doi.org/10.1002/rnc.7627 。2026-11-02阅读出版社开放HTML全文的§2.1–2.4、§3.1及QP推导、§4.3、§5.1–5.2、§6.1–6.3、§7及表1–5；附录1/2公式未独立逐式审计，非PDF逐页核对；状态：**开放正文分节已读**。全文 https://onlinelibrary.wiley.com/doi/full/10.1002/rnc.7627 。

- **控制对象/任务**：具有可反向旋转、可产生负推力的特殊四旋翼；悬停恢复与半翻滚跟踪，非标准单向桨的真实飞行。物理6自由度刚体，状态`(r_a[3],v_a[3],C_ab∈SO(3),ω_b[3])`，局部12维独立坐标；矩阵C有9个元素但只有3个旋转自由度。连续Newton–Euler模型(1)–(4)在当前估计状态/输入附近SO(3)局部线性化，再用零阶保持离散式(17)–(20)，姿态误差小量近似。没有把4个电机推力增广为优化状态，不能与Bicego的16维状态混淆。
- **输入/执行器**：`u=(T1,T2,T3,T4)`为**带符号**四桨推力，式(5)混控得到总推力与三轴力矩。§2.2速率边界由**双向电机**的推力—时间非线性曲线描述，假设各桨独立、正负对称、速率只依赖当前桨力；原始数据指向Jothiraj(2020)硕士论文的T-Motor Air 2213/920KV＋APC-3D 9×4.5对称桨。§6.2表2仿真用`m=1kg,Tmax=7N/桨,t_ramp=0.2s,几何参数c=0.166m,J=(0.0122,0.0126,0.0239)kg m²`。这些数是**作者仿真模型/曲线拟合设置**，不是本仓库平台的最坏硬件界；Jothiraj原始实验/ESC误差未在本轮独立读取。平均爬升斜率7/0.2=35N/s不等于逐时刻可靠最大变化率，更不能替代状态依赖速率函数。

## 3. 独立静态幅值可行性检查（非论文定理/非硬件认证）
仅为跨论文参数的**假设性演示**，暂设标准十字四桨单向幅值`0≤f_i≤7N`、桨臂`l=0.166m`，忽略电机动态/误差，沿用背景第20–21轮零滚转/偏航力矩逆混控
`f=(T/4-τ/(2l),T/4,T/4+τ/(2l),T/4)`。
对仓库**配置**`T∈[4.905,14.715]N, |τ|≤0.08Nm`，该线性映射的全盒逐桨极值：
`min_i f_i=4.905/4-0.08/(2×0.166)=65423/66400≈0.98528614N>0`；
`max_i f_i=14.715/4+0.08/(2×0.166)=260269/66400≈3.91971386N<7N`。
Python 3 `fractions.Fraction`精确分数断言已运行通过（本轮静态验证，不是仓库测试）；`7N/0.2s=35N/s`仅为平均爬升斜率，不能假定`h=0.02s`时每拍可变`0.7N`。上述幅值对照**既未使用论文的双向电机动态，也未校准真实l、ESC、桨力跟踪误差、上一拍桨力集合**；故不能宣布真实共同输入域非空，尤其不能覆盖Run268/269的观测纤维。真实硬约束须使用第21轮`L_i≤f_i^*(T,τ)≤U_i`并提供经过实验可靠认证的速率/误差区间。

## 4. 模型矩阵、主任务接口、创新性和难度
首选仍是六状态平面`(p_x,p_z,v_x,v_z,φ,ω)`、双输入`(T,τ)`，仅**条件性物理首选**；四状态固定推力保留有限安全/负面基线；2状态姿态保底；12维局部刚体/16维电机NMPC与双向桨scenario MPC为高工作量对照。对2/4/6/10/12及分层模型的既有证据不因本轮参数示例升级。SMF/CZ可能提供上一拍桨力集合和状态信息集合，但Wehbeh使用的是概率MEKF/抽样，**不能称作已实现SMF+MPC**；创新空间须与Le(2011)、Ping/Sun(2015)、Köhler等(2021)比较，未证明首次性。
