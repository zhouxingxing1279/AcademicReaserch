## 3. 新的可复核正向有限安全证书：真实hover初始盒

在六状态定义Euler真值下，取**同一因果输入**`T_k=g=981/100 N, tau_k=0`，连续`N=15`拍；每个初始真值属于上述完整六状态初始盒，所有每拍独立扰动满足
`|r_x|≤47/25+(243/16000)T`、`|r_z|≤1043/500+(81/800)T`。在`T=g`时严格有理数得到`R_x=3246383/1600000=2.028989375`、`R_z=246341/80000=3.0792625`m/s²。用`|sin(phi)|≤|phi|`和`0≤1-cos(phi)≤phi²/2`（本轮角度极小）：

- `omega_k=omega_0`，`|omega_k|≤0.01`；`|phi_k|≤0.005+0.0002k`。对控制作用时刻`k=0,...,14`，`|phi_k|≤39/5000=0.0078`，终点`|phi_15|≤0.008`。
- 全15拍可用统一加速度绝对界`A_x=R_x+g*(39/5000)=16844059/8000000=2.105507375`、`A_z=R_z+g*(39/5000)^2/2=15397804601/5000000000=3.0795609202`m/s²；这是外包而非精确可达集合。
- 对`k≤15`，`|v_{x,k}|≤0.1+k h A_x`，`|v_{z,k}|≤0.1+k h A_z`；`|p_{x,k}|≤0.02+k h*0.1+h²*k(k-1)A_x/2`，`|p_{z,k}-2|≤0.02+k h*0.1+h²*k(k-1)A_z/2`。故在终点`|v_x|≤0.7316522125`、`|v_z|≤1.02386827606`m/s；`|p_x|≤0.13843130975`m、`p_z∈[1.8206584413516,2.1793415586484]`m，所有中间拍更紧，全部硬状态和输入约束成立。
- 上述控制不读取隐藏速度、量测或未来丢包，故**对所有与先验一致的success/miss及有界量测噪声历史**，其SMF后验（若正确计算）都包含在这条完整先验的有限可达外包中；5/10/15拍的任意合法success/miss分支不改变物理安全结论。特别是它给出了**非空共享输入的15拍局部有限安全内证**，比仅证明单个状态有可用T更强。**它不构造SMF后验、也不保证从第15拍重复同一15拍策略安全，不能称为终端信息RCI。**
- 若`T_act≠T_cmd`、扰动界不同、连续真实动力学含Euler余项、风偏置跨步相关未被界覆盖，须重新认证；不能移植此有限证书。Run250/246已警示重复零输入或有限时域安全无法自动得到无限递归安全。

**精确算术核验：** 2026-11-02 UTC，在隔离Linux Python 3.13.5用标准库`fractions.Fraction`计算全部上式，并对`|v_z,15|<3`、`|p_z,15-2|<1.5`、`|phi_15|<0.45`执行断言，输出`ALL_EXACT_BOUND_ASSERTIONS_PASSED`；三角不等式是解析证明，Fraction只核验有理数代数。未运行六状态SMF/MPC、无算法CI或全仓库回归；无新增控制代码。
