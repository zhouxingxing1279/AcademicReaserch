# 阶段 3 · 已有结果与研究空白

**首先要判定的是块末要求本身是否可达。** 在本地有限记忆算例允许的一条四拍交付历史上，即使使用全部已收数据，第 4 拍速度误差所能保证的最小半径也是 \(1/25\) m/s，大于初始速度半径 \(1/100\) m/s。相反，放宽到现有统一界又会掩盖各相位的差异。值得研究的问题是给定语言、初始准入和目标界后，如何判定哪些恢复要求可达，并识别不能达标的前缀。以下“开放”限于已核文献与本地合同。日期为 2026-11-05。

## 一拍决策能看到什么

外环为 \(x=(p,v)\in\mathbb R^6,\ x^+=Ax+Bu+Gw,\ y_s=[I_3\ 0]x_s+\nu_s\)。\(u\) 是抽象高层命令，过程及量测误差各自满足规定硬界。十二状态非线性四旋翼留作后续验证。令 \(a_s\) 为生成戳 \(s\) 的交付拍。决策先处理本拍到达，再施加 \(u_k\)。可见历史 \(h_k\) 含截至 \(k\) 的交付拍、戳、值、空到达记录及实际已施加输入。未生成、已生成仍在途、已生成后永久丢失是三种物理事件；在线只能按可见前缀区分。有限记忆特例要求已生成包限时必达，一般语言允许永久丢失时，须另订有效戳的新鲜度条件。[模型合同](MODEL_CONTRACT.md) · [有限记忆合同 §§1–4](proposal/FINITE_MEMORY_THEORY.md)

用 \(S(h_k)\) 表示与这份历史相容的全部轨迹在当前状态上的投影。若发送事件可能依赖状态，须同时建模事件本身携带的信息。下表沿用外生时序假设。阶段 2 的 M、N、F 编号沿用原阅读卡。[核心文献对照](../literature/stage2/key_comparison.md) · [逐篇出处与原文定位](../literature/stage2/reading_cards.md)

## 一个可以精确核对的块末下界

取单轴 ZOH 的 \(T=1/2\) s，\(G=B=(T^2/2,T)^\top\)，\(|w_i|\le a=1/50\) m/s²，\(|\nu_s|\le n=1/200\) m，初始盒以零为中心，半径为 \((n,1/100)\)。选择合法已知输入 \(u_0=\cdots=u_3=0\)。在 \(M=L=1\) 的合同下，第 0、3 拍未生成，第 1、2 拍各自即时交付零位置读数，第 4 拍的样本到第 5 拍才交付。从第 5 拍起可持续按时生成与交付。这是一个可以延长的前缀。[参数与启动界](proposal/FINITE_MEMORY_THEORY.md)

取 \(\sigma\in\{-1,1\}\)，令 \(p_0=-\sigma n,\ v_0=0,\ w_0=\cdots=w_3=\sigma a\)，在戳 1、2 取 \(\nu_s=-p_s\)。由于 \(p_1=-\sigma/400,\ p_2=\sigma/200\)，两次误差均合法。在决策 4，两条轨迹的可见历史完全相同，真实末状态为
\[
(p_4,v_4)=\sigma(7/200,\ 1/25).
\]
任何共同估计在每个坐标上的最坏误差，至少为该坐标两端差的一半。

**该历史还给出相同的上界。** 由两步 ZOH 消去 \(v_0\)，有
\[
v_2=(p_2-p_0)/(2T)+(T/4)w_0+(3T/4)w_1 .
\]
既有初始位置硬界又有 \(y_2=0\)，故 \(|v_2|\le 2n/(2T)+Ta=1/50\)。再传播两拍，得 \(|v_4|\le 1/25\)，\(|p_4|\le n+2T/50+(2T)^2a/2=7/200\)。全零轨迹也相容，所以零是可行代表点，两个半径可同时达到。该盒给出精确的**坐标半径**，盒的任意角点未必在后验内。

因此，只要验收目标含这个启动块且要求第 4 拍回到原始盒半径，任一因果估计器都无法保证。数值针对该份历史，不能据此定出其他块末的统一最优界，也不能推出控制不可行。三轴独立合同中可将其余两轴固定为零，得到六状态的同一坐标障碍。耦合残差或不同交付合同须另审。

**有理数复算。** 以下程序核对事件合法性、共同读数、上下界与极值轨迹。使用 Python 标准库，命令、噪声、初值均已列出，无随机采样。

~~~python
from fractions import Fraction as F

T, a, n = F(1, 2), F(1, 50), F(1, 200)
arrivals = {1: 1, 2: 2, 4: 5}
assert all(s <= t <= s + 1 for s, t in arrivals.items())
assert all({s, s + 1} & arrivals.keys() for s in range(4))

def trajectory(sign):
    p, v = -sign * n, F(0)
    states = [(p, v)]
    for k in range(4):
        p, v = p + T*v + T*T*sign*a/2, v + T*sign*a
        states.append((p, v))
    history = []
    for s, t in arrivals.items():
        if t <= 4:
            noise = -states[s][0]
            assert abs(noise) <= n
            history.append((t, s, states[s][0] + noise))
    return states[-1], tuple(history)

positive, hp = trajectory(1)
negative, hm = trajectory(-1)
v2_bound = 2*n/(2*T) + (T/4 + 3*T/4)*a
v4_bound = v2_bound + 2*T*a
p4_bound = n + 2*T*v2_bound + (2*T)**2*a/2
assert hp == hm == ((1, 1, 0), (2, 2, 0))
assert positive == (p4_bound, v4_bound) == (F(7, 200), F(1, 25))
assert negative == tuple(-q for q in positive)
print(hp, positive, negative)
~~~
