# 研究短检查点（2026-09-28，Run 124）

主命题：在四旋翼外环可靠状态集合与扰动合同下，研究面向控制约束方向的在线集合表示及安全压缩，贯通输出反馈 tube MPC 的收紧、终端、递归可行性与同预算优势；学习方法暂停。

仓库：`main` 1c49659c；本轮基于 Run 123 的 47b46b1。精读 Scott 2016 Sections 3.1/4/5（安全 CZ 外包降阶）与 Raghuraman–Koeln 2022 Section 5（内近似，不能压缩可靠后验）；Robbins et al. ACC 2026 仍仅有摘要。对 602 潜变量后验构造固定 300 行控制方向 H-template；每个 cap 由浮点对偶提议经精确有理数弱对偶残差上界及向外舍入认证。全余量 LP 找到非零重定心 `alpha=0.12264`、`||d0||inf=0.001717`，使用认证 cap 后 300 条阶段约束最大超额为零，nominal 终点归零。

证据等级：模板外包含和列入方向的安全支持上界为条件性证明；LP 数据为数值观察。整体准入仍失败：若保持物理集合的精确平移，则 `d_i=F^i d0`；因 `det(F)=0.6999615978 != 0`，冻结零 nominal 终端只允许 `d0=0`。允许一般 nominal 修正虽通过阶段余量，却不再继承 Run 121 的 terminal mRPI 包含。

下一唯一问题：为实际 Run-124 非零候选构造可执行的终端包含证书 `E_N(d0,a) subseteq S`；若失败或只能退化为 `d0=0`，停止重定心主张，仅保留 300 行模板为固定复杂度压缩基线。
