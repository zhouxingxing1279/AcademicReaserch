# OIT–CZ 输出反馈管束的创新性与可证伪性评审

2026-11-05。评审对象为工作树中的[命题审计](OIT_MRPI_THEORY_AUDIT.md)，重点是 §4 用逐拍创新构造可移位管束的主张。**建议否决以“首次逐步遗忘历史、得到显著更优控制”定题。** 可以保留该原型作为有证明条件的基线。以下区分已有机制、实测反例和仍开放的命题。

## 三项主要审稿意见

1. **最接近的前作已经把逐步遗忘用于同一个问题。** Brunner、Müller、Allgöwer 研究有界过程扰动和测量噪声下带硬约束的线性输出反馈 MPC。其机构摘要直接将“预测越远、使用的过去量测越少”与递归可行性、有界复杂度关联起来。以 CZ 表达同一思想可以回答怎样实现。要主张理论增量，还须指出前作哪项假设被严格放宽，或在同一合同下多保证了什么。这里只核到期刊机构摘要，逐定理等价仍待全文对照。定向检索式为 `output feedback MPC set-valued moving horizon estimation`，OpenAlex 和 Crossref 均返回 HTTP 200，合并去重后 20 条，2018 期刊版、2016 会议版分列前两位。[Brunner 等，IEEE TAC 2018，2976–2986](https://research.uni-hannover.de/en/publications/enhancing-output-feedback-mpc-with-set-valued-moving-horizon-esti/)
2. **联合建模有价值，但应把创新主张定位到具体差异。** Lorenzetti–Pavone §IV-E 式 (12) 已把 \(x-\hat x\) 和 \(\hat x-z\) 堆叠，用同一测量噪声驱动两行，再从联合 RPI 收紧约束。其观测器时序与本稿后验更新有别。Cong 等已提出 OIT 和 OIT 启发的 CZ 滤波，解决初始先验与滤波稳定性。本文可能有别之处是给定已知边界偏差，保留同一段轨迹上的创新等式，再投影到活跃约束。它需要独立证明能提供什么额外信息。命题 A 的单调包含、C 的精确 mRPI 单调性都是直接推论。D 的固定模板仿射证书还需与已有仿射多面体包含 LP 区分。固定模板证书不完备，一次 LP 不可行不能证伪真实包含。[Lorenzetti–Pavone，作者稿 §IV-E](https://arxiv.org/pdf/1911.07360#page=4) · [Cong 等，作者稿](https://arxiv.org/abs/2203.13966) · [Sadraddini–Tedrake，仿射多面体包含](https://arxiv.org/abs/1903.05214)
3. **减小几何半宽、扩大可行域、降低实际代价是三个不同主张。** 从原始 CSV 重算，12 条配对轨迹上，真实累计代价相对固定管的下降中位数为 16.3463%，相对已知当前偏差基线为 0.005449%，后者最大值为 0.044875%。详细运行中自适应方法耗时中位数 30.3209 ms，0/360 步满足 20 ms。原报告的 10,000 条内部轨迹共 300,000 步均采用可行的无约束最优解，在线受约束 QP 调用为零。可行性与实时优势需要在实际激活约束的记录上比较。[配对代价](../../../experiments/results/oit_mrpi_20261105/closedloop_summary.csv) · [逐步计时](../../../experiments/results/oit_mrpi_20261105/closedloop_detailed.csv) · [批量运行记录](../../../experiments/results/oit_mrpi_20261105/montecarlo.json)

## 在原算例上分离历史创新的贡献

复用原二维双积分器、固定 \(K,L,S\)、窗口 \(\ell=3\)、时域 \(N=15\)、共同终端和 775 个名义状态。冻结原网格所用的零创新记录，所有已知 \(d_j=\hat x_j-z_j=0\)。用零目标可行性 LP 逐点比较，四种设置使用相同的状态和输入约束。

| 可见信息及传播方式 | 可行点 |
|---|---:|
| 当前层使用 \(S\cap\{d=d_k\}\)，未来各层用 \(S\)（原强基线） | 535 |
| 将同一当前切片向未来传播，\(i<3\) 使用预测，随后接 \(S\) | 547 |
| 从每层原有窗口的边界出发，只固定边界和当前两个 \(d\)，保留动力学，放开中间创新 | 549 |
| 同上，并加入原窗口逐条创新等式 | 549 |

第二行相对第一行新增 12 点，仅来自传播已知偏差。第三行再增加一对边界点 \(z=\pm(7/3,2)\)。第四行与第三行逐点完全一致。在这对点上，最小化所有原始约束行残差的最大值，第二行为 \(+0.00025151\)，第四行为 \(-0.00166307\)；这里只比较符号。第三行使用历史端点，端点本身携带测量信息。该结果限于同一信息切片，第三行的跨拍递归可行性需要另证。[原网格与四种已存方法](../../../experiments/results/oit_mrpi_20261105/feasible_grid.csv) · [原控制器和收紧方式](../../../src/oit_mrpi/control.py)

**为何会相同。** 记 \(F_d=A+BK\)。后验观测器满足 \(d_{j+1}=F_dd_j+Lr_{j+1}\)。给定 \(d_{k-2},d_k\) 就知道

\[
d_k-F_d^2d_{k-2}=[F_dL\quad L]\begin{bmatrix}r_{k-1}\\ r_k\end{bmatrix}.
\]

冻结增益下，两列行列式约为 \(0.45322446\)。按存档十进制增益作有理数复算，行列式严格落在 \((0.4532,0.4533)\)。因此两端固定后，两条标量创新有唯一解；单条创新由 \(L\ne0\) 唯一确定。对任意相容记录，预测层 \(i=1,2\) 各使用至多二条、一条过去创新，此处显式写入创新等式不会进一步收紧。第 0 层可以使用三条创新，尚可改变当前状态准入，但输入修正 \(Kd_k\) 已知。第 3 层起两者都用 \(S\)。因此，在都通过当前准入的同一历史和名义状态上，两个名义 QP 的决策约束及严格凸目标相同，首个控制量必相同。这个结论依赖本算例的秩、窗口与控制律，不要求两方法在所有历史的当前准入域一致。[冻结增益](../../../experiments/results/oit_mrpi_20261105/controller.json) · [观测器递推](../../../src/oit_mrpi/estimation.py)

复算采用 Python 3.11.9、NumPy 2.4.6、SciPy 1.17.1 的 HiGHS。第三、四行以各时刻的 \(\eta\)、初始 \(S\) 的生成系数、逐拍有界噪声为变量。对 \(i=0,1,2\)，从 \(k-(3-i)\) 起建模，约束起点和时刻 \(k\) 的 \(d\)；传播到 \(k+i\)，在六个状态/输入约束方向各求一次支持。两行只切换过去 \(3-i\) 条创新等式。第四行 18 个支持值与原 CZ 实现的最大绝对差为 \(1.50\times10^{-8}\)，与原 CSV 的可行点集合完全相同。该核对使用浮点 LP。此次重算了网格与已有 CSV 统计，没有续跑闭环仿真。

## 哪些结果会推翻哪些主张

| 主张 | 判别方法与否决条件 |
|---|---|
| 在给定合同下，窗口控制器递归可行 | 固定正确模型与误差集，从准入且初始可行的状态出发，检查每种相容下一创新，包括启动期和接入尾管的边界。若能给出方向 \(q\) 使 \(h_{P_{i\mid k+1}}(q)>h_{P_{i+1\mid k}}(q)\)，就推翻该移位包含引理。若要推翻递归可行性本身，还须给出新问题确实不可行的相容后继。求解器超时、越过噪声硬界各自回答不同问题。 |
| 保留创新等式能让控制决策受益 | 预先指定系统、窗口和端点信息，先找端点允许多组相容创新的情形，再检查这些创新是否在某个未来活跃约束方向产生严格支持差。要声称控制收益，须进一步给出基线不可行而本法可行的证书，或共同可行时首个命令或实际代价的可重复改善。本文冻结算例已排除在共同准入域靠重复加入一至两条创新改变首个命令的解释。 |
| 同预算下有实用优势 | 冻结预算、初值、噪声记录及最低有意义的收益，使用相同信息的轨迹 LP 和有保证的简化控制器作对照，计入超时、空后验和提前终止。原实现的 20 ms 逐拍目标已在详细记录上失败。 |

**评审决定。** 宽泛的窗口移位首创主张在 `light-idea-critique` 的碰撞检查中返回 `critical/fail`，对应 Brunner 2018。精确组合的全球首创性仍待逐定理核对与独立领域复审。可保留的研究问题是“给定两端偏差后，哪些尚未确定的创新分量能改变活跃约束或状态准入？”本轮只评该草稿。间歇、乱序、永久丢包和六状态外环需要各自的时间戳与终端合同。
