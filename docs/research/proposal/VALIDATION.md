## 数值、因果与归因审查

| 问题 | 核查结果与边界 |
|---|---|
| 是否向控制器泄露未来或真值？ | 估计器只接收当前到达的时间戳/数值和已执行命令；模拟器真值仅用于生成量测和断言 |
| 是否重复计算端点噪声？ | 两端点用于速度消元，各一个噪声变量；中间量测各新添一个变量 |
| 是否将 CZ 中心当可行估计？ | 使用带等式约束的LP选点，包含非零rhs反例 |
| 是否漏掉直径因子2？ | 全局E使用2倍两样本半径；pair对照也使用同一控制预算 |
| 是否直接裁掉旧生成元？ | 每拍从窗口样本重建外包；不修改旧联合CZ的耦合系数 |
| 是否等同有限存储与实时？ | 明确分开；现有计时未含全部三轴/通信及验证开销 |
| 是否重置名义中心导致移位失效？ | 名义状态持久传播；测试展示任意重置可能越过收紧边界 |
| 是否混用Euler和ZOH？ | 新基线明确ZOH；旧启动门仍保留两种模型的差异测试 |
| 是否把三个轴当三个独立六状态实验？ | 三轴共享交付表，只有轴独立动力学/集合；总分轴步仅为计算计数 |
| 是否挑选CZ收益场景？ | 最大间隔无额外量测时收益为0，随机跟踪改善很小，均报告 |
| 是否从采样零失败推出全称安全？ | 全称结论来自限定模型的解析证明；仿真只核验实现 |
| 是否把全历史支持检查当多面体包含证书？ | 测试仅检查坐标支持和样本包含；集合包含另有解析论证 |
| 是否已经验证真实四旋翼？ | 没有；抽象模型甚至未覆盖一般六维残差，仅允许 \(Bw\) |
