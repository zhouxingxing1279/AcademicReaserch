# 方案一的第一轮定题门槛验证

日期：2026-11-04。此文件在本轮实验结果生成前冻结。问题是：有限表示预算下，控制相关压缩是否比强基线更值得作为硕士论文第一项贡献？

## 范围与事前判断规则

1. 核对 Brunner 2018、SPIN-SMF、CCTMPC 模板设计、Predictive Zonotope Reduction 的对象、假设、算法和保证。无法取得全文的来源明确保留未核实状态；不以摘要推断它没有某种保证。
2. 新增独立实验和结果目录，不覆盖先前 screen/audit、src 控制代码或 SITL 数据。二维模型允许精确多边形操作，因而可以加入全历史精确后验强基线；不能据此外推高维 CZ 速度。
3. 实验比较的是**相同持久表示的面数上限**，不是相同 CPU 时间。完整记录构造、方向选择和求解耗时，以及支持查询次数。几何贪心可查询全部候选方向，额外计算必须计入。
4. 对任何经验收益不事后选择阈值：报告全部配对结果、失败及不利案例。若只有标准工具组合、无明确理论差异，则不宣布创新性门槛通过，即使部分算例改善。

## 冻结的实验设置

- 两个已知 LTI 系统：fast 使用原评估 A=[[.75,.2],[-.1,.7]]、N=6；slow 使用 A=[[.91,.06],[-.04,.92]]、N=10。B=(.15,.2)，W=[-.005,.005]^2。
- 状态约束、输入界 .35、终端盒 [-.25,.25]^2、终端输入 0 均沿用原评估。运行前检查终端鲁棒不变性。两模型都稳定，不冒充不稳定无人机验证。
- 初始生成元使用原 shape(theta)，theta=0,45,90,135 度。中心沿 0,90,180,270 度射线，通过 LP 求同一精确先验的最大可行距离，取其 98%，以构造约束边界压力测试。
- 每个模型 16 个初值，固定种子 4100+初值编号；30 步；观测每 1 拍、每 3 拍和完全不观测；初始时刻共享已知先验，从第 1 拍开始接收量测。C=(1,.4)，测量噪声半径 .025。
- 有限面数预算 m=6,8,12。三种压缩：均匀方向；几何误差贪心；移位控制约束残差贪心。后二者从坐标盒开始，分别补充支持间隙最大/归一化移位残差最大的预测约束方向。所有外包包含同一个输入后验。
- 强参考：固定完整预测方向模板；全历史精确后验。另统计未加备份时的移位失效与压缩 QP 不可行，不能把备份成功当作压缩 QP 递归可行。
- 全部控制器使用同一规则的名义观测器：预测后如有量测，用固定增益 (.6,.15) 修正；二次控制代价一致，避免集合代表点选取成为混杂因素。
- 静态配对：从精确参考轨迹的 k=1,2,3 提取后验与上一拍移位序列，对所有预算/方法做同后验对照。
- 闭环配对：所有方法共享初值潜变量及外生扰动/测量噪声序列。分别报告代价、状态/输入/包含违规、压缩 QP 失败、备份次数、时间和表示复杂度。

## 备份与数值审计

压缩 QP 可行时接纳新外包和计划；不可行时继续上一份已验证计划。备份保存最近接纳的有限面数集合、累计输入平移、经过步数和剩余计划；不偷偷保存全历史精确后验。备份期间允许丢弃过去未接纳的量测，只条件化当前已到达量测。达到旧终端后使用已验证不变终端盒重置。

永久存储面数与临时顶点数分开记录；临时二维几何运算不等于相同字节预算。精确参考可以保存完整后验，不受面数预算限制。

使用独立 LP 检查若干半空间/顶点支持值；使用 CZ 全历史递推核对精确多边形后验；检查输入、状态、包含和计划残差。容差 2e-6；所有证书为浮点残差检查，非向外舍入形式化证书。
