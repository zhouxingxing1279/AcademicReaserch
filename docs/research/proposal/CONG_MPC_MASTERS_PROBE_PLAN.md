# 硕士两项创新点评估：机制仿真计划
日期：2026-11-04。此计划在本轮数值结果产生之前写入。目标是筛选机制和划清创新边界，不是复现完整论文或证明实飞安全。

## 研究安排
用户确认：硕士论文，两个关联但可独立论证的创新点。已有文献和代码不改动；新增脚本、结果独立存储。新问题优先比较固定量测合同下的控制相关集合压缩，以及主动量测/计算调度。抗扰只是评价维度之一。

## 冻结的机制试验
1. A：最大连续缺测 M=1,2,3，标量误差放大系数 0.9,1.0,1.1，量测半径0.03、过程噪声0.02、预测8步。枚举允许收包序列与动态规划相互核对，比较已知当前年龄的未来最坏半径与统一最坏半径。禁止以未来全收到的理想序列冒充可用信息。
2. B：三维位置—速度—扰动增广系统，T=0.2，初始半径(0.1,0.2,0.5)，过程半径(0.002,0.005,0.02)，测量位置，噪声半径0.005/0.02/0.05；每拍与隔拍量测，8个固定种子，10次更新。比较同一后验的联合支持函数、仅分离状态与扰动的支持函数及全坐标盒；预测方向为1/3/6步位置及速度。检测真值包含，不以RMSE证明创新。
3. C：耦合稳定二维数学系统 A=[[0.75,0.2],[-0.1,0.7]]，B=(0.15,0.2)，过程噪声盒半径0.005，输入幅值0.35；状态盒(1.2,0.8)及归一化混合方向幅值0.85；预测6步，终端盒半径0.25、终端输入0。初始误差为长轴0.24的反相关集合加0.02独立误差。比较精确支持、坐标盒、同数量均匀模板与按预测约束反向传播选择的模板；12个旋转角度，每个15×15中心网格。此有限网格只反映所选模型的可行样本数量，不是连续可行域体积。
4. C闭环：上述二维模型，位置混合量测 C=(1,0.4)、噪声0.025，初始中心(0.7,-0.5)，8个种子，30步；每拍、每3拍两种模式。对比固定大小的约束方向模板、同大小均匀模板、坐标盒。控制器只接收已到达量测，不访问真值；报告约束/包含/移位检查、QP失败、完成率、代价及耗时。推导只针对鲁棒可行性，不自动声称稳定性或飞行验证。
5. C数值证书：对上述初始CZ，计算标准对偶支持上界与原LP基准；用平滑对偶目标的有限迭代优化生成候选，评价原始非平滑上界；报告有效性、间隙与耗时，不预设更快，不把标准LP对偶当创新。
6. D：已知原点信标，两个相容位置(-1,1),(1,1)，共同位移来自{-0.4,0,0.4}²；测距误差半径0/0.03/0.15/0.4。精确比较量测区间是否相交及最坏后验分支数；加入障碍和禁止横向运动反例。仅离散假设机制验证，不宣称连续状态主动MPC已实现。
7. E：e_i=b+ε_i，e_j=αb+ε_j，b半径0/0.1/0.3/0.5、ε各0.05、α=1/0.5/-1。枚举联合顶点验证相对支持界，对比独立边缘外包；α=-1为无收益负对照。不是多机闭环试验。

## 判断规则

- 理论上可推导的标准集合/优化性质，不计作已证新的学术贡献。
- 机理成立不等于文献新颖；新颖性由最近原始文献比较决定。
- 浮点LP/QP结果接受独立残差核验，误差界按报告注明；不称形式化浮点安全证书。
