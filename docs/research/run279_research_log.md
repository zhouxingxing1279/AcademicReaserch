## 可直接交付主任务的可靠LP合同（算法设计，不是已运行的完整SMF）
冻结四状态离散Euler `(p,v,phi,omega)`，`h=0.02`、`T=9.81`、`m=1`、`|r_k|<=R=3246383/1600000`，`p_{k+1}=p_k+h v_k`、`v_{k+1}=v_k+h(-T sin(phi_k)+r_k)`。每拍姿态观测 `zphi_k=phi_k+nphi_k`，`|nphi_k|<=0.005`；每次成功位置观测 `y_k=p_k+np_k`，`|np_k|<=0.02`。失测时**不添加位置条带**，但必须保留合法最多两次连续丢包自动机。

由正弦1-Lipschitz性质，定义**仅用于外包的松弛变量** `q_k`：
```
a_bar_k = -T*sin(zphi_k)
delta = T*0.005 = 981/20000 = 0.04905 m/s²
q_k in [a_bar_k - (R+delta), a_bar_k + (R+delta)]
p[k+1] = p[k] + h*v[k]
v[k+1] = v[k] + h*q[k]
success at k: y[k]-0.02 <= p[k] <= y[k]+0.02
all k: |p[k]|<=5, |v[k]|<=3
```
从**真实初始集合和所有0–60拍已执行控制/观测**建立一次LP可行多面体，并分别最小化/最大化 `p60,v60`。每条实际轨迹都满足这些松弛约束，因此其投影是可靠外包（前提：冻结动力学、扰动界和历史数据确实成立）。可用同一个历史LP保留不同成功读数间的关联，不能逐拍把后验投影成独立盒再宣称精确后验。若需姿态/角速度完整后验，应再加入每拍角动力学、角速度条带、角硬盒、力矩历史和初始角集合；本轮**尚未实现**。正弦中心的浮点实现必须向外舍入或用认证区间；普通浮点QP/LP的容差不能自动构成形式证明。

## 与Run278的可复核交叉检查
在45–59拍真实 `phi=omega=0`、`x45=0`、`y60=0`的**受限内切片**，Run278原始扰动向量 `[-R]*3 + [alpha*R] + [R]*11`，`alpha=28057872/35710213`，给 `p60=0.02`、`v60=39217447/110000000`。本轮标准库Fraction检查再次通过。若姿态读数零，姿态噪声松弛给额外加速度半宽 `0.04905`；15拍不施加位置条带时速度半宽 `15*h*(R+0.04905)=9974589/16000000≈0.623412`，**只是松弛外包的粗上界**，不能拿来代替带位置条带的LP最优值，更不能与内切片0.356522混同。
