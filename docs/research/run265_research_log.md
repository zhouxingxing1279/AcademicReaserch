# Run265 — 三拍物理制动权限下的终端速度绝对值必要筛选（2026-11-02）

## 1. 基准、瓶颈与证据等级

本轮开始读取远端 main `b70fe7c9063e4278f8cea595f2e696b47fec0ed6`、CURRENT_CHECKPOINT、Run262–264研究日志及验证源码、真实 `configs/planar_baseline.json` 和唯一论文总账。Run263证明第60拍全部非空有噪后验的**速度投影宽度**有上界；Run264只证明特定历史第45–75拍共享零力矩有限安全。Run261排除了零力矩无限重复，Run262证明从零姿态零角速出发，力矩第三拍才影响速度。本轮唯一问题：**仅靠速度后验宽度能否筛选一个物理上可重复安全的终端信息集合？** 结果是否定的，给出绝对速度必要条件与合法扰动反例；没有构造完整终端RCI。

## 2. 精确必要条件：绝对速度中心不可省略

仅继承冻结四状态**定义的离散Euler真值**，不是六状态平面四旋翼：
`p+=h*v; v+=h*(-T*sin(phi)+r); phi+=h*omega; omega+=h*tau/J`。
`h=J=1/50`，`T=981/100 N`（固定），`|tau|<=U=2/25 Nm`，`|r|<=R=3246383/1600000 m/s²`；硬约束`|p|<=5, |v|<=3, |phi|<=0.45, |omega|<=2`。

考虑任意真实状态 `x0=(p0,v0,0,0)`，取合法扰动三拍 `r0=r1=r2=+R`。对**所有**合法因果力矩序列（即使知道未来扰动也不能改变结论），Euler时序严格给出
`phi1=0, phi2=h²*tau0/J`，且
`v3=v0+3hR-hT*sin(h²*tau0/J)>=v0+D`，
其中
`D=3hR-hT*h²U/J=48570177/400000000=0.1214254425 m/s`。
若希望对每种合法扰动保持三拍速度硬约束，必须有
`v0<=3-D=1151429823/400000000=2.8785745575 m/s`。
对负向扰动 `r=-R` 对称得 `v0>=-2.8785745575`。因此在`phi=omega=0`的真实状态切片上，任何鲁棒可生存终端集合都必须满足这个**必要但不充分**的绝对速度带。对任意信息后验，只要其包含该切片上不满足速度带的真实状态，即使全状态反馈也无法保证三拍硬安全，故观测纤维共享控制更不可能保证。

**明确真实反例**：`x0=(0,2.9,0,0)`，`r=+R`持续三拍。第一、第二拍速度`235246383/80000000`、`119246383/40000000`，均小于3；第三拍对所有合法力矩都有`v3>=1208570177/400000000=3.0214254425>3`。第三拍位置`705739149/4000000000≈0.1764348m<5`，姿态和角速度三拍上界分别0.0048rad、0.24rad/s，均合法；因此是**真实速度硬约束失效**，不是区间外包误报。负向速度和扰动给出对称见证。

甚至只含上述一个状态的零宽度后验也不可生存，因此**宽度小不等于绝对状态安全**。此见证不是Run260第60拍或Run264第75拍实际后验成员的证明；本轮**不**据此判定它们不可行，也不排除更窄且中心安全的反馈终端集合。

## 3. 真实论文阅读与创新性边界

Renato Quartullo, Gianni Bianchini, Andrea Garulli, Antonio Giannitrapani (2025), *Robust Output Feedback Variable-Horizon MPC With Adaptive Terminal Constraints*, *IEEE Control Systems Letters* 9:883–888, DOI https://doi.org/10.1109/LCSYS.2025.3578491 。2026-11-02阅读作者公开6页PDF https://www3.diism.unisi.it/~giannibi/research/papers/ATCS_LCSS_2025.pdf ，pp.1–6，§II–IV、Theorems 1–2、Algorithm 1、式(1)–(26)；未逐式核对IEEE终版。

论文为离散LTI `x+=Ax+Bu+w,y=Cx+n`，有界过程/测量噪声；Luenberger观测器 `L` + 固定增益 `K` 双层误差管束，名义状态和输入做Pontryagin收紧。可变时域MPC通过自适应**终端目标集合**，在初始问题可行和代价下降参数条件下给出递归可行与**有限时刻到达目标邻域**。不是无限时间保持安全的终端信息RCI，也不是逐次测量条带交集SMF。§IV为轨道交会**六状态位置/速度、三虚拟加速度**数值例；每拍仅有带噪位置（无丢包），采样11.7s，Gurobi平均求解约0.5s；100组Monte Carlo，非四旋翼、无真实飞行、无本项目T/tau饱和或20ms WCET。§V明确将SMF与非线性扩展列为未来工作。

**可复用**：式(5),(10),(11)的估计误差、控制偏差分离与状态/输入收紧，式(15),(23)的移位候选和自适应终端目标集合。**不能直接迁移**：论文全程每拍观测，目标是有限时间拦截而非无限重复悬停；其状态是LTI且加速度可直接施加，无法替代Run262物理三拍力矩响应、Run263失测状态后验或本项目的终端信息RCI。该文已经证明部分输出＋有界噪声＋自适应终端的相关贡献，本课题创新需进一步限定在有噪失测、非线性物理控制权限与可重复安全上。
