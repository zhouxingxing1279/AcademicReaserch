# Run208：两层因果非零 backup 与可达第95拍严格见证

日期：2026-10-30（美国太平洋时间）；基线 main a88290b3b9841590497df34408b0ed4c2bdb2bd1（Run207）。

**唯一研究问题：** Run207 的下一拍零力矩四拍 backup 在合法交变扰动历史第95拍拒绝；允许下一拍观察实际推力后选择非零 backup 力矩，能否严格扩大当前首拍可行域？

## 冻结合同与信息顺序

四状态 Euler 代理 x=(p,v,phi,omega)，h=J=1/50，T∈[981/200,2943/200]，|tau|≤2/25，|r_x|≤47/25+(243/16000)T，状态硬界 (5,3,9/20,2)；每拍姿态与角速度观测，位置每5拍尝试、最多连续两次缺包。当前已知 T0、后验盒 B_k；先选择 u0，后发生未知扰动与下一观测；下一拍知道 T1 后才可选择 u1(T1)。

本轮采取比观测条件化更保守的**测量无关**策略：使用 B+=F_box(B_k,T0,u0) 覆盖全部下一观测后验 B_{k+1}⊆B+；下一拍 u1 只依赖可见 T1，不依赖下一测量。其量词为一个充分策略子类：存在 u0；对所有合法 T1、y1、r0，存在仅依赖 T1 的 u1(T1)；对所有未来 T2..T4 与扰动，后继四拍控制 u1(T1),0,0,0 安全。**未实现一般 u1(y1,T1)。**

## 精确投影与条件性证明

固定下一推力端点 T1∈{Tmin,Tmax} 及其后三拍推力端点 T2..T4，将完整 B+ 的独立初始误差生成元与扰动生成元传播。每时刻每坐标的双侧硬约束化为有理数线性行：

    a_i*u0 + b_i*u1 <= d_i.

每个 T1 端点有 2^3×4×4×2=256 条带符号行（另有输入限幅）；按系数去重后53行。对 b_i>0 的 u1 上界与 b_i<0 的下界进行精确 Fourier–Motzkin 消元，得到两个端点各自允许的 u0 区间，并与当前首拍安全和输入约束相交。初始盒的每端点各有14条不同斜率的上界/下界、196次两两比较。所有决策使用 Python fractions.Fraction，不依赖浮点 LP。

对任意允许的 u0，在 T1 两端点选择可行 u1^-、u1^+，令 u1(T1) 为其线性插值。冻结 Euler 动力学中同拍 T1 不乘同拍 u1；未来各拍推力独立，因此固定初始误差/扰动原语后，未来状态对 T1..T4 是 multi-affine。对每一有符号原语的线性状态约束，超矩形顶点安全推出全部内部推力安全。任何合法下一测量只收缩 B+，故同一 u1(T1) 对全部后验子集仍保证未来四拍安全。

**严格范围：** 本结论仅保证当前动作后**下一拍存在四拍 backup**，不是下一拍还可满足相同两层桥，也不是终端受控不变集、无限时域安全、稳定性或 MPC 递归可行性。投影只对完整盒重置与限定后继策略类精确，不能声称是一般因果控制的充要条件。

## 实际可达重放与严格见证

从合法零真实初态、可靠初始盒、合法有界扰动/测量历史出发，使用同一反馈建议和两包速度收紧 SMF，各运行最多100拍：

| 合法场景 | Run207零力矩一步桥已准入 | Run208非零两层桥已准入 | Run208首次拒绝 |
|---|---:|---:|---|
| 高推力、持续正扰动 | 100 | 100 | 100拍内无 |
| 高推力、交变扰动及极端有界测量噪声 | 94 | **95** | 第96拍 |
| 推力切换、持续正扰动 | 100 | 100 | 100拍内无 |

在**同一 Run208 交变场景第95拍可达后验**上，Run207 零力矩桥区间为空；Run208 两层区间非空，首拍 u0∈[-0.08,-0.05554926875015705…] N·m。建议力矩经准入后取区间上界；下一拍在 T1=Tmin、(Tmin+Tmax)/2、Tmax 时均可选 u1=-0.08 N·m，独立四拍 backup 审计均通过。

这个严格扩张来自**允许非零后继力矩**，不是本轮已证实的测量条件化增益，也不是不同推力端点策略差异。两种过滤器生成的实际控制历史不同，94→95仅是指定可达重放前缀，不能解释为一般最优性或统计性能改善。Run208 在第96拍仍拒绝；上一拍证书只保证第96拍有有限四拍 backup，不保证可持续恢复。
