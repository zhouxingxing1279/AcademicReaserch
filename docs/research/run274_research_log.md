## 3. 第三15拍的可计算信息状态准入门槛
若第90拍某个真实SMF/CZ后验（包括该时刻全部非空合法读数纤维）可靠包含于 `|p|<=P90`、`|phi|<=0.014`、`|omega|<=0.01`、`|v|<=V90_post`，则共同零力矩对90–105拍安全的一个**充分条件**为
```
V90_post <= 3 - h*(15*R + T*(15*0.014 + h*0.01*15*14/2))
         = 187678479/80000000 = 2.3459809875 m/s.
```
当速度条件成立，使用上述两种P90外包，第105拍位置界分别不超过2.63836638761m(SMM)、2.06857476125m(MMS)，姿态界0.017rad，故其他硬盒也满足。这个门槛**不是必要条件**；更聪明的反馈、关联集合或较小位置界可绕过它。现有第90拍**无条件**速度盒SMM 2.8499067436、MMS 2.3750803885均大于门槛，因此尚未认证任何第90拍全部读数分支都能进入第三块。成功位置读数的交集会把位置投影直径收紧到至多0.04m，但不自动使隐藏速度满足门槛。
