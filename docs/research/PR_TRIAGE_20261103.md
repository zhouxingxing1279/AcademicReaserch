## Current research boundary

The active target is outer-loop MPC above a mature flight controller. The flight controller retains attitude/rate stabilization, allocation and motor control. **The current stage is theoretical, not interface selection:** no PX4 position/velocity/acceleration A/B, no Offboard interface freeze, and no SITL interface identification until the theory gates are closed.

The primary high-fidelity simulation object remains the full 12-state, six-DOF rigid-body quadrotor plant under a mature flight-controller loop. The first abstract outer-loop state candidate is the six-dimensional translational state
\`x=[p_x,p_y,p_z,v_x,v_y,v_z]^T\`, with position-only measurement as the initial information pattern. Its discrete matrices and high-level command semantics are not frozen; the input is abstract \(u_k\) during the theory phase.

The current proof chain is: finite measurement language → reliable CZ/set-membership error enclosure → phase-dependent Equalized Recovery → common causal output-feedback controller → estimator/tracking tubes and tightened constraints → common terminal set and recursive feasibility. Specific PX4 evidence remains deferred background material.

## Classification

- **A — retain in the active research stream:** directly supports mature-flight-controller outer-loop architecture, its interface, or relevant literature evidence. Merge only after ordinary review; append-only evidence logs should be consolidated where they duplicate the same interface audit.
- **B — preserve as reusable evidence, but do not merge into the active implementation unchanged:** model-specific SMF/observability/dropout mathematics or synthetic benchmarks. Archive or selectively port only after the new closed-loop model and sensor contract are frozen.
- **C — archive as historical/out-of-scope for the current controller boundary:** four-state planar direct-control work or rotor-/wrench-level controller research. Preserve the papers, logs, code and exact certificates; do not let these branches restore the old control contract.
