# 阶段 5｜系统假设与信息时序

本文件固定候选 A 第一版数学合同的允许路径、在线信息和精度目标。变量与单位见[数学模型](mathematical_model.md)。主合同采用阶段 4 已登记的 \(M=1,L=2\)、四拍恢复块；\(M=L=1\) 的历史算例另作对照。[原合同](stage4_critique_A/reduction_protocol.json)

## 1. 哪些路径进入保证

| 假设 | 本次冻结 | 假设失效时的处理 |
|---|---|---|
| 初始与时钟 | 从 \(k=0\) 和已知初始盒启动；初始连续未生成计数为零，在途队列为空。在统一整数采样时钟上准确识别生成戳，记录当时实际施加的命令 | 缺少输入历史、时钟错位或从未知在途队列重启，均需新的准入条件 |
| 动力学与误差 | 六状态基线采用独立三轴 ZOH、\(G=B_T\)、紧乘积盒。误差可任取合同内值，既覆盖零也覆盖边界 | 初始失配、非匹配残差、测量偏置超界时登记失败。相关硬界可单列建模；高斯置信区间不足以给出逐路径保证 |
| 生成 | 每个戳 \(s\) 至多生成一个三维全位置包。\(g_s=0\) 表示未生成，任意相邻两戳满足 \(g_s+g_{s+1}\ge1\) | 分轴异步或分量缺失须重新检查各轴的有效生成戳 |
| 交付 | \(g_s=1\) 时唯一首次交付拍 \(r_s=s+\ell_s\)，\(\ell_s\in\{0,1,2\}\)。允许乱序、同拍多包、所有包同时取最大延迟。时序外生，与状态、扰动和读数无关 | 已生成且始终未交付记为永久丢包；主合同排除此类路径。若研究永久丢包，需另定有效戳新鲜度，例如任意给定长度的生成窗口内至少一戳限期成功，再复核全部覆盖条件 |
| 观测与故障 | 完整读数约束生成时刻的 \(p_s\)。同戳同值的重复副本仅使用一次；同戳异值、未来戳和空后验分别登记为数据或模型失配 | 保存失败路径、当时可见数据及相容性检查结果；合同外故障的安全降级另行设计 |
| 控制因果性 | \(\hat x_k\) 与 \(u_k\) 只依赖 \(H_k\) 和由该历史确定的控制器记忆。共同命令须对所有相容状态可实施 | 真实扰动、在途读数、未来到达表仅供离线判定；同一历史分别为各隐藏状态选取不同命令会改变问题 |

估计保证的量词为：对每个允许的无限生成/交付序列、每个合同内的初始状态、过程扰动与读数误差，以及同一已知实际输入历史，评估该时刻全部相容真值。控制保证还须限定从经认证的初始信息集、名义中心和可行计划启动。先验正确给估计问题一个初始见证；初始控制安全和 MPC 可行性须各自检查。[启动共同输入条件](cz_startup_predecessor.md)

## 2. 一拍内的顺序与跨块处理

1. 在 \(t_k\) 对 \(x_k\) 生成本拍允许的样本，接收所有首次交付拍等于 \(k\) 的包，其中可包含 \(y_k\)。
2. 用已交付记录、已执行输入和先验形成 \(H_k\)，按**生成戳**施加条带；若为块末，此时检查恢复界。
3. 根据当时的估计和名义记忆选择实际命令 \(u_k\)，记录下来，作用于 \([t_k,t_{k+1})\)。到下拍才把下一批读数计入信息。

在 \(r_s\) 之前控制器看不到 \(y_s\)。到 \(s+2\) 处理完所有包后，可在主合同内从缺包推知这一戳未生成。有永久丢包的扩展必须把“未生成”和“已生成但最终丢失”作为不同的隐藏事件。空到达也可能只是旧包仍在途。

第 \(q\) 块的生成戳为 \(4q,\ldots,4q+3\)，在 \(b=4q+4\) 当拍交付处理后验收。旧块包 \(r_s=b\) 为恰到边界，\(r_s>b\) 为严格跨块。**若下一块首戳 \(s=b\) 当拍交付，其读数也在 \(H_b\) 内。** 两块共享这一时刻的后验和记忆，包仅处理一次。下列前缀是后续核验时的固定输入示例；数值可取零，零状态、零输入和零误差即为相容见证。

| 例 | 生成/交付安排 | 决策时实际可用的信息 |
|---|---|---|
| 启动与空拍 | 戳 0、2、4 未生成，戳 1、3 均延迟两拍 | 拍 0–2 无包，拍 3 收戳 1，拍 4 仍只有戳 1，拍 5 才保证已有戳 1、3 |
| 边界同到 | 前三戳即时，戳 3 延迟一拍，戳 4 即时 | 拍 4 同时加入戳 3 与 4；任何一项移到拍 5 才处理都会改变比较 |
| 严格跨块且乱序 | 前三戳即时，戳 3 延迟两拍，戳 4 即时，戳 5 未生成 | 拍 4 可用戳 4，拍 5 才能用戳 3；回放时仍施加在 \(p_3\) 上 |
| 历史负对照 | 延迟词 \((0,0,0,2,2,2)\) 与 \((0,0,0,\text{未生成},2,0)\) | 两词在拍 5 各有一条零读数，但生成戳分别为 3 和 5，联合后验可不同 |
| 合同外 | 戳 3 已生成，此后永久丢失 | 只标为主合同外记录；与 \(r_3=5\) 的两拍迟到分开统计 |

数值对照可使用同一物理接收记录的三种处理规则：即时组在到达拍使用，截止缓冲组在 \(s+2\) 才释放，丢弃组只丢严格超过该生成块末的读数。同信息强基线保留全部已到读数，按同样时间戳做精确联合轨迹或延迟增广。各组共享真实过程、边界约定和规则所允许的输入历史；一旦各自闭环命令分歧，后续轨迹应分别按各自实际命令传播。[时序反例与缓冲规则](stage4_critique_A/CDC22_REDUCTION.md)

## 3. 恢复目标、启动和块末记忆

记 \(E(P,V)=\{(\delta p,\delta v):\|\delta p\|_\infty\le P,\ \|\delta v\|_\infty\le V\}\)，\(P\) 的单位为 m，\(V\) 的单位为 m/s。采用同一个可行代表点来衡量各坐标误差。完整后验与有限窗后验各用自己的代表点，并登记所属集合。

| 用途 | 合同值或要求 | 证据身份 |
|---|---|---|
| 启动先验 | \(E(1/200,1/100)\)，中心为零 | 给定的初值信息 |
| 块边界 | \(E_0=E_4=E(7/100,21/400)\)；每个正块末在 \(H_{4q}\) 上检查，\(q\ge1\) | 沿用原定的恢复目标；初始盒包含于 \(E_0\) |
| 块内相位 | \(E_1=E_2=E_3=E(37/400,3/50)\) | 本次取已有启动传播与稳态界的共同保守上界，便于比较各相位；逐相位最优值仍开放 |
| 稳态核对 | \(k\ge6\) 的单轴七格参考半宽 \(3/50,\ 31/600\) | 既有精度基线。六格参考为 \(13/200,\ 11/200\)，其中速度已超过块末登记值 |

启动期 \(k\le5\) 的无量测先验传播给半宽 \(r_{0,p}+kTr_{0,v}+a(kT)^2/2,\ r_{0,v}+akT\)。其最大值在拍 5，等于块内相位表中的保守界。拍 4 应单列，用已有全前缀核验的 \(23/400,\ 1/20\) 检查更紧的块末目标。对按轴可分的平面凸后验，位置、速度区间的中点组合为可行代表；一般耦合六维集合须另验代表点。单轴论文证据及可迁移范围见[可观测性分析](observability_analysis.md)和[原始半径证书](stage4_critique_A/cdc22_reduction_certificate.json)。

**块初准入**取从上述真实启动可达的记忆。完整参考携带全部已交付记录与实际输入。七格参考携带生成戳位于 \([\max(0,k-6),k]\) 内的已交付读数和状态转移所用实际输入；启动用初始盒，稳态窗口可按已证公式用自由窗首重建外包。两者均保留时钟、接收标识与相容的在途可能性，控制版本另携带名义中心和已认证计划。信道中的真实待发队列由离线验证器保存，在线只可维护相容候选。每个块末交接既有后验与合法记忆，不能清空队列并从误差盒中任意状态重启。七格计生成时刻，峰值读数、在途处理、摘要和离线表须另行计量。[记忆下界和条件删包的证据边界](stage4_critique_A/PACKET_MEMORY_RESULT.md)

## 4. 转入后续理论时保留的义务

阶段 6 如获准，先审查时间戳后验的真值包含（精确表达、窗口外包及空后验各列），再审查块末误差与记忆的可重复准入。共同命令、Tube 收紧、共同终端、递归可行与有扰动稳定性依次承接。Hassaan 等的 Assumptions 1–3 将估计与跟踪预算、终端和代价条件分别列出；该文的周期语言和本合同须分别核查。峰值存储相对强基线的优势、Brunner 等期刊定理的直接差异、十二状态残差覆盖继续列为未证。[Hassaan 等，2021，式 (12)、(18) 与 Assumptions 1–3](https://qiangs.github.io/Papers/Conf_Hassaan2021ADHS.pdf) · [阶段 4 专项严审](stage4_critique_A/REVIEW.md)
