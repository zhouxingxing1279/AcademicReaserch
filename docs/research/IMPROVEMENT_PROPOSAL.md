## 0. 评审结论摘要

分维度评价：问题定义强（量词完整、可证伪、上下两侧兼顾）；数学纪律很强（有理数证书、LP 对偶核验、前缀枚举、反例强制登记）；创新性存疑未闭合（light_review 聚合 FAIL，12 条 critical，3 条拒稿理由均 rebuttable=false）；物理有效性弱（参数为数学设计值无辨识依据、G=B_T 匹配假设已被自有反例击穿、三轴独立与倾角耦合矛盾）；工程可行性弱且无复杂度门槛（OIT 实测求解全部超 20 ms）；流程治理强但缺少"路线存续门"。

主要断点：参数无物理溯源；G≠B_T 影响未分类；三轴独立假设；恢复目标 E₀=E(7/100, 21/400) 与七格窗最坏半宽 3/50 m、31/600 m/s 的接近性构成循环论证风险；信道合同排除永久丢包；时间戳准确性为未检盲点；新颖性 FAIL 无收敛路径；求解复杂度无预算；阶段 5 交付未提交入库。

总体判断：最确定的成果（证书、紧性、反例集）建立在最不确定的支柱（参数量级、G≠B_T 影响、机制级新颖性）之上，而后者被排在最后验证。改进主线是把结构性风险前置。

## 2. P1 合同层修复（进阶段 6 前冻结）

1. **G≠B_T 影响分类清单。** 在 MODEL_CONTRACT.md 增加一节，把阶段 6 的六条证明义务（真值包含、Equalized Recovery、因果输出反馈 Tube、鲁棒收紧、共同终端、递归可行）逐一标注"结构性成立 / 依赖匹配假设 / 未分类"。验收：每条义务有分类与依据；未分类项在进入对应证明前清零。
2. **时间戳误差分析。** 现合同假设统一整数时钟上准确识别生成戳。补充 ±1 拍戳偏移的相容性分析：错戳条带施加在错误状态上直接破坏真值包含，不属于外包可覆盖的噪声。验收：给出"戳偏移 ≤δ 时证书退化界"或将其列为阶段 6 显式待证项并标注失败条件。
3. **永久丢包压力测试协议。** 主合同不变，在 system_assumptions.md 补一段丢包路径下证书退化与诊断降级触发条件的协议，列为阶段 8 必报项而非可选扩展。验收：协议含"未生成"与"已生成但最终丢失"的区分统计口径。
4. **参数敏感性附录。** 在 observability_analysis.md 增附一节：利用两戳界 β_d = 2n/(dT) + aTd/2 的解析形式，给出六格/七格半径对 (T, a, n, M, L) 的偏导数与"参数放大 k 倍时恢复目标何时失效"的表。验收：每个冻结参数至少一行缩放律，与归档 JSON 数值一致。

## 3. P2 流程层

1. **增设路线存续门。** 在阶段 6 与阶段 8 入口各加一项 go/no-go：当新颖性 critical 未清条数 ≥6，或任一 P0 探针失败时，强制重评估路线，不得以阶段交付达标为由绕过。
2. **未证债务设上限。** 跨阶段滚动的未证项上限设为 5；超限时不允许开新阶段，强制先清偿或显式放弃并记录放弃理由。
3. **交付入库核对。** 阶段 5 三份交付文档（mathematical_model.md、system_assumptions.md、observability_analysis.md）提交后以 blob 哈希核对确实入库（本仓库 git 索引存在 stat 缓存异常，必要时用 git update-index --cacheinfo 强制写入）。验收状态应建立在版本化成果而非工作树文件上。

## 4. P3 论文策略层

1. **双叙事预案。** 现在就各写一页提纲。叙事一（P1 探针通过）：沿用现题名，相位收紧从第二项贡献降级为验证章节，主支柱改为最短窗口紧性、条件删包与记忆代价。叙事二（P1 探针失败）：改题为间歇延迟位置量测下因果有限记忆估计的极限刻画，以反例集与两可达性为主干，四旋翼仅作 motivation。探针结果出来后直接选定，不损失后续时间。
2. **反例正资产化。** 六格窗速度半宽 0.055 m/s 超过目标 0.0525 m/s 的不可达见证、零噪声传播误差构造、条件删包改变最优命令的前缀，是全仓库唯一不受参数量级威胁的成果。论文中给独立章节，既是贡献也是审稿防御。
3. **相位收紧降级。** 块内相位速度预算 0.06 m/s 仅比块末目标 0.0525 m/s 松约 14%，对照 OIT 实测代价改善中位数 0.005449%，该贡献点预期收益量级不足以支撑独立支柱，建议降为验证性内容。
