# 实现验证协议：正确性、机制消融与闭环证据

状态：研究预注册草案，未开展训练或控制实验。本文的数值是拟定实验参数／推进门槛，不是已有结果。公式、模型域及控制器定义以本目录算法文档为准；参数调整必须发生在正式测试解封前，并留下理由和版本。

## 1. 首要假设与不能混淆的证据

主假设 H1：在同一网络容量、数据、物理误差覆盖要求、集合算法和控制预算下，将实际测量更新模式纳入训练，能减少后验状态外包络冗余。主比较是 D（后验集合目标）对 C（开环集合目标），不是 D 对 PID。

H2：H1 的收益在每个网络重新认证真实残差界后仍存在。

H3：缩小的集合能改善输出反馈 MPC 的可行运行范围，同时不增加合同内约束违反；估计收益不蕴含控制收益。

混淆排查：收益不能完全由普通 Jacobian 正则、增加训练预算或区间算法过度保守解释。H4 的丢包容忍条件扩展见 00/03。

区分三种证据：

| 层次 | 真值与误差来源 | 允许结论 |
|---|---|---|
| T1 解析离散模型 | 完整已知生成模型；对整个声明工作域认证每个训练模型的残差 | 对该模型及合同的条件性包含性与数值控制验证 |
| T2 连续平面模型 | 独立高精度积分、真实保持输入；离散化误差另行严格外包或仅经验记录 | 严格外包完成前只能声称经验有效性 |
| T3 三维 PX4 SITL／后续飞行日志 | 真实软件链路、估计延迟、未知真实误差 | 工程迁移证据，不能继承 T1 的确定性真机保证 |

随机抽样没有发现反例，不等于全域认证。有限次闭环仿真没有违反，不等于递归可行性定理。

## 3. 固定最小系统与测量合同

- 状态顺序：\(x=[p_x,p_z,v_x,v_z,\phi,\omega]^\top\)，输入 \(u=[T,\tau]^\top\)。禁止将角度弧度与角速度混用。
- 控制与滤波步长 \(\Delta t=0.02\,s\)，MPC 时域 \(N=25\)，即 0.5 s。
- \(\phi,\omega\) 在每个控制时刻有含有界误差的直接观测；这是一项简化传感器假设，不等同于真实 IMU 已提供无误差姿态。
- \(p_x,p_z\) 正常每 5 个控制时刻到达一包，即 10 Hz；合同内最多连续丢失 2 个预定位置包。
- 若 \(k=0\) 收到位置，\(k=5,10\) 丢失，下一包必须在 \(k=15\) 收到；因此有 14 个位置空观测控制时刻（1 到 14），两次收到位置之间为 0.30 s。不能把“丢两包”写成“只空两步”。
- 位置测量的传输延迟在第一版固定为零；测量缺失不等于延迟。第二阶段加入时间戳和延迟重传播后再增加延迟实验。
- 噪声幅值、初始集合半径、状态输入域均从单一配置读取。主实验用有界均匀噪声；符号交替、边界饱和噪声作为合同内困难工况。不得用未截断高斯噪声冒充有界合同。
- 网络输入为 \([v_x/3,v_z/3,\phi/0.45,T/(mg)-1,\tau/0.08]\) 的固定归一化量；输出两个残差加速度。归一化尺度只能由训练数据或预先物理域确定，不可读测试集。

## 4. 数据划分与防泄漏

数据生成器、采集控制器、解析残差公式和参数域在训练前冻结。T1 的已知真值函数只用于生成数据和离线残差认证，不向在线估计器／控制器暴露当前真值。

建议每条轨迹 20 s（1000 个控制步）；过域或提前终止的轨迹保留失败标签，不静默删除。

| 用途 | 种子范围（含端点） | 条数 | 用途约束 |
|---|---:|---:|---|
| 训练轨迹 | 10000–11199 | 1200 | 仅此集合计算标准化、优化网络 |
| 验证轨迹 | 20000–20199 | 200 | 超参数、早停、门槛预演 |
| 经验包络诊断 | 30000–30199 | 200 | 只检测明显包络问题；不替代全域认证 |
| 正式合同内测试 | 40000–40199 | 200／预定场景 | 测试前锁定配置与模型选择规则 |
| 合同外压力测试 | 50000–50199 | 200／预定场景 | 单列，不计入合同内保证结果 |
| 模型初始化 | 61001–61005 | 5 | A/B/C/D 共享对应初始化权重 |
| 统计 bootstrap | 62001 | 1 | 10000 次分层配对重采样 |

完整物理轨迹先划分，再切训练窗口，禁止窗口随机划分导致相邻状态泄漏。风场／残差参数实例、参考轨迹族实例、初值以及噪声流按 episode 固定。同一测试 episode 在所有控制器间共用外生随机数和测量丢包模式，但不强行共用状态轨迹，因为闭环动作不同。

合同内测试允许训练域内未见参数组合；合同外压力测试明确标识越域。使用种子与场景 ID 的稳定哈希生成子流，禁止依赖 Python 进程随机 hash。每条数据记录 split、scenario、seed、generator_commit 和 SHA256。

首次正式测试后不得通过调参反复择优；发现实现错误必须登记、废弃受影响结果、重新冻结版本，并建立新的未读测试种子集。

## 5. 训练与比较矩阵

| 编号 | 模型训练 | 同步控制／估计设置 | 检验用途 |
|---|---|---|---|
| P | 低阶物理阻力残差，最小二乘拟合 | 与 A–D 同一 SMF/MPC | 深度网络是否必要 |
| A | 点预测损失 | 固定 box/IBP，单独重算全域残差界 | 基础模型 |
| B | A＋Jacobian 正则 | 同上 | 是否只是平滑网络即可 |
| C | A＋开环预测集合宽度损失 | 同上 | 最关键的已有机制比较 |
| D | A＋测量更新后集合宽度损失 | 同上 | 核心研究候选 |
| A-Z、C-Z、D-Z | 复用已训练 A/C/D | 紧 zonotope／strip 外包比较 | 是否仅利用 box 表示缺陷 |
| D-no-mask | D 去掉间歇测量展开，按每次位置包都到达训练 | 其余不变 | 丢测模式的独立贡献 |
| D-empirical-bound | 使用经验残差界 | 仅诊断，不参与保证比较 | 揭示遗漏认证成本造成的虚假优势 |
| oracle-state | 真值作为状态输入 | 明确标识非可部署上界 | 定量定位估计瓶颈，不作公平主基线 |

每个网络以相同初始化、batch 顺序和点损失训练预算进行成对比较。先在验证集预演预算，再冻结如 200 epochs、batch=128 的候选上限；每个方法获得相同次数的超参数搜索，例如 12 组（lambda、学习率的预注册网格），不得给 D 更多试验。比较相同梯度步预算和总训练耗时两种视角，报告两者。

C 与 D 使用相同窗口、状态初始区间、输入数据、残差建模方式、宽度尺度、最大展开长度和丢测场景库。D 在离线训练可使用该窗口观测；部署 MPC 不得读取未来真实观测。最终测试每个网络都重新认证其完整“真值模型减网络模型”残差，记录认证时间、外包宽度和域划分数。

## 6. 分级验证：先正确再比较性能

### V0：代数和接口

1. 悬停平衡：零残差、\(T=mg,\tau=0,\phi=0\) 时速度和角速度不漂移。
2. 力矩符号：正 \(\tau\) 使 \(\omega\) 按约定增长，推力旋转矩阵与坐标正方向一致。
3. PyTorch 与 CasADi 使用同一权重与归一化，对 1000 个训练域内点，双精度输出及 Jacobian 的最大绝对误差门槛预设为 \(10^{-8}\)；超差先定位类型／导数问题。
4. 检查测量 mask：0/5/10/15 的边界用例；对预测时域枚举合法位置丢包序列，不得少枚举跨窗口已有的连续丢包计数。
5. 检查日志严格因果：在线模块 API 仅接收当前／过去观测，不可接收 truth 或 future_y。

### V1：集合与包络

1. 线性映射 box 的上下界与解析结果完全一致；tanh 区间用单调性检查。
2. 单点区间退化一致；非空测量交集不能扩大 box；不相交必须产生显式 empty 标记，不可悄悄重置集合。
3. 在小维系统用可穷举边界／高精度采样寻找传播反例；发现一个真值漏出立即阻断实验。没有反例仍不构成证明。
4. 分域认证报告必须覆盖整个输入工作域，无空洞；父域分裂后子域并集完全覆盖父域；保留所有未达紧度目标的域，不能丢弃。
5. 每个模型保存残差上界及数值误差预算。认证不足以支撑声称时标记“经验界”，不得与严格界混排。
6. zonotope 比较器需包含非线性余项和 strip 测量误差；仅线性化不加余项不能作为严格紧比较器。

### V2：估计机制，先固定输入重放

对相同输入／观测日志运行 A–D，隔离控制策略差异。比较位置包到达前后和每个丢测长度下的速度半径、全部状态宽度。位置观测可能直接把位置宽度夹到固定噪声带，因此必须单列未直接观测的速度，不可只报告位置总宽度。

使用两种数据：验证集上的自由闭环轨迹；独立采集控制器产生的相同输入轨迹。若 D 只在自身生成数据上有效，不能宣称一般滤波收益。

### V3：输出反馈闭环

按场景、种子、初始化运行成对闭环。每一步独立记录：真实状态是否在集合内、合同是否满足、MPC 原始状态、重算可行性残差、执行输入、是否启动有证书的后备策略、耗时和终止原因。

未来未知观测不能用于候选控制序列的实际约束收紧。在线只能使用算法文档规定的有保证误差包络或保守传播。若后备控制器尚未证明可恢复，实验可记录其工程效果，但“切回后备”不记为已保证安全。

## 7. 场景与扰动设计

| 场景 | 合同内定义 | 核心观察 |
|---|---|---|
| S0 正常定位 | 所有预定位置包到达 | D 是否损害常态性能 |
| S1 单包丢失 | 每次只丢 1 个包，恢复后至少收到 1 个包 | 轻度测量缺失收益 |
| S2 最长合同缺失 | 连续丢 2 包，第 3 包必到 | 0.30 s 到达间隔下集合增长 |
| S3 不利时机 | S2 的起点安排在转弯／加速参考段 | 不能只挑悬停丢包 |
| S4 噪声边界 | S0–S3＋有界噪声交替取边界 | 覆盖性和约束余量 |
| S5 参数域边缘 | 未见但仍在认证域内的气动参数、初值 | 域边界是否过保守 |
| X1 超合同缺失 | 连续丢 3、5、10 包 | 失败边界，明确非保证工况 |
| X2 超域动力学 | 超出声明残差界或状态／输入域 | 域监测与保证失效报告 |
| X3 异常观测／延迟 | 未建模跳变和有时间戳延迟 | 后续研究动机，不混入 H1 主结论 |

参考族至少包括悬停、小幅正弦、平滑转向和带加速度变化的轨迹。所有参考先检查名义可达性；不能将物理上不可能的参考导致的失败归因于估计器。合同内扰动可选常值、平滑正弦、分段有界三族，具体幅值必须在模型误差域内，由单一配置定义。

## 8. 指标、统计与通过门槛

定义 \(r_{k,j}=(\overline x_{k,j}-\underline x_{k,j})/2\)，固定尺度 \(s_j>0\)。主要滤波指标为每条轨迹归一化宽度：

\[
W_e=\frac1{K_e}\sum_{k=1}^{K_e}\sum_{j=1}^{6}\frac{2r_{k,j}}{s_j},
\qquad W^v_e=\frac1{K_e}\sum_k\left(\frac{2r_{k,3}}{s_3}+\frac{2r_{k,4}}{s_4}\right).
\]

必须同时报告最大宽度、测量恢复前宽度、归一化状态误差、空集次数，以及包含失败标志 \(1\{x_k\notin\mathcal X_k\}\)。只对数值舍入的预注册容差放宽成员判定，并另报无容差结果。

控制指标：位置 RMSE、最大位置误差、最大归一化约束超限、违反 episode 比率、初始优化可行率、全程可行完成率、后备启动次数和控制变化总量。控制变化是平滑性代理，不直接称为电池能耗。

一条轨迹的全程成功要求：无成员失败、无合同内状态／输入约束违反、无求解超时导致未验证动作、且完成全时长。提前失败不能因有效片段短而得到较低 RMSE；完整报告成功率，连续性能指标分成功条件统计和失败时间统计。不得把删掉失败轨迹后的均值当作全样本性能。

统计单位为 episode：同场景、同噪声种子、同初始化的 D−C 差值成对计算。5 次训练初始化先分别汇总，再进行以初始化和 episode 为层次的配对 bootstrap（10000 次）给出 95% 区间；不把每个采样时刻当独立样本。报告所有初始化，5 个模型的区间仍可能不稳定，应同时展示逐种子效应。二元成功／失败指标报告配对列联表及配对比例差区间。

预注册主终点为 S2/S3 上 \(W^v\) 的 D 对 C 相对下降；次终点为全程可行完成率与 p99 总闭环耗时。若做多组显著性检验，主终点单独指定，次终点使用 Holm 校正或明确标为探索性；不事后选择最显著场景。

建议推进门槛（研究管理规则，不是物理定律）：

- 覆盖门：T1 合同内成员失败为 0；一例失败立即定位，而非平均掉。
- 机制门：D 对 C 在预定 S2/S3 的速度宽度平均相对改善至少 10%，且配对区间支持正向改善；若不足，结合效应量判断是否继续，不夸大微小差异。
- 稳健门：在紧集合比较器上收益方向仍一致；否则收缩主张为“改善 box 实现”，不宣称方法普遍优越。
- 控制门：先证明／核查约束正确，再要求预定场景完成率或跟踪误差有实际改善；两者无改善则 H3 不获支持。
- 实时门：固定目标 CPU，单线程求解、100 步预热后记录总链路 p50/p95/p99/max；20 ms 为硬截止，目标 p99≤16 ms 留出调度余量，并报告所有超时。平均小于 20 ms 不能称满足实时要求。

零失败并不说明失败概率为零。例如 200 条独立 episode 均成功时，单侧 95% 二项失败概率上界仍约为 \(1-0.05^{1/200}\approx1.49\%\)；若 episode 不独立则该计算也不适用。
