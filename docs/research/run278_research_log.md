## 精确受限后验切片：原始-对偶双证书

仅考虑这个真实历史的**子集**：45–59拍`phi=omega=0,tau=0,T=9.81`，15个扰动`r_i∈[-R,R]`独立，60拍成功位置读数`y60=0`。离散Euler精确展开：

```
v60 = h * sum_{i=0}^{14} r_i
p60 = h² * sum_{i=0}^{14} (14-i) r_i
|p60| <= eps  (because y60=0, |noise|<=eps)
```

最大化`v60`是15变量线性规划。取`lambda=1/11`，对任意可行扰动：

```
sum r_i = (1/11)sum (14-i)r_i + sum (1-(14-i)/11)r_i
        <= eps/(11*h²) + R * sum |1-(14-i)/11|
        = eps/(11*h²) + 72R/11.
```

构造**可行原始见证** `r45..47=-R, r48=alpha R, r49..59=+R`，其中`alpha=(eps/(h²R)-16)/11=28057872/35710213∈[-1,1]`。此时`p60=eps`，`v60=39217447/110000000=0.3565222454545...m/s`，恰好达到对偶上界，故是**此受限切片内的严格全局最优值**。取符号相反扰动得到`p60=-eps,v60=-0.3565222454545...`，两个世界60拍共同读数0分别用噪声`-eps,+eps`，全部真实状态仍在硬盒内。于是**完整Run260 MMS真实后验**的速度投影直径至少
