## 模型与精确LP
冻结Euler四状态 `x=(p,v,phi,omega)`，`h=1/50`秒，`T=981/100`，`R=3246383/1600000`，位置噪声界`eps=1/50`米，姿态噪声界`1/200`弧度。采用Run279的可靠1-Lipschitz加速度松弛 `q=-T sin(zphi)+e`，`|e|<=A=R+T/200=3324863/1600000`。固定本次**受限检查** `x45=(0,0,0,0)`、45–59拍姿态读数`zphi=0`、60拍位置读数`y60=0`，且不施加45–59拍其他位置成功读数条带（这会放大可行集）。设15个独立松弛变量`q_i∈[-A,A]`，则
```
v60=h*sum(i=0..14) q_i
p60=h*h*sum(i=0..14) (14-i)*q_i
|p60|<=eps
```
该问题是Run279 LP的**15拍松弛子问题**，不是原非线性系统可达集合；松弛变量不必对应同一条真实角状态/扰动轨迹。

## 精确最优性证书
原始可行解：`q0..2=-A`, `q3=1675137/1100000`, `q4..14=+A`。精确计算 `p60=1/50`、`v60=39923767/110000000=0.36294333636...m/s`，且`|q3|<=A`。对任意可行q，令`w_i=14-i`：
```
sum q_i = (1/11)*sum w_i*q_i + sum (1-w_i/11)*q_i
        <= eps/(11*h*h) + A*sum |1-w_i/11|
        = eps/(11*h*h) + 72*A/11
```
两边乘h，右侧恰等于`39923767/110000000`。因此原始/对偶一致，给出**这一15拍LP的精确全局最优值**。符号对称可得松弛速度投影`[-39923767/110000000,+39923767/110000000]`，直径`39923767/55000000=0.725886672727...m/s`。

与Run278**真实后验内切片**的速度直径下界`0.713044490909...m/s`相比，此松弛切片的直径更大约`0.012842181818...m/s`。注意两者集合语义不同：Run278提供真实可行成员的**下界**，本轮只提供特定起点、特定读数且删除中间条带的**松弛LP精确投影**，不是完整Run271历史的可靠外包数值，更不能用二者差值宣称完整SMF保守性。
