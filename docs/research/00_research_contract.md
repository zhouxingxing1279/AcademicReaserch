# 00 研究总纲与验收合同

> 2026-09-09 更新：G1 已实现并暴露 box 速度宽度增长问题。原方案中的 box 训练选择暂缓冻结，先完成带余项的非线性 zonotope 基线；实际结果及修订顺序见 [08](08_g1_implementation_and_findings.md)。

## 1. 问题及适用范围

候选题目：**面向间歇位置测量的四旋翼神经动力学建模与集员输出反馈预测控制**。

核心 RQ：在相同真实动力学覆盖要求、模型容量及在线计算预算下，包含测量修正和丢测模式的模型训练，能否相对纯预测可达集训练，减少状态集合计算外包络的冗余，并提高输出反馈 MPC 的可行运行比例？

研究假设而非结论：

- H1：两类训练目标选出的模型存在可重复的差异；不是仅把网络变平滑。
- H2：这种差异在重新计算每个网络的真实模型残差界后仍存在。
- H3：在相同控制器、状态集合算法和约束下，估计层面的收益能传递到控制层面。
- H4（扩展）：在给定域、噪声界、观测配置和终端条件下，可以求得更宽松的充分丢测容忍条件；不预先假定该条件存在。

当前纳入：平面四旋翼、固定离线网络、气动加速度残差、间歇位置与持续有界姿态/角速率观测、状态 SMF、硬约束控制。三维与高保真是后续外部有效性验证。

暂不纳入：在线改变网络权重、同时识别质量/推力系数/风、自由潜空间 Koopman、端到端视觉、强化学习控制策略、多机、故障容错、实机飞行自动执行。排除项是本轮研究规模控制，不是对其学术价值的判断。

## 2. 最近邻及必须超越的机制

- Köhler 等 2021 已有在线估计界 + 非线性输出反馈 MPC + 四旋翼；不能将此组合宣称创新。
- Pan 等 2025 已有深度 Koopman + 集员状态估计；不能将深度学习接入 SMF 宣称创新。
- Kayalibay 等 2023 已有 Filter-Aware MPC；不能将考虑估计质量宣称创新。
- Shen/Chou 2026 预印本已训练可达集友好的模型/控制器；必须与纯预测可达集训练作直接对比。

详见 [来源矩阵](06_sources_and_tools.md)。没有文献使用相同名称不等于没有相同机制。

## 3. 交付与主张等级

| 标签 | 含义 | 允许的论文表述 |
|---|---|---|
| DERIVED | 本方案给出可检查的代数推导 | 指定模型下的恒等式/包含推导；不是原创定理 |
| CONDITIONAL | 在明确真值包含、噪声界等假设下成立 | “在 A1–A7 下……”；还需正式证明检查 |
| NUMERIC_CHECK | 有限浮点、样本或网格核查 | 未发现反例，不等于全域证明 |
| EMPIRICAL | 独立测试轨迹统计 | 仅报告测试域/工况内表现 |
| OPEN | 未完成的新理论或算法 | 候选命题/待验证假设，不能放进结果摘要 |

三层保证不能混用：网络输出可验证 ≠ 网络覆盖真实物理系统；状态真值被包含 ≠ 集合宽度有界；集合有界 ≠ MPC 递归可行/闭环稳定。

## 4. 技术路线的冻结选择

初版采用六维物理状态、两维控制、两维学习残差、小型 tanh MLP。采样 0.02 s，控制时域 N=25；这些是初始设计参数，不是实机已辨识常数。位置正常每 5 个控制周期到达；最多连续缺失 2 个**位置数据包**，等价于成功位置观测间隔不超过 15 个控制周期（其间最多 14 个空 tick）。偏置与姿态估计误差必须进入观测界，不能把“IMU 持续工作”当成准确姿态可用。

按固定模型训练 A/B/C/D，重新标定各模型残差包络；先比较开环集合和真实后验集合，再比较闭环。安全声明使用全域有效包络；经验残差界只能支持经验结果。

## 5. 阶段门槛

| Gate | 必须交付 | 不通过怎么办 |
|---|---|---|
| G0 问题冻结 | 统一模型、假设、指标、阶段表、查新矩阵 | 修复定义，不训练 |
| G1 数学最小原型 | 独立真值、部分观测接口、集合运算、数据拆分 | 禁止真值进入在线控制；定位包含失败 |
| G2 认证基线 | 每模型全域残差界、SMF 重放、物理基线 | 无法认证时只能切为经验轨道 |

| G6 三维迁移/写作 | 独立高保真模型、论文资产、复现包 | 保留为平面方法研究，不虚构迁移成果 |

## 6. 科研决策规则

在测试集解封前冻结一个主终点：S2/S3 上 D 相对 C 的轨迹级归一化后验速度宽度 W^v（定义见 04），控制主终点在 G4 单独冻结为任务成功率（全程约束满足 + 无失效 + 完成跟踪）。其余为次要指标。效应阈值与样本量通过训练/验证 pilot 决定并写入注册文件，不能根据测试表现选择阈值。

硬停止条件：一次实际真值漏包却仍继续声称确定性包含；D 优势仅由较小但无效残差界产生；仅与 PID 比较；通过删失败样本改善均值；安全动作使用未来真实测量；同等预算物理模型已充分解释全部收益。

D 无优势是有效负结果。优先检查：测量修正是否截去了 C 优化的全部方向；残差界是否主导宽度；集合算法冗余是否掩盖模型差异；丢测长度是否不在模型敏感区。只允许使用验证数据调整一次机制；再次失败则将研究转为“何时后验训练无优势”的边界分析，或停止此方向。
