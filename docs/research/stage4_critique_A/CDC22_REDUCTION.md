## 2. 即时处理为何不能直接套用整包开关

以下在一般线性模型上解释接口，在数值例中取单轴。对 \(L=2\)，令 \(z_k=(x_k,x_{k-1},x_{k-2})\)，首行按原系统传播，后两行仅移位。抽象高层输入和过程扰动只进入首行。定义 \(S_j z_k=x_{k-j}\)。若本拍收到的包龄集合为 \(J_k\subseteq\{0,1,2\}\)，真实观测按固定顺序堆叠为
\[
  Y_k=\operatorname{col}_{j\in J_k}(C_p S_j z_k+\nu_{k-j}).
\]
启动拍仅选择存在的生成戳。联合轨迹必须沿用实际输入和每个戳自己的误差变量。这个描述与完整已交付历史有双向映射，能用于强对照。

**同一二值前缀的反例。** 用生成戳 \(0,\ldots,5\) 的时延列表示两条合法前缀：
\[
 (0,0,0,2,2,2),\qquad (0,0,0,\mathrm{miss},2,0).
\]
前几拍相同，两者在拍 5 都恰好收到一个值为零的包。前者约束 \(p_3\)，后者约束 \(p_5\)。从原点出发，命令为零，前 3 次转移扰动为零，后 2 次各取 \(1/50\) m/s²，则 \(p_3=0,\ p_5=1/100\) m，\(v_5=1/50\) m/s。这个可达状态符合前者；在后者，零读数要求 \(|p_5|\le1/200\) m，排除了它。后者本身有零轨迹见证。故即使保留每拍的包数和不带戳的数值，仍无法从相同的二值记录恢复两组不同后验。该反例针对**原物理时钟、仅状态移位、整输出共用一位开关**的直接代换；没有排除改变编码或扩展定理的其他方法。

若把每个物理拍拆成多个顺序固定的包龄时隙，各时隙的二值开关可以无损传送整个 \(J_k\)。要沿用定理，须落实每个时隙的观测行，冻结物理状态与过程扰动直至真正的转移时隙，并禁止在时隙中途执行物理命令。若改为分量级响应列置零，还须使不同潜在路径的仿射增益在相同可见前缀上兼容。该路线提供直接的强竞争方法；本轮没有把这两种扩展宣布为已验证的定理。

## 3. 可以化为二值通道的强基线

在拍 \(k\ge L\) 只释放戳 \(k-L\)。该戳若生成，到此拍必已送达；若未生成，用缺测标志。于是
\[
 q^{\rm buf}_k=g_{k-L},\qquad C^{\rm buf}=C_p S_L ,
\]
\(g_s\) 表示该戳是否生成。读取 \(g_s\) 只用截止时已经掌握的信息。数值例的生成端每两拍至少生成一次，缓冲启动后仅需记上一个已到期的生成标志即可识别缺测图节点：上次生成时下次可有或无，上次未生成时下次必须有。启动阶段采用已知先验与空队列；在 \(k<L\) 的前导空拍不得伪造历史数据或自动假定进入某个误差球。这给出了二值估计器的观测通道和可见信号；完整定理准入、预测/后验时钟和估计器类别仍按上表审查。

**为什么最坏信息界持平。** 固定生成序列、决策拍和已知输入。缓冲的读数是即时读数的子集，因此即时后验包含于缓冲后验，任一坐标区间的半宽至多与缓冲相等。反向，选这条生成序列的每个包均在其最大延迟时送达；它在当前合同下合法，且两种策略此时逐戳使用完全相同的数据。缓冲截止前的到达时钟与状态无关，量测值与初始/扰动取值仍有相同的可行范围。由此对所有合法时序及连续读数取上确界，两种策略的最坏坐标半宽相等。论证对任一固定决策拍成立。它未要求每条记录都相等，也没有证明沿反馈闭环的性能等价。若语言排除了所有包同时取最大延迟，或发送机制依赖状态、传感器主动调度，反向构造要重新检查。

这是该信道信息结构的推论，不依赖某种滤波实现或 CZ 运算。**不再将“即时保留优于二值截止缓冲的全语言最坏坐标预算”作为 A 的预期贡献。** 对 A 有意义的比较是可见时序条件下何时能释放余量、这种余量在所有后继上能否安全利用，或在相同全局预算下能否认证更低的计算/记忆开销。

**接受“同一个可行代表点”所需的论证。** 固定有效戳集合，初值/扰动/量测误差是中心对称的凸盒。两条产生相同输出的可行潜变量之半差仍在原盒中，且落入零输出切片；故任意读数下的坐标半宽不超过零读数切片的正支持。零切片的正负极值使上界取到。对一轴的 \((p,v)\) 紧凸后验，两坐标区间的中点组成的向量必在后验中：对非退化坐标归一化到 \([-1,1]\)，若原点在紧凸集外，则存在严格分离原点的法向。取法向绝对系数最大的坐标，在集合中选择该坐标与法向反号的端点，另一坐标贡献最多抵消它，与严格分离矛盾。若有退化坐标，则退化为区间。因而在这两个决策拍，可以用当拍后验的同一个可行点同时取得两个坐标半宽；它们的最坏值可分别来自不同记录。该论证可按独立三轴笛卡尔积复用，不适用于任意耦合六维后验。

**如何独立验算。** 对每个决策拍，用戳集合表示可见的约束。枚举所有前缀后，零读数截面按戳集包含关系单调缩小，只需对每组的极小戳集求最坏支持。第 8 拍即时/缓冲/丢弃各有 136/34/200 种有效戳集，各剩 7/7/4 个极小集；证书另含正反对照。对每个待核方向 \(q\)，设潜变量盒半径向量为 \(d\)，位置观测矩阵为 \(H\)。任意乘子 \(\lambda\) 给零读数切片上界 \(n\|\lambda\|_1+\sum_j d_j|q_j-(H^\top\lambda)_j|\)。存档的盒内原始点逐行满足 \(|H\xi|\le n\)，并在有理数运算中精确取到相同值。HiGHS 只提议乘子与极值点，验算路径用 Python 标准库重枚举并核对等式。[源码](cdc22_reduction_check.py) · [精确证书、对照、版本与哈希](cdc22_reduction_certificate.json)

## 5. 独立的滑动窗口证明：缓冲基线能重复达到这个物理误差盒

这一节是上述有限实验后的解析推论，适用合同和假设与数值例相同。下面的上界从每拍均成立的戳覆盖条件推出，无须把第 8 拍的初始集合重置到原点。

对任意 \(k\ge6\)，考虑生成戳区间 \([k-6,k-2]\)。在决策前，这五个生成标志对截止缓冲器已知，每两个相邻戳至少生成一次。取最新已生成戳 \(t\)，记 \(h=k-t\)，则只有两种情形：

- \(h=2\)。在 \(t-1,t-2\) 中取一个已生成戳 \(s\)，戳距 \(d=t-s\) 为 1 或 2。
- \(h=3\)。在 \(k-5,k-6\) 中取已生成戳 \(s\)，优先前者，此时 \(d=2\) 或 3。

对这两戳，令 \(\beta_d=2n/(dT)+adT/2\)。由 ZOH 差分与随后 \(h\) 次传播，当前速度、位置半宽分别至多为 \(\beta_d+ahT\) 和 \(n+hT\beta_d+a(hT)^2/2\)。例如零命令时取速度代表 \((y_t-y_s)/(dT)\)，位置代表 \(y_t+hT(y_t-y_s)/(dT)\)，端点读数误差和加速度界即给出所述外包。增加窗内其余可用读数会进一步约束后验。为保证代表点本身也在所用窗口后验中，可取该二维后验的坐标区间中点（见上节）；不要求简单的两戳外包中心满足其余读数。[仓库已有两戳差分关系](../proposal/FINITE_MEMORY_THEORY.md)

代入四种 \((h,d)\) 组合，得到对每个 \(k\ge6\)、每个合法连续记录均成立的位置/速度界 \((3/50,\ 31/600)\)。启动的 \(k=4\) 已由有理数证书覆盖，\(k=0\) 取初始盒。因此在每个正块末 \(4,8,12,\ldots\)，截止缓冲和即时保留的两个坐标最坏半径各自不超过上式；第 8 拍的可达极值证明这两个**跨所有块末的统一常数均为紧界**。两组在所有块末都能满足预先登记的 \((7/100,\ 21/400)\)；丢弃组仅凭第 8 拍失败即可否定同一目标。对块内拍给一个保守界也足够：\(k\le5\) 用启动盒传播，最松在 \(k=5\)，半径为 \((37/400,\ 3/50)\)；\(k\ge6\) 的上述上界逐坐标更小。

**记忆如何跨块接续。** 运行初期保留原初始盒和已到期的位置约束。自 \(k=6\) 起，保留最近六次实际转移所需的输入、上述五个到期戳的生成标志/可用读数，以及尚未到期的短包队列；在窗首允许任意状态，仅施加窗内动力学、误差界及读数约束。每个相容的真实轨迹都提供该窗的可行见证。对任一合法后继，真轨迹的共同后缀加下一次真实转移仍是新窗的见证；每两戳至少生成一次的性质对新窗继续成立，相应包均按截止交付。故无论是否跨越四拍边界，都有非空且受同一两戳界约束的窗口后验。可达边界记忆按此滚动，不在边界清空。这里的在线代表点属于**所用的窗口后验**；若要求属于完整历史精确后验，取后者的二维坐标中点也满足同一预算，但本证据不保证精确全历史代表点能以相同记忆计算。即时保留组可直接在同一有限窗口加入最新已交付的约束，并按同样方式选中心。

这建立了从本项目指定先验启动、沿全部合法后继的**估计侧重复预算**。它不担保删除在途记忆后从目标盒内任意重启，亦没有为原文式 (18) 的每个增广节点误差球求出仿射增益。它使用已有的有限记忆差分界；本轮新增证据是该强基线的紧性和对创新主张的否定作用。

以下标准库核对覆盖引理中的所有五戳模式，仅用于复算常数。

~~~python
from fractions import Fraction as F
from itertools import product

a, n, T = F(1,50), F(1,200), F(1,2)
def window_bound(bits):
    # bits are the generation flags at k-6,...,k-2; all are known by k.
    ages = [6-i for i,x in enumerate(bits) if x]
    h = min(ages)
    choices = (h+1,h+2) if h==2 else (5,6)
    assert h in (2,3)
    older = next(age for age in choices if age in ages)
    span, age = (older-h)*T, h*T
    b = 2*n/span + a*span/2
    return n+age*b+a*age**2/2, b+age*a

legal = [w for w in product((0,1),repeat=5) if (0,0) not in zip(w,w[1:])]
bounds = [window_bound(w) for w in legal]
assert len(legal)==13
assert tuple(map(max,zip(*bounds)))==(F(3,50),F(31,600))
print("13 legal windows; steady upper radii:",*(max(c) for c in zip(*bounds)))
~~~

## 6. 复审决定

维持 A、阶段 4。即时带戳后验的朴素二值代换有反例；全语言最坏信息界有等价二值缓冲基线；在冻结的单轴合同下，该基线通过滚动历史得到紧的统一块末坐标预算。尚未验证的是 CDC 定理 2 的指定仿射结构和节点球能否取到同一常数，以及利用提前到包的条件性余量对控制是否有用。控制收紧、终端和十二状态物理覆盖均保持未证。此前 Light 的独立领域评议和盲留证据缺口仍在，已有评审记录保留原样。

**下一项只检验条件性误差余量的控制价值。** 在同一可达前缀、名义状态、初始准入、控制律及终端条件下，将即时保留分别与截止缓冲和同信息精确增广比较。先检查至少一条实际限制决策的原始状态或输入约束，是否因提前到包而增加可认证的共同首步，然后检查所有后继能否容纳旧计划的尾段。若只比丢弃组有利，或支持改善停留在不活跃行，只保留信息价值结论。继续暂缓阶段 5。
