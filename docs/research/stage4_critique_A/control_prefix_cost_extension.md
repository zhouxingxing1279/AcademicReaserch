# 原调节代价的追加检查

零名义记录的首步可行区间已得到分离，而零参考代价的最优命令仍为零。为区分可行性与最优决策，再检查一个构造的非零名义记录。此为在上述结果之后另列的探索性检验。

保持同一原点初始先验、信道、输入与状态硬界、反馈增益、12 拍时域、终端及两种首步检查。令前四拍名义命令为 −5/8、后四拍为 +5/8；真实扰动与测量误差取零，位置读数由实际轨迹生成。决策 8 时名义状态应为 (−5/2,0)，创新为零。沿用原调节代价 Q=diag(4,1)、R=1/5 和由终端反馈生成的 P。对主记录和截止到达对照，先核对以前每个已执行首步的鲁棒续接，再以严格凸二次规划的原始可行性、乘子符号及驻点条件判别实际最优首步是否分离。保留不分离或证书失败的结果；不改权重、边界或判据。无需运行或修改飞控和现有在线控制器。
