# 增益筛选与任意允许缺测下的观测误差界

日期：2026-09-13。承接 [07 固定候选否证](07_terminal_candidate_obstruction.md)。本节在不改变原扰动、噪声或缺测合同的前提下，给出一个通过现有必要条件的新高度候选，并证明其位置观测器对任意允许包间隔序列具有统一误差界。

**已证明的是观测误差有界、无约束竖直外包系统的有界性，以及一个明确的误差证书改进；尚未证明原状态/推力约束或六维终端闭合。** 本节不覆盖非线性真实模型在原域外的行为，不恢复控制仿真或训练。

## 1 固定比较对象与新候选

沿用 06 的竖直线性外包与位置观测更新，仍采用成功包位置增益 1。仅将待验证高度参数提议为：

```math
k_p=5,\qquad k_d=3,\qquad \ell=9/2.
```

即 $`t=-5\hat p-3\hat v`$、成功包速度校正为 $`\hat v^+=\hat v^-+(9/2)r_p`$。角控制与水平观测器没有在此重新合成；不能将竖直证明自动用于水平轴。

使用 06 的完整竖直外包半宽：

```math
|w_j|\leq D=572143/160000=3.57589375,
\qquad |n_j|\leq\varepsilon=1/50.
```

这里 w 可以任意变化、与观测误差相关。该盒属于原域与输入界上的可靠外包；将其作为全空间抽象模型分析时，可以研究有界性，但将结论转回真实系统仍需另证不出域。

## 2 成功包之间的准确误差映射

记成功包时刻 s 的速度误差为 E，位置噪声为 n_s。位置增益 1 给出 $`e_p(s)=-n_s`$。下次成功包为 s+L，其中 L=5、10、15。直接展开 06 的预测和校正：

```math
E^+=(1-\ell Lh)E
+h\sum_{j=0}^{L-1}[1-\ell h(L-1-j)]w_{s+j}
+\ell(n_s-n_{s+L}).
```

此式明确保留两端噪声；不能将 n_s 误当成零，也不能在变号权重求和时丢掉绝对值。定义：

```math
a_L=|1-\ell Lh|,\qquad
b_L=h\sum_{j=0}^{L-1}|1-\ell hj|.
```

因此：

```math
|E^+|\leq a_L|E|+Db_L+2\ell\varepsilon.
```

如果全部 a_L<1，取：

```math
R(\ell)=\max_{L\in\{5,10,15\}}
\frac{Db_L+2\ell\varepsilon}{1-a_L},
```

则 $`|E|\leq R(\ell)`$ 蕴含每一种后继 $`|E^+|\leq R(\ell)`$。逐包归纳覆盖任意允许的间隔切换，不要求周期测量或随机独立。相同扰动和噪声下两条误差递推的差至多按 $`\max_L a_L`$ 每包收缩，但这不代表持续噪声下误差趋于零。

上述 R 是满足这三条标量充分不等式的最小非负数；不声称它是实际可达误差的最小界，也不声称 ℓ=9/2 是所有观测器中的最优增益。

## 3 定量严格改进与启动期覆盖

对新增益，精确系数为：

| L | a_L | b_L |
|---:|---:|---:|
| 5 | 11/20 | 41/500 |
| 10 | 1/10 | 119/1000 |
| 15 | 7/20 | 657/5000 |

最大比值由 L=5 给出，因此：

```math
R(9/2)=\frac{41}{225}D+\frac25.
```

对于同一 D、ε、允许间隔及同一种标量验证方式，旧速度增益 ℓ=5 给出：

```math
R(5)=\frac{13}{50}D+\frac25,
\qquad
R(5)-R(9/2)=\frac7{90}D>0.
```

这是对明确误差界的严格改进，且不使用学习模型。必须交给所有非学习基线同样使用；不能将它包装为神经优势或逐条轨迹误差下降。

启动期不能假设已有上一个成功包。若零时刻位置成功，按 06 初始化 $`\hat v_0=0`$，故 $`|E_0|\leq0.1`$。若零时刻失败，首次成功在 q=5 或 10；初始 $`|e_p(0)|\leq0.02,|e_v(0)|\leq0.1`$，其速度误差满足：

```math
|E_q|\leq |1-\ell qh|\,0.1
+\ell(0.02+\varepsilon)+Db_q.
```

两种 q 的界均不超过新 R。首次成功前仍按初始先验传播，不能虚构 -n_s。成功包之后，距上次成功 j 步的先验界为：

```math
|e_v|\leq R+jhD,\qquad
|e_p|\leq\varepsilon+jhR+\frac{h^2j(j-1)}2D.
```

到达前先验必须覆盖 j=15；无校正的控制时刻最多 j=14。此处只证明误差有界，不保证估计中心或这些盒位于任务域。

## 4 高度增益筛选：必要条件与无扰动名义稳定

07 的平均高度条件对每一个允许固定 L 都是必要条件。按更强的完整外包幅值 D 检查新参数：

```math
D\left[\frac{1+k_d/\ell}{k_p}
+\frac{h(L-1)}{2\ell}-\frac{h^2(L^2-1)}{12}\right]\leq\frac32.
```

L=5、10、15 的三个条件均通过。由于 kd>0、kp>0，这也覆盖幅值不超过 D 的正负恒定扰动平均值限制。但不能据此推断任意时变扰动的瞬态安全。

真实竖直状态写成：

```math
\begin{bmatrix}p^+\\v^+\end{bmatrix}
=A_c\begin{bmatrix}p\\v\end{bmatrix}
+\begin{bmatrix}0\\h\end{bmatrix}(w+k_pe_p+k_de_v),
\qquad
A_c=\begin{bmatrix}1&h\\-hk_p&1-hk_d\end{bmatrix}.
```

对二阶特征多项式，Jury 三条件等价于：

```math
h^2k_p>0,\qquad hk_d-h^2k_p>0,\qquad
4-2hk_d+h^2k_p>0.
```

新参数给出的左侧分别为 1/500、29/500、1941/500，均严格为正，因此 A_c 为 Schur 矩阵。这只认证竖直名义矩阵，不认证整个六维非线性闭环。

## 5 任意允许缺测下的无约束竖直有界性

第 2、3 节已对任意包序列建立有限误差界，包含启动期和包间传播。令 $`b_k=w_k+k_pe_{p,k}+k_de_{v,k}`$；它具有与总运行时间无关的有限界。状态展开为：

```math
x_k^z=A_c^k x_0^z+\sum_{j=0}^{k-1}A_c^{k-1-j}B b_j,
\qquad B=(0,h)^\top.
```

Schur 性使矩阵幂绝对可求和，故存在有限常数 C、r<1，使 $`\|A_c^k\|\leq Cr^k`$，进而：

```math
\|x_k^z\|\leq Cr^k\|x_0^z\|+
\frac{C\|B\|}{1-r}\sup_j|b_j|.
```

这证明无饱和竖直抽象模型在允许切换下有界，不需要把三个固定周期的谱半径结论误当作任意切换稳定性。证明利用了“误差自主有界 + 固定 Schur 真实状态子系统”的结构。

但这个上界没有被证明小于原高度、速度或推力限制，也没有给出合格的模式多面体。饱和会改变 A_c；不能在输入越限后继续沿用该有界性结论为真实控制作保证。

## 6 下一步的精确准入

新候选已避开 07 的恒定竖直扰动平均矛盾，并有任意允许缺测的误差界。下一步应先针对**竖直位置、速度、估计误差及当前噪声的联合集合**验证原高度、速度、推力约束。保留相关性后求支持上界或有限不变多面体；若仍不可行，需要明确是候选被反例否定，还是仅某种集合表示/外包不足。

只有竖直硬约束通过后，才将它与姿态参考及水平推力耦合，形成新的完整六维模式证书。不得将 06 已归档矩阵冒充已更新的新参数矩阵；本节只归档公式和参数核对，原模型文件与失败证据不改写。
