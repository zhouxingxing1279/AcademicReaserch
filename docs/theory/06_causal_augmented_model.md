# 六维终端合成前的因果增广模型与全域仿射外包

日期：2026-09-13。承接 [05 有限终端证书](05_finite_terminal_polytope.md)。

本节固定一个可计算的输出反馈候选结构，消除 05 中控制器内部状态 χ 和后继映射尚未定义的缺口。给出覆盖原域的解析非线性余项界，以及成功测量/缺测的 14 维增广仿射映射。**尚未求出不变多面体，以下候选增益没有获得安全或稳定准入。** 不运行控制轨迹，不修改原实验配置。

## 1 状态、测量与实际输入时序

将位置平衡点平移为 $`p=(p_x,p_z-2)`$，其余状态不变。真实状态为 $`x=(p,v,\phi,\omega)`$。控制器内部状态选为：

```math
\chi=(\hat p_x,\hat p_z,\hat v_x,\hat v_z,\psi,\rho,y^\phi,y^\omega)\in\mathbb R^8.
```

当前测量先更新 χ，再生成实际输入。控制器只读取 χ，不能读取真实 x。选择以下有理数候选，目的仅是固定待验证矩阵，而非宣称参数最优：

```math
t=-\hat p_z-2\hat v_z,\qquad T=g+t,
```

```math
\mu=\frac4{125}\hat p_x+\frac8{125}\hat v_x
-\frac8{25}\psi-\frac4{25}\rho,
\qquad
\tau=\mu-\frac8{25}(y^\phi-\psi)-\frac4{25}(y^\omega-\rho).
```

正水平位置对应正倾角参考需求，与水平推力符号一致。参考连续递推，不能在位置包到达时重置：

```math
\psi^+=\psi+h\rho,\qquad \rho^+=\rho+\mu.
```

此候选仍须证明 $`|\mu|\leq0.0672`$、参考后继在 05 的核内及真实输入约束。没有在公式后加饱和：饱和会改变待证映射，必须单独分区建模。

## 2 预测与观测更新的有限内部记忆

使用线性中心预测，非线性余项进入误差证明：

```math
\hat p^-=\hat p+h\hat v,\qquad
\hat v^-=\hat v+h(-g y^\phi,t)^\top.
```

到达下一时刻后，若位置包成功，令已减去平衡点的测量为 $`y_p^+=p^++n_p^+`$，更新：

```math
r_p=y_p^+-\hat p^-,\qquad
\hat p^+=\hat p^-+r_p,\qquad
\hat v^+=\hat v^-+5r_p.
```

若无位置包，则 $`\hat p^+=\hat p^-,\hat v^+=\hat v^-`$。两种情况均存入下一角测量：

```math
y^{\phi,+}=\phi^++n_\phi^+,\qquad
y^{\omega,+}=\omega^++n_\omega^+.
```

位置残差为同一个向量，不能在位置、速度两处换成互不相关的“测量中心”。允许在最后求支持函数时保守外包相关性，但原映射应保留它。增益 5 的单位为每秒；它仅是固定的合成候选，不保证在全部缺测模式下估计稳定。

## 3 覆盖原任务域的解析余项

原离散模型精确改写为：

```math
p^+=p+hv,\quad
v_x^+=v_x+h(-g\phi+d_x+R_x),\quad
v_z^+=v_z+h(t+d_z+R_z),
```

```math
\phi^+=\phi+h\omega,\qquad \omega^+=\omega+\tau,
```

其中 $`|d_x|\leq1.880,|d_z|\leq2.086`$，并且：

```math
R_x=-t\phi+T(\phi-\sin\phi),\qquad
R_z=T(\cos\phi-1).
```

Taylor 积分余项给出对全部实数角度成立的界 $`|\phi-\sin\phi|\leq|\phi|^3/6`$ 和 $`|1-\cos\phi|\leq\phi^2/2`$。在候选源集合上若已证明 $`|\phi|\leq\Phi,|t|\leq b_t,0<T\leq T_{\max}`$，则：

```math
|d_x+R_x|\leq D_x=1.880+b_t\Phi+T_{\max}\Phi^3/6,
```

```math
|d_z+R_z|\leq D_z=2.086+T_{\max}\Phi^2/2.
```

可使用原域 $`\Phi=0.45,b_t=4.905,T_{\max}=14.715`$，得到无需采样的全域外包。若之后在更小候选域取得更紧参数，必须先证明该域的投影和输入界；不能先假定后继不出域，再使用这一假定证明闭合。

这里 d 与 R 的独立盒只增加允许后继，不删除真值；可能非常保守。不能以该盒无法找到不变集断言真实系统不存在安全控制器。若以后引入气动结构，须明确知识合同，并让所有比较基线使用同样知识。

## 4 误差递推检查：测量更新不会凭空消除速度不确定性

定义当前 $`e_p=p-\hat p,e_v=v-\hat v`$，$`n_\phi=y^\phi-\phi`$，$`w=(d_x+R_x,d_z+R_z)`$。则：

```math
e_p^-=e_p+h e_v,\qquad
e_v^-=e_v+h\bigl(w+(g n_\phi,0)^\top\bigr).
```

成功位置包后：

```math
e_p^+=-n_p^+,\qquad
e_v^+=e_v^- -5e_p^- -5n_p^+.
```

缺测则保留先验误差。证明直接相减，不用独立噪声或零均值。特别是速度更新中必须保留 $`-5e_p^-`$；将其遗漏会人为制造估计收缩。

## 5 观测模式与初始集合

离散模式取 $`\sigma=(r,m)`$，$`r=k\bmod5`$，m 是最近连续失败的位置包机会数，取 0、1、2。非机会时 $`r<4`$，下一步 $`(r+1,m)`$ 且不校正。$`r=4`$ 时成功转到 (0,0) 并校正；失败仅在 m<2 时允许，转到 (0,m+1)。因此有 15 个模式、17 条边，最长成功包间隔为 15 步。相同连续映射在多条边上重复，仍需逐边检查不同目标多面体。

初始先验保持原集合。零时刻位置机会成功时设置 $`\hat p_0=y_{p,0},\hat v_0=0`$、模式 (0,0)；失败时设置 $`\hat p_0=0,\hat v_0=0`$、模式 (0,1)。这是初始化而非上述运行更新。两者均取 $`(\psi_0,\rho_0)=(0,0)`$，存入实际初始角测量。若合同额外规定零时刻必成功，允许删除失败初始分支；当前采用同时覆盖两者的保守版本。

初始增广集合必须保留 $`y_0^\angle=x_0^\angle+n_0^\angle`$、成功时 $`\hat p_0=p_0+n_{p,0}`$ 的相关性，或使用经证明包含它们的外包。不能只代入零噪声或一个初始测量。

## 6 接入有限包含证书的具体对象

令 $`\xi=(x,\chi)\in\mathbb R^{14}`$，噪声顺序固定为：

```math
w_a=(d_x+R_x,d_z+R_z,n_{px}^+,n_{pz}^+,n_\phi^+,n_\omega^+).
```

半宽为 $`(D_x,D_z,0.02,0.02,0.005,0.01)`$。上述所有递推对 ξ 和该噪声都是线性的，所以成功和缺测分别得到准确的外包映射：

```math
\xi^+=A_\gamma\xi+G_\gamma w_a,\qquad \gamma\in\{0,1\}.
```

当前角测量噪声已包含在 ξ 中，不能再把它当成一个新的独立当前测量替换 χ。下一时刻噪声通过 G 注入。位置测量使用下一真实位置 p⁺，不是当前位置。
