# 理论优先设计：有界窗口估计、可验证集合改进与输出反馈 MPC

日期：2026-09-10。状态：**条件命题及证明草案已形成；四旋翼闭环证书、深度学习独立优势和首创性仍未成立，控制实现暂缓。**

本文件取代旧 00/05/12 中“继续收紧包络、随后补理论”的执行顺序。历史实验只作问题证据。用户明确要求先确定可证明优势，再进行技术实现；因此本轮没有修改控制/滤波代码、重新训练或运行新的轨迹试验。下述数学结论是本设计中的推导，不冒充文献原定理或原创成果。

## 1 先确定能够成立的主张

建议研究题目（候选）：**间歇测量下具有基线包含保证的学习辅助集员输出反馈预测控制**。

选择两个层次：先建立完全不依赖网络精度的物理有界估计与控制基础；网络动力学模型只参与提出值得验证的约束方向、求解初值和性能候选。只有经独立数学上界验证的附加约束才能缩小集合。保留网络的建模角色，但其点预测不能充当真实系统的确定性证明。

| 主张 | 本次结论 | 比较范围 |
|---|---|---|
| 物理窗口估计半宽不随运行时间无限增长 | T1 给出显式条件上界 | 已知扰动界、最大观测间隔、指定离散模型 |
| 学习辅助输出集合不大于基线 | T2 给出包含证明 | 同一历史、实际输入、先验和物理知识 |
| 在控制相关方向上严格收紧 | T3 给出可核查的充分条件 | 必须提供证书与严格间隔，不能只展示图 |
| MPC 可行决策集非减、最坏情形最优值非增 | T4 条件成立 | 同策略类、模型关系、代价与终端条件 |
| 闭环域内保持与递归可行 | T5 给出证明接口 | 还需实际构造不变族和移位闭合证书 |
| 神经网络比同预算非学习策略严格更好 | **未证明，也不能无条件保证** | 要求额外逼近/覆盖条件或限于经验结论 |
| 所有真实轨迹跟踪误差都更小 | **不作主张** | 鲁棒最优值比较不等于逐轨迹支配 |

若用户要求的“更优”必须包含任意系统、任意测量序列上的深度学习严格优势，则该目标本身不可实现，见 T0。可实现的目标是“有条件的确定性非劣 + 可核查的严格改进”。

## 2 T0：同信息条件下的极限

固定先验、动力学类、噪声界、全部可用输入测量历史，令所有与之相容的世界在当前时刻可能产生的状态集合为：

```math
\mathcal X_k^{\mathrm{exact}}
=\{x_k:\text{存在符合全部给定假设和观测历史的状态、扰动轨迹}\}.
```

任何要求对这些世界都具有确定性真值包含保证的估计器 $`\mathcal A`$，必满足：

```math
\mathcal X_k^{\mathrm{exact}}\subseteq\mathcal A(\mathcal I_k).
```

**证明。** 若某个相容状态被排除，则存在一个具有相同可见历史的合法世界以该状态为真值；估计器在该世界漏包，矛盾。证毕。

因此，相同信息下的网络不能可靠地排除精确物理一致性集合中的点。它只能帮助减少可计算外包络的冗余、加速计算，或在提供可验证的新信息后缩小允许世界集合。随机初始化、更多训练轮数和更低 MSE 都不是新物理信息。

反例：系统状态本来已精确已知，任何可靠估计都不能严格小于一个单点。有限数据的另一反例是两个未知函数在所有训练点一致、在未访问状态不同；无已知正则性或结构约束时，网络无法据这些数据给出普适的更小确定性界。

**设计决策：** 不再把“网络残差加独立全域误差盒”作为必须优于物理估计的主线，也不承诺深度学习的必要性。

## 3 模型、信息与不可省略的假设

沿用六维物理状态 $`x=(p_x,p_z,v_x,v_z,\phi,\omega)`$、实际输入 $`u=(T,\tau)`$、$`h=0.02\,\mathrm{s}`$。本阶段研究对象是仓库定义的离散 Euler 系统，不是连续动力学精确采样：

```math
p_{j+1}=p_j+h v_j,\qquad
v_{j+1}=v_j+h(\bar a_j+\delta_j),\qquad |\delta_j|\leq\alpha_j.
```

每个轴单独使用此式。位置测量误差不超过 $`\epsilon_p=0.02\,\mathrm m`$，每 5 个 tick 有一次位置数据包机会，最多连续丢失 2 包，故相邻成功包间隔 $`L\in\{5,10,15\}`$。姿态和角速率每 tick 有界观测；不能将其当作无误差真值。

以已到达的姿态测量 $`y_j^\phi`$ 和已知实际输入形成可计算中心加速度：

```math
\bar a_j=
\begin{bmatrix}
-T_j\sin(y_j^\phi)/m\\
T_j\cos(y_j^\phi)/m-g
\end{bmatrix}.
```

若在模型有效域内已证明气动分量界 $`|a_{\mathrm{aero},r}|\leq\bar d_r`$，用 sin/cos 的全局 1-Lipschitz 性可取：

```math
\alpha_{j,r}=\bar d_r+(T_j/m)\epsilon_\phi,
\qquad \epsilon_\phi=0.005.
```

这里不假设网络逼近误差已知。当前配置外部离散过程增量为零；若添加位置过程误差、速度增量误差、时间戳误差、推力执行误差，必须重新推导，不能沿用本表。

必须区分三种域：物理任务约束域、模型界有效的计算域、最终要证明控制不变的运行域。当前配置前两者相同，不自动意味着第三者存在。所有基于域内气动界的结论均“在轨迹留在计算域期间”成立，只有 T5 能消除这一停止时刻条件。

## 4 T1：由两次位置观测得到显式窗口有界性

设成功位置测量时刻为 $`t`$ 与 $`k=t+L`$。展开离散系统：

```math
p_k-p_t=Lh v_t+h^2\sum_{r=0}^{L-2}(L-1-r)(\bar a_{t+r}+\delta_{t+r}),
```

```math
v_k=v_t+h\sum_{r=0}^{L-1}(\bar a_{t+r}+\delta_{t+r}).
```

消去 $`v_t`$ 得到精确恒等式：

```math
v_k=\frac{p_k-p_t}{Lh}
+\frac hL\sum_{r=0}^{L-1}(r+1)(\bar a_{t+r}+\delta_{t+r}).
```

于是定义速度区间中心及半宽：

```math
c_k^v=\frac{y_k^p-y_t^p}{Lh}
+\frac hL\sum_{r=0}^{L-1}(r+1)\bar a_{t+r},
```

```math
R_k^v=\frac{2\epsilon_p}{Lh}
+\frac hL\sum_{r=0}^{L-1}(r+1)\alpha_{t+r}.
```

**结论。** $`|v_k-c_k^v|\leq R_k^v`$。证明仅需将两端测量噪声与各步加速度误差代入上式并作三角不等式；不需要独立性、零均值或持久激励。

若 $`\alpha_j\leq\bar\alpha`$，则：

```math
R_k^v\leq R^v(L):=\frac{2\epsilon_p}{Lh}
+\frac{\bar\alpha h(L+1)}2.
```

下一成功包之前经过 $`q\leq14`$ 个空 tick，用已知中心加速度传播中心，可取：

```math
R^v_{k+q}\leq R^v(L)+qh\bar\alpha,
```

```math
R^p_{k+q}\leq\epsilon_p+qhR^v(L)
+\frac{\bar\alpha h^2q(q-1)}2.
```

位置式中的 $`q(q-1)`$ 来自所定义的 Euler 模型；若采用含半步加速度的离散位置模型，系数会改变。位置与速度误差相关并不影响这个外包上界，但分别取盒会损失相关性。若要求测量到达前的预测集合也留域，还必须检查 q=L≤15，不能只检查 q≤14 的后验时刻。

因此，只要成功测量间隔有上界，速度与位置半宽有独立于已运行总时长的有限上界。两次测量前的启动阶段由已知初始集合直接传播，不能虚构前一次位置观测。

### 4.1 当前参数的算术示例

取 [原物理界](../research/01_model_and_bounds.md) 的保守向上取值 $`\bar d_x=1.880,\bar d_z=2.086`$，以及 $`T/m\leq14.715`$，可进一步向上取 $`\bar\alpha_x=1.954,\bar\alpha_z=2.160`$。这是公式代入，不是新轨迹仿真或严格浮点认证。

| 分量 | 成功观测时统一速度半宽上界 | 包间速度半宽上界 | 包间位置半宽上界 |
|---|---:|---:|---:|
| x | 0.518 m/s | 1.065 m/s | 0.236 m |
| z | 0.530 m/s | 1.135 m/s | 0.247 m |

这些取值向上覆盖 $`L=5,10,15`$、$`q=0,\ldots,14`$ 的上述算术结果。启动先验速度半宽 0.1 m/s 也满足该粗界。

测量到达前先验按 q≤15 检查时，保守速度半宽分别取 1.104、1.178 m/s，位置半宽分别取 0.258、0.270 m；后续控制域裕度应使用与实际检查时序匹配的先验或后验界，不能混用。

它说明：现有传感器合同允许构造一个不会因无限重复预测而使半宽无界的物理窗口估计器。它**没有**证明集合中心永不接近任务边界，也没有证明已有 zonotope 实现满足这个窗口界。将“现有实现超域”解释为“信息论上无法估计”是不成立的。

### 4.2 理论上的直接改进与公平基线

令旧的可靠外包集合为 $`\mathcal B_k^{\mathrm{old}}`$，窗口区间集合为 $`\mathcal W_k^{\mathrm{win}}`$。定义物理基线：

```math
\mathcal B_k=\mathcal B_k^{\mathrm{old}}\cap\mathcal W_k^{\mathrm{win}}.
```

它同时包含真值，并不大于旧集合，且其坐标盒不宽于窗口界。若旧集合在某一速度方向的支持值超出窗口上界，则该方向严格缩小。这个改进来自历史观测约束，**必须给非学习基线同样使用**，不能计为深度学习收益。

## 5 学习辅助的可验证附加约束

### 5.1 一致性集合与网络角色

令 $`\mathcal F_k`$ 为有限历史窗口上的状态、扰动、测量噪声联合可行集，包含所有实际历史轨迹：

```math
\mathcal F_k=\{(x_{k-H:k},d_{k-H:k-1}):
 x_{k-H}\in\mathcal P_{k-H},\quad
 x_{j+1}\in F_0(x_j,u_j),\quad
 y_j-C_jx_j\in\mathcal V_j\}.
```

其中 $`\mathcal P`$ 是可靠的到达集合，$`F_0`$ 是已证明有效的物理集合值转移关系；缺测 tick 不添加不存在的位置约束。为保证递归可行性，窗口推进还必须满足第 7 节的嵌套接口。

神经动力学模型 $`n_\theta`$ 可以产生候选轨迹及 Jacobian，用以提出支持方向 $`a`$、非线性验证器的分支优先级或初始点。随后求一个可靠上界：

```math
\gamma\geq\sup_{\zeta\in\mathcal F_k} a^\top\operatorname{proj}_{x_k}\zeta.
```

只有验证这个不等式后，才加入 $`a^\top x\leq\gamma`$。局部优化给出的可行点是最大化问题的**下界**，不能拿它当安全上界；神经预测值加经验裕度也不合格。验证器超时可以返回已证明的较松上界；没有证明则不接受该 cut。

### 5.2 T2：真值包含与基线非劣

将有限个通过验证的半空间记为 $`\mathcal H_{k,j}`$，定义：

```math
\mathcal X_k^A=\mathcal B_k\cap\bigcap_{j=1}^{m_k}\mathcal H_{k,j}.
```

若实际历史属于 $`\mathcal F_k`$、基线包含真值、所有支持上界可靠，则：

```math
x_k\in\mathcal X_k^A\subseteq\mathcal B_k,
\qquad h_{\mathcal X_k^A}(a)\leq h_{\mathcal B_k}(a),\ \forall a.
```

**证明。** 实际状态满足每一条验证过的半空间，故属于交集；交集包含于每一个因子。支持函数的单调性立即给出后一式。证毕。

这是同一历史和实际输入下的比较。闭环中若两个控制器选择不同输入，其后续历史不同，不能继续用这个式子比较两条独立运行轨迹。

运行表示必须保留基线约束。例如用 $`x=c_B+G_B\xi,|\xi|\leq1`$ 加线性 cut 的交集表示。允许只保留有限条附加 cut，但不能把交集无条件约简成一个可能越出 $`\mathcal B_k`$ 的普通 zonotope。若换表示，必须另证新输出仍包含真值并位于基线内。

### 5.3 T3：严格改进与控制方向

若存在某条有效 cut 满足：

```math
h_{\mathcal B_k}(a)>\gamma,
```

则 $`h_{\mathcal X_k^A}(a)\leq\gamma<h_{\mathcal B_k}(a)`$。可用基线中已验证可行点 $`x^{\rm wit}`$ 提供严格证据：

```math
a^\top x^{\rm wit}\geq\gamma+\varepsilon,\qquad\varepsilon>0.
```

只在这些方向证明严格收紧，不声称所有方向都变小。有效线性 cut 最多恢复精确一致性集合的闭凸包。例如精确集为 {-1,1}、基线为 [-1,1] 时，基线虽然包含不可能状态，也无法用任何有效半空间进一步缩小。若 $`\mathcal B_k`$ 紧、凸、满维，且 cut 严格穿过内部，则还可证明体积严格减小；不是所有低维集合都适用体积指标。

控制主指标优先使用约束传播后的法向。固定线性误差传播 $`A_K`$ 时，未来约束法向 $`q`$ 对当前误差的相关方向为 $`a=(A_K^i)^\top q`$。与控制无关的方向收紧未必带来控制收益。

### 5.4 学习本身能够增加什么

T2/T3 对任何方向提议器都成立，因而它们不是“神经网络比所有非学习方法强”的证明。需要固定验证预算和方向候选库，用物理启发式/均匀方向/贪心搜索作为同预算强基线。

可研究的附加命题是有限候选库上的选择误差界。若真实有效收益为 $`g(a)`$、学习预测为 $`\hat g(a)`$，并在当前查询上已经保证 $`|\hat g(a)-g(a)|\leq\eta`$ 对全部候选成立，则选择预测最大方向有：

```math
g(\hat a)\geq\max_a g(a)-2\eta.
```

**证明。** $`g(\hat a)\geq\hat g(\hat a)-\eta\geq\hat g(a^*)-\eta\geq g(a^*)-2\eta`$。要比某个固定启发式严格更好，还需最优收益差超过 $`2\eta`$。当前没有该一致逼近证书，所以这只是条件扩展，不能作为已完成贡献。

如果学习版本保留同一个非学习基线已接受的所有 cut，再增加已验证 cut，可以继承非劣性；但它消耗额外时间，这不能称为同总预算优势。

## 6 T4：估计优势何时传递到 MPC

### 6.1 同一决策问题的可行性与最坏值比较

固定同一信息历史、动力学关系、策略类 $`\Pi`$、传感器合同、阶段/终端代价及终端条件。令 $`\Omega_A\subseteq\Omega_B`$ 是原始不确定量的允许集合，包含当前状态、未知模型参数、未来过程噪声、测量噪声及丢包序列。未来状态和实际测量值由同一个策略与这些量共同诱导，不能把策略相关的未来测量值预先冻结。任何固定输出反馈策略均为同一历史空间上的因果映射；若采用策略相关的世界集合定义，则必须对每个候选策略分别证明嵌套。

```math
\mathcal P(\Omega)=\{\pi\in\Pi:\text{对全部 }\omega\in\Omega\text{ 满足约束及终端条件}\}.
```

那么：

```math
\mathcal P(\Omega_B)\subseteq\mathcal P(\Omega_A),
```

```math
J^*(\Omega_A)=\inf_{\pi\in\mathcal P(\Omega_A)}\sup_{\omega\in\Omega_A}J(\pi,\omega)
\leq J^*(\Omega_B).
```

**证明。** 面对更大世界集合可行的策略对其子集仍可行。对任一基线可行策略，缩小 supremum 的取值域不会增大代价，再对扩大后的策略集取 infimum。证毕。

严格集合收缩未必使可行集严格扩大，也未必使最优代价严格下降。严格可行域扩大需要给出基线排除、改进后可行的决策见证。严格最优代价下降另需证明：改进方案某个可行策略的可靠最坏代价上界 U_A，小于基线全局最优值的可靠下界 L_B（或已知精确基线最优值）。仅比较两个可靠上界也不够；两个局部求解器返回的目标值不能冒充全局最优值比较。

```math
J_A^*\leq U_A<L_B\leq J_B^*.
```

### 6.2 固定管状传播的具体接口

若两方法确实共用同一中心、$`A_K`$、扰动集和收紧算子，且初始误差集合嵌套，则：

```math
\mathcal E^A_{0}\subseteq\mathcal E^B_{0},\qquad
\mathcal E_{i+1}=A_K\mathcal E_i\oplus\mathcal W
\quad\Longrightarrow\quad\mathcal E_i^A\subseteq\mathcal E_i^B.
```

因此固定约束法向上的支持收紧非增。这只是简化说明。实际非线性输出反馈必须包含估计误差、跟踪误差及估计中心跳变；换网络中心、线性化点、反馈增益或终端集合后，不能直接套用该比较。

可使用 [Köhler 等的在线估计界输出反馈 MPC](https://arxiv.org/pdf/2105.03427) 作为证明参照，其 Theorem 3/4 还要求可检测性、增量可稳定性、未来估计界及终端条件。本文没有把这些前提视作当前四旋翼配置已经满足。

## 7 T5：超域必须通过信息状态不变性闭合

### 7.1 半宽有界还缺什么

例如当前速度域为 $`[-3,3]`$。T1 的后验粗界给出足够的中心裕度要求 $`|c^v_x|\leq1.935`$、$`|c^v_z|\leq1.865`$；若还要求到达前先验集合留域，则用更严格的 1.896、1.822 m/s 中心界。但这些条件均未被控制策略保证。位置、姿态、角速度同样需要裕度。不能把估计集合直接裁剪到物理任务域，除非已经从先验和控制证明真值不会离开该域。

### 7.2 信息状态不变族

信息状态 $`I`$ 包含估计集合、观测窗口、必要到达集合、传感器模式 $`\sigma`$ 及其记忆。设 $`\mathfrak K_\sigma`$ 是一族允许信息状态，每个元素所代表的状态集均在计算域内部。对每个 $`I\in\mathfrak K_\sigma`$，要求存在一个只依赖可见信息的控制输入 $`u=\kappa_B(I)`$，使：

```math
F_0(X(I),u)\subseteq\mathcal D_{\rm eval},\qquad
(X(I),u)\text{ 满足任务约束},
```

```math
\forall\sigma'\in\operatorname{Succ}(\sigma),\ \forall y^+\text{ 与 }I,u,\sigma'\text{ 相容},
\quad\operatorname{Update}(I,u,y^+,\sigma')\in\mathfrak K_{\sigma'}.
```

**结论。** 若初始信息状态属于该族，且每步执行满足这些条件的控制，则所有允许缺测序列下保持域内并有可用后续控制。证明是关于时刻的归纳：先验证整个预测集合在域内，故下一步仍可合法使用域内模型界，再使用全称测量条件进入下一族成员。

关键量词是 $`\exists u\ \forall x,d,y^+,\sigma'`$，不是“每个真实状态各自存在一个输入”。检查任一名义轨迹的稳定性或满秩线性化可观测矩阵不够。

### 7.3 MPC 移位闭合与近似表示

只证明当前集合较小不足以保证下次优化可行。必须规定：实际更新外包信息状态被当前规划对相应观测分支的预测信息状态覆盖；终端族在备用策略下不变；策略分支为因果输出反馈。然后上一时刻的策略尾部加终端备用策略构成下一次候选，才有标准归纳证明。

若将基线侧安全证书固定保留，学习 cut 可以是当前额外约束，未来预测必须允许它被遗忘时的外包结果。若希望在整个时域持续使用这些收紧，则应保留它们的传播后约束，或证明约简/窗口滑动后的表示仍被上一预测集合覆盖。不能同时“随意遗忘 cut”又“假设未来永远享有本次收紧”。

基线备用策略存在也不意味着学习策略可以先把系统带出基线可恢复域；每次接受的动作必须通过相同的信息状态后继检查。

### 7.4 稳定性单独列为待证

域内保持和递归可行不等于渐近稳定。若希望证明实际有扰动闭环的实用稳定性，需要额外构造信息状态 Lyapunov 函数及下降不等式，例如 $`V(I^+)-V(I)\leq-\alpha(\operatorname{dist}(x,\mathcal X_{\rm ref}))+\sigma(\bar w,\bar v)`$ 对所有相容后继成立，并给出上下界关系。当前未构造该函数，不能声称稳定性已经证明。

## 8 为什么这是一次设计重置

旧路线的网络预测误差变小、但集合超域，反映了模型分解和外包运算的保守性。继续分区加密不能回答“能否保持域内”“学习是否提供了可证明优势”。新顺序为：

1. 以 T1 建立窗口有界的物理基线，再检查可恢复运行域是否非空。
2. 在 T2/T3 框架下只接受可证明有效且有明确收益的附加约束。
3. 用 T4 约束可行性/最坏代价的主张范围，用 T5 建立递归关系。
4. 最后检验学习提议是否比同预算非学习提议有独立价值。

如果第 1 步无法在当前噪声与最大缺测条件下得到非空控制不变族，应调整研究工作域或传感器合同并明确版本变化；不允许把有限试验成功当替代证书。如果第 4 步无法形成可信优势，停止“深度学习改进”的论文主张，保留物理窗口理论作为基础工作。
