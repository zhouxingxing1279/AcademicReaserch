# 终端候选的确定性否证与高度增益必要条件

日期：2026-09-13。承接 [06 因果增广模型](06_causal_augmented_model.md)。

**结论：06 固定增益与独立全域余项盒的组合不能通过原域的终端不变性验收。** 这是可复核的反例，不是求解器超时或“暂时没找到集合”。不得继续为该组合搜索包含原初始集合、覆盖全部允许后继且投影在 D 内的证书。

否证范围是 06 的集合值外包模型。下述恒定竖直扰动未证明能由原解析气动公式的某个风序列实现，因此不据此否定真实非线性系统、其他控制器或结构更紧的模型。

## 1 一个合法抽象世界

取原初始集合的中心，所有测量噪声为零，位置每 5 步成功，水平状态和参考均为零。在 06 噪声顺序下选：

```math
w_a=(0,d,0,0,0,0),\qquad d=2.086=1043/500.
```

该数在 06 的竖直余项半宽内，甚至没有用到新增 Taylor 余项预算。因此仅去掉 Taylor 余项，仍不能修复使用相同独立气动盒的这组高度反馈。

竖直子系统精确为：

```math
p^+=p+hv,\qquad v^+=v+h(t+d),\qquad
 t=-k_p\hat p-k_d\hat v.
```

06 固定 $`k_p=1,k_d=2`$，成功包位置增益为 1、速度增益 $`\ell=5`$，$`h=1/50`$。p 已减去悬停高度 2，任务约束为 $`|p|\leq3/2`$。

## 2 周期测量下的误差极限，与物理闭环稳定性无关

对固定成功间隔 L，在成功包刚校正后位置误差为零，记速度误差为 E。连续传播 j 步后：

```math
e_v(j)=E+jhd,\qquad
e_p(j)=jhE+\frac{h^2j(j-1)}2d.
```

下一成功包速度校正给出：

```math
E^+=(1-\ell Lh)E+
\left[Lh-\frac{\ell h^2L(L-1)}2\right]d.
```

当 $`|1-\ell Lh|<1`$ 时，成功包误差收敛到：

```math
E_* =d\left[\frac1\ell-\frac{h(L-1)}2\right].
```

对一个周期的控制时刻 j=0,...,L−1 取平均，得到长期 Cesàro 平均：

```math
\overline e_v=\frac d\ell,\qquad
\overline e_p=c_Ld,\qquad
c_L=\frac{h(L-1)}{2\ell}-\frac{h^2(L^2-1)}{12}.
```

这里不是假设真实状态已收敛到平衡点；只使用估计误差递推的收缩及有限周期平均。06 在 L=5、10、15 时收缩因子分别为 1/2、0、−1/2。各固定周期的收缩不自动证明任意切换闭环稳定。

## 3 定理 H：有界安全轨迹必须满足的平均高度条件

假设上述恒定扰动下全部时刻 p、v 都有界。将位置、速度递推从 0 到 N−1 相加并除以 N，边界项趋于零，故：

```math
\overline v=0,\qquad \overline t=-d.
```

由 $`\hat v=v-e_v`$ 和控制律，$`k_p>0`$ 时可进一步推出平均值确实存在，且：

```math
\overline{\hat v}=-d/\ell,\qquad
\boxed{\overline p=d\left[\frac{1+k_d/\ell}{k_p}+c_L\right].}
```

若所有时刻 $`p\leq P`$，其平均不可能大于 P。这给出必要条件：

```math
d\left[\frac{1+k_d/\ell}{k_p}+c_L\right]\leq P.
```

对 06 的 L=5：

```math
c_5=9/1250=0.0072,\qquad
\overline p=\frac{1759}{1250}\frac{1043}{500}
=\frac{1834637}{625000}=2.9354192>1.5.
```

于是“原初始集合出发、在这个允许世界中永久满足 D”的假设矛盾。若存在包含原初态、对 06 全部后继闭合并投影在 D 内的非空模式族，归纳必给出上述不可能的安全轨迹。因此此种证书不存在，不论采用多少面或何种求解器。

## 5 如何修正研究路线

若坚持相同独立盒、相同观测器并采用一般高度 PD，则对每个允许固定 L 均须满足上述必要条件。当 $`P-dc_L>0`$、$`1+k_d/\ell>0`$ 时：

```math
k_p\geq\frac{d(1+k_d/\ell)}{P-dc_L}.
```

若分母非正且分子为正，则不存在正 k_p 满足该条件。将 L=5、10、15 的阈值同时纳入候选合成；这只是必要条件，不保证瞬态、推力、横向耦合或缺测切换安全。更不能简单增大 k_p 后宣称通过。

接下来应先完成以下数学任务：

1. 将恒定扰动平均条件作为合成前的排除条件，联合考虑推力限幅和估计噪声放大，避免继续验证已被否定的固定增益。
2. 在保持原风、测量和缺测合同的前提下，比较改变反馈结构与保留气动相关约束两条路线。若引入扰动估计/积分内部状态，应重新推导增广系统及抗饱和条件。
3. 对通过必要条件的新候选，再求模式多面体与非负乘子，验证初始包含和全部后继。不能由一次必要条件通过推断证书必存在。

本轮没有擅自修改 06 增益或原配置，没有把较小风界当作修复。P2/P5 仍未通过，学习独立优势仍单独开放。
