# 竖直硬约束核查：精确输入反例与受限输入证明接口

日期：2026-09-13。承接 [08 增益筛选](08_gain_screen_and_switched_observer.md)。

**08 新候选通过必要条件并且有界，但仍不能通过原推力约束。** 本节在成功测量周期固定为 5 步时，保留原始不确定量相关性，计算有限可达集的准确支持值：第 30 步输入偏移上界为约 5.347934 N，超过允许的 4.905 N。提供达到该界的有理数扰动/噪声序列，否定这组未限幅候选对独立外包模型的鲁棒安全性。

同时证明一个可以保留的正向结果：若观测器预测使用实际执行输入，输入限幅不改变 08 的观测误差递推。因此应转向显式受限输入模型，而不是继续把 Schur 性或均值条件当作硬约束证明。

## 1 精确有限可达集合

使用竖直联合状态 $`z=(p,v,\hat p,\hat v)`$，位置已减去平衡高度 2。控制偏移为 $`t=c_t^\top z`$，$`c_t=(0,0,-5,-3)`$。沿用 08 的全部界、增益和每 5 步成功测量，零时刻也成功。

原初始联合集合精确写成：

```math
z_0=G_0\xi_0,\quad |\xi_0|\leq1,\qquad
G_0=\begin{bmatrix}
0.02&0&0\\0&0.1&0\\0.02&0&0.02\\0&0&0
\end{bmatrix}.
```

同一初始位置同时进入真实和估计位置；不能将这两项独立化。每步增加竖直加速度盒，成功包另增加一个同时作用于估计位置和速度的噪声生成元：

```math
g_w=(0,hD,0,0)^\top,\qquad
g_n=(0,0,\varepsilon,\ell\varepsilon)^\top.
```

根据已知成功/缺测映射构造 $`A_\gamma`$，则：

```math
G_{k+1}=[A_\gamma G_k,\ g_w,\ \gamma g_n],\qquad
\mathcal R_k=\{G_k\xi:|\xi|\leq1\}.
```

γ=0 时省略噪声列。这里保留所有生成元，不作盒化或降阶。对独立外包扰动世界及固定模式序列，这个可达表示是精确的；不是原解析气动世界的精确可达集。

对任一方向 c，线性目标关于各原始参数分别最大化，故：

```math
h_{\mathcal R_k}(c)=\sum_j|c^\top g_{k,j}|.
```

取 $`\xi_j=\operatorname{sign}(c^\top g_{k,j})`$ 即达到最大值（零系数任取端点）。这既给上界，也给对应允许世界，不依赖随机试验、局部优化或浮点舍入。一个相同参数同时影响多个状态的相关性由同一生成元保留。

## 2 第 30 步推力反例

检查方向 p、v、t 及其负方向。集合关于原点对称，因此每个坐标的正支持值也等于绝对值最大值。精确核对结果为：

| 第 30 步量 | 最大绝对值（显示小数） | 原限制 |
|---|---:|---:|
| 高度偏移 p | 0.557900 | 1.5 m |
| 速度 v | 1.352017 | 3 m/s |
| 输入偏移 t | 5.347934 | 4.905 N |

在此固定观测序列上，第 0..29 步这三个量的全可达集均满足相应限制，第 30 步首次出现支持超界。**未声称这是所有允许缺测序列中的全局最早失败时刻。** 每 5 步成功已是一个允许序列，足以反驳对全部序列的保证。

选择输入方向的端点参数得到实际抽象见证，计算 $`T_{30}=9.81+t_{30}\approx15.157934>14.715`$。该输入尚未执行就已不合法；反例无需用越限输入传播第 31 步。第 30 步前的原状态与输入约束均成立，避免在源域外使用气动外包的循环论证。水平和角状态、角噪声可以全取零，从而嵌入当前抽象六维候选。

[checks.json](../../results/theory_vertical_constraints_20260913/checks.json) 保存每步精确支持值、39 个归一化原始参数的达到见证及有理数输入。输出中的小数只为阅读，接受/拒绝全部由 Fraction 完成。

因此，任何包含原初始集合、覆盖该未限幅候选全部外包后继并要求输入合法的终端证书都不存在。改变多面体面数不能消除这个反例。它仍不证明同一扰动序列可由真实气动风场实现。

## 3 将推力限制写入候选，而不是事后忽略

定义明确的受限输入候选：

```math
t_{\rm des}=-5\hat p-3\hat v,\qquad
t=\operatorname{clip}(t_{\rm des},-a,a),\quad a=4.905,
\qquad T=g+t.
```

这使 T 对任意 z 满足原输入区间。但高度和速度安全没有由限幅自动得到。实际输入必须同时进入真实状态与观测器预测：

```math
v^+=v+h(t+w),\qquad \hat v^-=\hat v+ht.
```

直接相减仍有：

```math
e_v^-=e_v+hw,\qquad e_p^-=e_p+he_v.
```

成功校正仍为 $`e_p^+=-n^+`$、$`e_v^+=e_v^--\ell e_p^--\ell n^+`$。所以 08 的包间误差界、启动期及任意缺测切换归纳全部保留；它们原本不依赖 t 的具体反馈表达。

若观测器仍使用未限幅 t_des，则会多出 $`h(t-t_{\rm des})`$，不能沿用旧界。另一方面，08 的固定 Schur 状态矩阵在限幅后不再成立，不能保留其无约束状态有界性结论作为限幅系统证明。

## 4 三个带条件的仿射分支

将候选源集合 P 按实际控制律分为：

```math
P_- =P\cap\{c_t^\top z\leq-a\},\quad
P_0=P\cap\{-a\leq c_t^\top z\leq a\},\quad
P_+=P\cap\{c_t^\top z\geq a\}.
```

分别代入 t=−a、t=c_tᵀz、t=a，就得到三种仿射状态/观测更新，每种再区分下一位置包成功与缺测。边界处两个输入相同，不产生歧义。已知 χ 决定实际分支，不能由未知真实状态替控制器挑选更有利分支。

终端包含应在各交集 P_s 上逐分支证明。若将三个仿射映射无条件施加到整个 P，仍可能形成安全外包，但会引入控制器根本不会选择的输入，造成额外保守性；不能把其求解失败等同于实际受限候选不可能。

## 5 面约束给出共同一步输入区间

对当前可靠联合集合的真实状态投影 B，固定下一目标多面体：

```math
Q=\{(p,v):\alpha_i p+\beta_i v\leq b_i,\ i=1,\ldots,m\}.
```

同一已知信息下必须选择同一个 t。对 $`(p,v)\in B,|w|\leq D`$，目标面恒等展开后，准确的鲁棒一步条件为：

```math
h\beta_i t\leq b_i-
 h_B(\alpha_i,h\alpha_i+\beta_i)-h|\beta_i|D.
```

证明是对 B 与独立扰动盒取支持函数，输入为共同标量而非各状态单独选择。β_i>0 给输入上界，β_i<0 给下界，β_i=0 则是当前集合必须直接满足的无输入条件。与 [−a,a] 求交得到闭区间 U_Q(B)，或空集。若使用经验证的支持上界替代准确支持值，条件变为充分而非必要。

U_Q(B) 非空时，可投影 t_des 到该区间，得到符合该一步证书的共同动作；空集时不能声称随意限幅仍能到达 Q。仅取 Q=D 的高度/速度盒只保证一步，不能提供无限时域闭合；目标族仍须证明递归可行和初始入口。

这给出下一步的两个明确对象：受限候选的带分支不变族，或具有非空共同动作区间的受控不变信息族。二者都保留实际输入驱动的误差证明。先解决竖直联合集合，再处理倾角、推力与水平约束耦合，不再以增益筛选通过代替安全验收。
