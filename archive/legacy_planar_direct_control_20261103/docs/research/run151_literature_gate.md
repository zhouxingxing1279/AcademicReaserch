Houska 的一般 information-ensemble 方法是最强直接基线。本文 §6.5 已允许不同极端信息集合具有不同形状和各自输入，故“按 return 历史分形状”本身**无算法创新准入**。本项目也尚未证明有限 return-age 是信息状态的充分统计量：相同 mode 与 age 可能对应不同历史测量交集、不同可见 `d` 及相关纤维。固定 `W` 的分离定理不能直接搬到 `W(T)`。

本轮判定：**不通过有限周期 fixed-point 求解器准入**；先做语义合同审计。若能证明一个有限索引保守覆盖映射，且在每条 packet 边保持历史一致性、因果共享输入、状态/输入硬约束及非空初始化，才进入实现。若同索引历史的所有后继不存在满足硬约束的共同外包及共享控制，才构成该索引候选类的反证；单纯后继形状不同还不足以反证。仅增加模板或法向而没有终端可行性收益，不继续该支线。
