# 109. 成功测量不能重置物理速度

## 1. 被检验的闭合命题

Run173只证明从配置初始集出发的首个15步窗口满足局部气动门槛。若要在每次位置测量成功后
直接复用该证明，必须保证真实状态重新进入同一绝对初始盒，特别是`|v_z|<=0.1`。SMF更新只
对预测集与观测逆像求交；它不会改变真实plant状态。

## 2. 五步精确物理轨迹

取初态`x_0=(0,2,0,0,0,0)`，连续五步使用`T=14.715`、`tau=0`，并在每步令
`w_x=0,w_z=v_z`。于是相对风速恒为零，解析气动项严格为零，且

\[
a_z=T-g=4.905=\frac{981}{200}.
\]

以`h=0.02`作配置中的Euler更新，五步后

\[
v_{z,5}=5h a_z=\frac{981}{2000}=0.4905,
\qquad
p_{z,5}=2+h^2a_z\sum_{j=0}^{4}j
=\frac{100981}{50000}=2.01962.
\]

所有中间风速均位于`[-0.5,0.5]`，输入和状态也满足配置硬域。模式4的成功边可取零位置噪声，
因此观测与该真值精确一致，可靠posterior必须包含它；但测量不改变`v_{z,5}`。

## 3. 结论与范围

成功测量后的真实速度超过初始半宽

\[
\frac{981}{2000}-\frac1{10}=\frac{781}{2000}=0.3905.
\]

故“仅由成功测量即可推出重新进入同一绝对首窗口合同”被精确反例否定。但该轨迹使用控制器
主动选择的最大推力；控制输入不是对手扰动。因此反例**没有**检验是否存在一个因果控制策略，
能对所有允许扰动把返回状态送入初始盒，也不能据此断言受控reset不可能。下一对象应先写成
`exists causal policy, forall disturbances/dropout paths`的5/10/15步return-set综合问题。

这仍不是递归可行性证明，也未覆盖完整六自由度四旋翼。
