# 19 候选保护外包的性能损失界与支持查询停止证书

18章证明了多维实现的可行性与名义下降，但三个模式的闭环代价一致，没有展示集合精度的控制价值。本章补充一个更直接的结论：**对同一时刻、同一后验与同一名义目标，方向支持误差可以转换为最优代价损失界；另有不依赖已知原最优解的可计算证书。**

数值部分使用部分观测、状态约束活跃的两状态一阶段鲁棒 QP，全部几何及优化结果为精确有理数。它是性能界的严格见证，不是新的闭环或四旋翼实验。凸插值与对偶理论本身属于标准工具，尚不宣称新定理的首次性。

## 1. 固定比较合同

固定当前后验集合 $\mathcal P$、名义初值、预测长度、终端条件和凸名义目标 $J(v)$；$v$ 表示消去名义状态等式后的整个控制序列。鲁棒 QP 可写为

\[
J_{\mathcal P}^*=\min_v J(v),\qquad a_j^Tv+s_j\le b_j.
\]

其中 $s_j$ 是后验集合沿相应回拉方向的支持值；未来噪声支持可以统一并入 $s_j$，也可预先从 $b_j$ 扣除，但比较中必须保持相同。固定输入约束等不依赖集合的行在两问题间不变。

外包或认证支持计算使控制器实际采用 $\widehat s_j\ge s_j$，相应最优值记为 $J_{\widehat s}^*$。这里 $\widehat s$ 是**实际用于控制约束的可靠上界**，不要求它恰好等于外包几何的精确支持；否则会漏算支持数值误差。

给定原问题的认证可行候选 $\bar v$，17章的候选上界保证

\[
s_j\le\widehat s_j\le b_j-a_j^T\bar v.
\]

令

\[
\delta_j=\widehat s_j-s_j,\qquad
m_j=b_j-a_j^T\bar v-s_j.
\]

因此 $0\le\delta_j\le m_j$。当候选恰在某个约束边界，即 $m_j=0$ 时，必须有 $\delta_j=0$；候选证书能精确保护这个方向，即使新支持查询未完成。

所有比较限于这个固定 $\mathcal P$。若之前已经压缩过历史信息，$\mathcal P$ 是当前先验条件化后的后验，不能把它自动称为“不压缩全部历史信息的后验”。不同控制器长时间运行后得到不同集合时，本章单时刻结论不能直接比较它们的闭环累计代价。

## 2. 候选余量给出的理论代价界

设原最优解 $v^*$ 存在，定义

\[
\theta=\max_{j:m_j>0}\frac{\delta_j}{m_j}\in[0,1],
\]

空最大值取0；零余量行必须满足零膨胀。该比例对约束行的正数缩放不变，避免通过改方向归一化人为改变指标。

构造 $v_\theta=(1-\theta)v^*+\theta\bar v$。逐行有

\[
\begin{aligned}
a_j^Tv_\theta+\widehat s_j
&\le (1-\theta)(b_j-s_j)+\theta(b_j-s_j-m_j)+s_j+\delta_j\\
&=b_j-\theta m_j+\delta_j\le b_j.
\end{aligned}
\]

不变的凸约束也在插值下保持。外包问题可行域包含于原可行域，目标凸，因此

\[
0\le J_{\widehat s}^*-J_{\mathcal P}^*
\le\theta\big[J(\bar v)-J_{\mathcal P}^*\big].
\tag{1}
\]

若 $J(v)=\tfrac12v^THv+f^Tv+c$，$H\succeq0$，则二次恒等式进一步给出

\[
J_{\widehat s}^*-J_{\mathcal P}^*
\le\theta\big[J(\bar v)-J_{\mathcal P}^*\big]
-\frac{\theta(1-\theta)}2(\bar v-v^*)^TH(\bar v-v^*).
\tag{2}
\]

这些界明确揭示了安全与性能的区别：只保住候选最多保证不差于该候选，不能保证接近原最优值；支持误差相对候选余量越小，式(1)越有信息。若候选本来就是原最优解，则仅保护它就足以保持最优值，无须保留整个原可行域。

式(1)–(2)涉及原最优值、原最优解或真实支持差，主要用于理论解释及离线审计，不能冒充无需参考解的在线停止规则。没有认证余量时，也不能用数值估计的 $m_j$ 替代它们。

## 3. 不知道原最优解时，如何认证损失

若已有后验支持下界 $\ell_j\le s_j$，例如来自经过成员资格验证的后验点，则问题

\[
\min_v J(v),\qquad a_j^Tv+\ell_j\le b_j
\]

放宽了原问题。设 $g_\ell(\lambda)$ 为其拉格朗日对偶函数，任意 $\lambda\ge0$ 都满足

\[
g_\ell(\lambda)\le J_{\mathcal P}^*.
\]

对任何通过压缩约束安全验收的 $v_c$，不要求它最优，有

\[
0\le J(v_c)-J_{\mathcal P}^*
\le J(v_c)-g_\ell(\lambda)=:\Delta_{\rm cert}.
\tag{3}
\]

因此数值 QP 没求到最优、支持上下界尚有间隙时，也能发布有效的性能上界。弱对偶足以证明式(3)，不要求严格内点或强对偶。若目标 Hessian 正定，消去等式后可显式计算对偶值；有理数线性求解或有向舍入仍需保证其下界方向，不能直接信任浮点目标值。

令 $g_{\widehat s}$ 是实际收紧问题的对偶函数，则

\[
\Delta_{\rm cert}
=\underbrace{J(v_c)-g_{\widehat s}(\lambda)}_{\text{优化未收敛及对偶松弛}}
+\underbrace{\lambda^T(\widehat s-\ell)}_{\text{集合与支持计算造成的不确定性}}.
\tag{4}
\]

两项都非负。它能区分继续优化控制序列还是继续改善集合支持可能更有价值，但用 $\lambda_j$ 排序查询只是一种启发式，本章没有证明贪心查询全局最优。

对本章目标 $J(u)=(u-r)^TR(u-r)$，$R\succ0$，约束矩阵记为 $D$，放宽右端为 $h=b-\ell$，实际代码核对

\[
g_\ell(\lambda)=\lambda^T(Dr-h)
-\tfrac14\lambda^TDR^{-1}D^T\lambda.
\]

代码实现正对角 $R$ 的精确版本，并验证任意非最优非负乘子仍提供下界；负乘子被拒绝。

### 容易写反的对偶界

若原问题强对偶成立且有最优乘子 $\lambda_{\mathcal P}^*$，则

\[
J_{\widehat s}^*-J_{\mathcal P}^*\ge(\lambda_{\mathcal P}^*)^T\delta.
\]

它是**下界**。在收紧问题强对偶成立且存在最优乘子 $\lambda_{\widehat s}^*$ 时，才有另一方向

\[
J_{\widehat s}^*-J_{\mathcal P}^*\le(\lambda_{\widehat s}^*)^T\delta.
\]

在线通常不知道精确 $\delta$，式(3)–(4)更合适。原乘子乘误差可以作为敏感度线索，不能用它保证性能损失不超过某阈值。这是标准对偶扰动分析的直接应用，参见 [Boyd–Vandenberghe 对偶与敏感度讲义](https://web.stanford.edu/class/ee364a/lectures/duality.pdf)。

## 4. 部分观测、活跃约束的精确见证

当前估计中心与名义状态均为0，先验误差 $e\in[-.1,.1]^2$。只测量一个线性组合：

\[
y=e_1+e_2+\nu=0,\quad |\nu|\le.02.
\]

后验为 $\mathcal P=\{e\in[-.1,.1]^2:|e_1+e_2|\le.02\}$。其 CZ 表示有3个生成元、1条等式：

\[
e=\begin{bmatrix}.1&0&0\\0&.1&0\end{bmatrix}\xi,
\quad .1\xi_1+.1\xi_2+.02\xi_3=0,\quad\|\xi\|_\infty\le1.
\]

下一步模型使用18章的耦合矩阵

\[
x^+=\begin{bmatrix}.8&.2\\-.2&.8\end{bmatrix}e+u+w,
\quad\|w\|_\infty\le.01,
\quad\|x^+\|_\infty\le.2,\quad\|u\|_\infty\le.4.
\]

目标为 $J(u)=\|u-(.18,0)\|_2^2$。这里 $N=1$，没有借用18章的终端集或声称部分观测闭环稳定；目的是让集合几何直接影响活跃状态约束。

第一状态方向 $p=(.8,.2)$ 满足

\[
\sigma_{\mathcal P}(p)=.064,\qquad\sigma_{\rm box}(p)=.1.
\]

前者由成员点 $(.1,-.08)$ 给出下界，CZ 对偶乘子 $\lambda=.2$ 给出相等上界：

\[
|.08-.1\lambda|+|.02-.1\lambda|+.02|\lambda|=.064.
\]

故精确后验允许 $u_1\le.2-.01-.064=.126$，普通盒仅允许 $.09$。选择已认证候选 $\bar u=(.12,0)$，原余量 $.006$，候选保护上界是 $.2-.01-.12=.07$。查询若提供 $\sigma_{\mathcal P}(p)+.003=.067$，取小后获得更精确方向。

| 当前表示／上界 | 最优 $u_1$ | 最优名义代价 | 相对精确后验损失 | 保留候选 $.12$ |
|---|---:|---:|---:|---|
| 精确后验 | .126 | .002916 | 0 | 是 |
| 普通盒外包 | .09 | .0081 | .005184 | 否 |
| 候选保护，无新查询 | .12 | .0036 | .000684 | 是 |
| 候选保护，查询误差 .003 | .123 | .003249 | .000333 | 是 |

最后一行有 $\theta=.003/.006=.5$。式(1)给出 $.000342$，式(2)给出 $.000333$，与实际损失完全相等。旧最优乘子 $.108$ 乘误差得到 $.000324$，严格低估真实损失；新乘子 $.114$ 给出上界 $.000342$。使用后验成员点和新乘子的在线形式证书同样得到 $.000342$，其计算不需要原最优解。

这是**同一份传感器信息的几何表示对照**：盒外包也收到测量，只是在表示中丢弃相关性。整个原后验的所有顶点均满足新外包半空间，因此通过凸性验证整个集合包含，不只是检查单条真值。

这个小型后验本身已有紧凑 CZ；把盒加4条保护半空间转成 CZ 会得到6个生成元、4条等式，比原来的3/1更大。这里没有计算或存储优势声明。18章的固定历史规模结果与本章的控制价值见证是不同实验，不能拼接成同一实例上的全面优越性。

## 5. 可行性与性能双证书的停止规则

在**一次控制更新内固定后验**，可采用以下确定性规则：

1. 先由旧可行计划构造候选保护上界，保存认证候选及其名义目标值。
2. 新支持查询提供上界和可验证成员点下界；按方向取最小有效上界、最大有效下界。
3. 数值优化器提出控制方案；仅在安全验收通过且不增大回退目标时采用。
4. 用任意非负对偶乘子更新原问题的可靠目标下界，保留迄今最大的下界。
5. 若 $J(v_c)-\underline J\le\varepsilon_J$，则可认证地结束精度计算；若预算先耗尽，执行安全候选，并明确精度目标尚未认证。

同一后验下，上界只改善、目标只降低、目标下界只提高时，记录的性能差距不会变大。跨测量时刻后验改变后，旧成员点与目标下界必须重新认证，不能直接沿用。

若与18章的候选移位、终端条件及成本接受规则结合，名义下降证明保持有效；式(3)另外约束当次名义次优性。预算耗尽不会自动满足指定性能阈值，也没有从这些单步界推出整个扰动闭环的累计性能差界。

代码包含合成查询顺序“缺失 → 误差 .01 → .003 → .001 → 0”。当 $\varepsilon_J=.0004$ 时，前两种状态的证书为 $.00072$，到第二轮新查询后降至 $.000342$，于是可停止；若新查询预算为0，则保留 $.12$ 候选，但报告性能阈值未认证。该测试按查询轮数模拟预算，不是实际计算中断或毫秒截止时间测试，也没有把离线审计所用精确后验计算计作免费的在线工作。

## 6. 扫参与证据边界

使用6种测量条带宽度、6种候选余量、6种支持误差／缺失模式，共216个精确算例。所有算例核查后验 CZ 的原始—对偶支持相等、整个后验包含、候选保留、插值可行性、两种理论界及对偶性能证书。

结果为：全部216例通过；其中144例普通盒丢失指定候选，125例保护外包相对原问题仍有严格代价损失，这125例的旧乘子线性项全部低估损失。144是完整参数网格的计数，同一测量宽度与候选余量在6个查询模式下重复，不是144条独立轨迹，更不是144次物理事故。

以上证明降低某些方向的保守性确实能够改善约束活跃时的名义优化结果，也证明“保可行”不等于“无性能损失”。没有估计随机成功概率，没有模拟新的闭环，尚未测试四旋翼部分观测、持续轨迹跟踪或有限算力硬截止时间。

## 7. 与文献的关系和研究判断

凸插值、弱对偶、目标差停止准则与乘子敏感度均为成熟工具，不能把式(1)或式(3)单独包装为首创。当前候选贡献收敛为：**把旧控制候选提供的方向上界、CZ 支持的原始／对偶证书与 MPC 目标下界连接起来，使集合外包同时具备可行性保障及当次性能损失证书。** 首次性仍需近邻全文排重。

本轮补充两个应纳入强对照的近邻：

- Robbins 等，2026 ACC，[Online Constraint Tightening for MPC using Constrained Zonotope Reachability Analysis and Zonotope Over-Approximations](https://pure.psu.edu/en/publications/online-constraint-tightening-for-mpc-using-constrained-zonotope-r/)：机构页面明确研究在线 CZ 可达集收紧及无需优化的 zonotope 外包。当前核查到机构摘要，尚未完成算法全文复现；其免优化方案可能比本系列 LP 外包更适合实时控制。
- Leung、Vinod，2026 ACC，[A set-based approach for stable MPC with Minkowski cost functions](https://www.merl.com/publications/TR2026-062)：机构摘要包含 CZ 精确策略与多面体近似次优策略。目标和集合角色与本章不同，但“集合近似—性能”的关系已有研究，不能声称无人讨论。

下一步应把式(3)的可靠对偶目标下界接入18章的多步求解器，在约束持续活跃的任务中统计“给定误差阈值需要多少实际查询和时间”。先保留固定模型和原终端合同，分别测量优化误差、几何误差与查询误差；通过后再迁移到四旋翼外环。新增学习算法仍暂停。
