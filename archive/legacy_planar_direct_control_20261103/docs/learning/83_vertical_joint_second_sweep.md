# 83. 竖直 joint information 完整纤维类的第二下降层

日期：2026-10-03。本章以 Run 145 的 `C_j^1` 为 target 做第二次 exact predecessor。
结果严格淘汰 `complete eta fiber` 候选类，但不否定保留 `eta|d` 相关性的 joint
information set。

## 1. target 与动力学

Run 145 给出

```math
C_j^1=\{(\eta,e):\eta\in E_j,\ d=e-\eta\in D_j^0\}.
```

本轮仍固定可执行策略 `delta T=0`，并要求每个当前 `d` 兼容完整 `E_j`。miss 边为

```math
d^+=A_d d,\qquad A_d=\begin{bmatrix}1&h\\0&1\end{bmatrix}.
```

success 边为

```math
d^+=A_d d+\begin{bmatrix}1\\L\end{bmatrix}(q+n),\qquad
q=\eta_p+h\eta_v,\quad L=9/2.
```

同一 physical residual 在 `eta^+` 与 `e^+` 中抵消，因此不进入 `d^+`；测量创新
`q+n` 必须保持为一个共享原语。对 target facet `a d_p^+ + b d_v^+ <= c`，success
反拉回的 exact 不等式为

```math
a d_p+(ah+b)d_v
\le c-|a+Lb|\left(h_{E_j}(1,h)+\bar n\right).
```

每个 mode 把全部 outgoing-edge 反拉回 facets 与 source `D_j^0` 相交。mode 4/9 的两条
未知后继边在相交前固定同一个 `delta T=0`。

## 3. mode 14 的精确宽度证书

mode 14 完整纤维给出

```math
h_{E_{14}}(1,h)=\frac{23312147}{48000000},\qquad
\bar n=\frac1{50}.
```

因此 success 创新的半宽为

```math
\sigma=\frac{24272147}{48000000},
```

并在 `d_v^+` 上产生不可消除的半宽

```math
L\sigma=\frac{72816441}{32000000}\approx2.275514.
```

但 target `D_0^0` 的速度半宽只有

```math
\bar d_{v,0}=\frac{94125081847}{57600000000}\approx1.634116.
```

严格超量为

```math
L\sigma-\bar d_{v,0}
=\frac{36944511953}{57600000000}\approx0.641398>0.
```

任意只依赖可见 `d` 的当前 correction 都只能把 successor 速度区间整体平移
`h delta T`，不能缩小其半宽。因此同一完整 mode-14 fiber 不可能被放入 `D_0^0`；这比
“零输入数值求交为空”更强，但仍只针对完整纤维 target。

## 4. 证据等级与方向纠正

证据等级为 **exact mode-14 width obstruction for the complete-fiber second sweep**。
它证明当前 `E_j x D_j` 模板不能形成非空15模态 fixed point，也说明单纯改成依赖 `d`
的仿射/分段 correction 仍无法解决 mode-14 的完整纤维宽度问题。

它没有否定 joint information RCI：真实可行信息集可以让给定 `d` 只对应 `E_j` 的一个
条件子集，从而缩小 `q|d` 半宽。下一步必须显式保留 `eta` 与 `d` 的相关性，先构造
mode-14 条件纤维 target，并以本轮宽度证书作为必须跨越的基线；不再继续完整纤维的多层
迭代。
