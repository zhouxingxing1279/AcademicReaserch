# 任意反馈下的控制权限障碍与保留输入结构的外包

日期：2026-09-18。承接 [11 测量年龄方向运输](11_measurement_age_transport.md)。

**本轮结论：第11节的25步公共开环反例还不是最终瓶颈。当前独立全域仿射盒甚至无法从初始中心实现无限期鲁棒安全，完美状态反馈也无济于事。必须先保留推力—姿态关系，再做联合输出反馈 tube 和终端合成。** 本节给出任意策略的否证、替代模型的一步集合包含证明、已知变输入的固定复杂度传播实现及复现记录。

## 1. 合同与量词

状态仍为 `(px,pz−2,vx,vz,phi,omega)`，初始中心全零对应物理高度2米。固定参数 h=1/50，J=1/50，g=9.81；约束 |px|≤5、|phi|≤0.45、|omega|≤2、|tau|≤0.08。注意角速度递推为 omega⁺=omega+h tau/J，本例 h/J=1，不能误用 omega⁺=omega+h tau。

旧全域外包允许

```math
p_x^+=p_x+hv_x,\qquad v_x^+=v_x+h(-g\phi+w_x),
```
```math
\phi^+=\phi+h\omega,\qquad \omega^+=\omega+h\tau/J,
```

其中 wx 独立地遍历 [−Dx,Dx]，Dx=4.3107340625。该外包覆盖源模型仅在原域内有依据。下述证明是一项必要条件检查：假设某策略可以始终安全，推出矛盾。无需在失域之后把抽象轨迹当作物理轨迹。

允许策略使用完美全状态、无限记忆，甚至预知未来扰动。证明只使用其物理输入和状态约束，因此比输出反馈情形更宽松。

## 2. 不依赖任何增益的不可行定理

从零角度、零角速度出发，tau/J≤4，所以任意仍满足约束的策略均有

```math
\omega_k\le4hk,\quad
\phi_k\le a_k:=\min\{0.45,\,2h^2k(k-1)\}.
```

a_k 是逐时乐观上界，不要求存在同时达到整条 a_k 序列的策略。它忽略角速度上限以及靠近倾角边界时必须刹停的限制，因此只会高估可用控制能力。

固定选择合法抽象扰动 wx,k≡+Dx。定义有理数下界序列

```math
V_0=P_0=0,\quad
V_{k+1}=V_k+h(D_x-ga_k),\quad P_{k+1}=P_k+hV_k.
```

由 −g phi_k≥−g a_k，归纳得到 vx,k≥V_k、px,k≥P_k。精确算得

```math
P_{208}=4.992725439,\qquad
P_{209}=\frac{5013796793}{10^9}=5.013796793>5.
```

故**固定的恒定扰动已经击败所有保持其他约束的控制策略，最迟第209步（4.18秒）必须失域**。若其他约束更早失效，也已经违反安全目标。

这并非“某组反馈增益不佳”“求解器没有找到终端集”或“传感器不够精确”。在该抽象合同下，不存在覆盖原初始集合并永远保持原域的鲁棒安全控制器；也不存在包含初始中心投影、能满足该要求的鲁棒受控不变证书。它不排除不包含中心的其他集合，也不否定真实非线性系统的可控性。

### 定量必要条件

把水平独立扰动半径换为 D，保持其他条件不变，有

```math
P_N(D)=\frac{h^2N(N-1)}2D
-gh^2\sum_{k=0}^{N-2}(N-1-k)a_k.
```

任何无限期安全策略必须对每个 N 满足 P_N(D)≤5。取一个明确的有限检查点 N=356，得到

```math
D\le\frac{2657458367}{631900000}\approx4.20550461624.
```

旧值4.3107340625不满足。该阈值只是一个必要条件，不是安全可控半径，也不宣称是所有N中的解析最优值。低于它不能据此通过终端验收。

## 3. 根因：外包把已知输入作用当成独立扰动

原水平动力学为 vx⁺=vx+h[−T sin(phi)+aero_x]，m=1。旧分解

```math
-T\sin\phi=-g\phi-(T-g)\phi+T(\phi-\sin\phi)
```

把后两项独立盒化，使用

```math
D_x^{old}=1.880+4.905(0.45)+14.715(0.45)^3/6.
```

在这一抽象模型里，增大推力不能直接增加水平反向加速度；其有利和不利作用都已被对抗性独立盒吸收。倾角达到0.45后，旧模型的最大净制动能力仅为 g·0.45−Dx=0.1037659375 m/s²，无法及时消除倾转前积累的速度。

这揭示的是抽象保守性。恒定+Dx并未证明能由真实气动、同一个T和phi共同实现，不能把不可行定理移植给非线性真值系统。

## 4. 保留已知推力后的外包，理论上为何更紧

对实际已知输入T，精确保留 −T phi：

```math
v_x^+=v_x+h[-T\phi+r_x],\quad
r_x=aero_x+T(\phi-\sin\phi),
```
```math
|r_x|\le d_x(T):=1.880+T\Phi^3/6,\quad\Phi=0.45.
```

竖直方向仍为 vz⁺=vz+h[T−g+r_z]，取 |rz|≤dz(T)=2.086+T Phi²/2。这里沿用原全域气动界，未缩小物理约束，也未假设一个尚未证明闭合的小域。

Taylor积分余项给出 |phi−sin(phi)|≤|phi|³/6、|cos(phi)−1|≤phi²/2；T正且已知，所以整个源域内均成立。

最大水平余项从 **4.3107340625降为2.1034840625**，恰好移除2.20725这一独立预算。更关键的是，对每个原域状态x和每个合法T，

```math
\mathcal F_{new}(x,T)\subseteq\mathcal F_{old}(x,T).
```

**证明：** 将新模型后继写回旧中心 −g phi，所需旧水平余项为 r_x−(T−g)phi，满足

```math
|r_x-(T-g)\phi|
\le1.880+T\Phi^3/6+|T-g|\Phi\le D_x^{old}.
```

竖直半径 dz(T)也不大于旧全域值，其余状态方程一致。于是任意原域源集合的一步后继并集也包含于旧外包。T=g、phi=0时水平新旧区间已经严格不同，故并非仅仅更换表示。

该定理比较的是精确的一步集合值外包；它不自动保证经过不同模板压缩后的数值支持逐项更小，也不保证 MPC 可行。源集合失域后不能继续调用该物理包含定理。

## 5. 已知输入下，72方向运输仍然成立

对 s_j=px−jh vx，有

```math
s_j^+=s_{j-1}+jh^2T\phi-jh^2r_x.
```

竖直方向为 s_j⁺=s_(j−1)−jh²(T−g)−jh²rz。正推力保证运输系数非负，故存在 M(T)≥0 满足 HF(T)=M(T)H。已知输入贡献的常数项记为o(T)，传播为

```math
\mathcal T_T(b)=C\big(\lceil M(T)b+H o(T)+\sigma_{W(T)}(H)\rceil_\delta\big).
```

H仍为第11节的72方向，C仍为60个速度闭包推论。映射对b单调。因此，**新旧链采用相同的移位输入路径**时，测量更新后的逐项收缩仍推出整个移位包含链。路径随时间变化不影响该归纳；擅自改变未来路径则没有这一保证。

实现 `InputTransport` 保留精确T、F(T)、有符号常数偏移和噪声支持；当前验证内核取tau=0。一般已知tau可作为角速度仿射偏移接入，但本轮没有据此测试任意力矩路径。在线支持LP为零，CZ重建规模仍为66生成元、60等式；没有WCET认证。

### 全允许间隔的后验宽度

每步测量姿态后，将 −T phi 写成已知的 −T yphi 与剩余项，统一水平半径为

```math
A_x^*=1.880+14.715\Phi^3/6+14.715(0.005)=2.1770590625.
```

已知竖直输入只平移区间，其统一半径仍为Az*=3.57589375。第11节运输证明对任意已知输入序列成立，只需把每步加速度半径以Ax*、Az*上界，并沿用精确测量端点与65δ/100δ取整预算。

## 6. 为什么不能直接宣布联合反馈tube完成

若T由未来估计反馈产生，它依赖尚未到达的观测，因而 −T phi 是联合变量的乘积。把T冻结为一条数值路径，仅证明该路径的外包；第11节固定F的12维增广线性方程也不能原封不动处理此乘积。

下一步需保留 `(x,hatx,T)` 的关系。在T∈[Tl,Tu]、phi∈[pl,pu]上，可引入q=T phi并使用四个线性外包约束：

```math
q\ge T_l\phi+p_lT-T_lp_l,\qquad
q\ge T_u\phi+p_uT-T_up_u,
```
```math
q\le T_u\phi+p_lT-T_up_l,\qquad
q\le T_l\phi+p_uT-T_lp_u.
```

有效性分别由 `(T−Tl)(phi−pl)≥0`、`(Tu−T)(pu−phi)≥0`、`(Tu−T)(phi−pl)≥0`、`(T−Tl)(pu−phi)≥0` 直接展开得到。边界来自已认证源集合；不得使用未证明的后继小区间。还需同时保留反馈律给出的T与hatx等式、共同状态潜变量和观测分支，不能把这些变量独立成盒后声称关系仍在。

这些是下一步联合外包的明确约束，尚未实现反馈增益搜索、终端不变集或递归可行性证明。若四面外包仍过宽，可在已认证源域分区后取并集，或保留更多多项式相关性；是否值得增加复杂度应由状态/输入收紧余量决定。

## 8. 文献定位

[Mitchell、Budzis、Bolyachevets，Invariant, Viability and Discriminating Kernel Under-Approximation via Zonotope Scaling](https://arxiv.org/abs/1901.01006)研究离散仿射系统在对抗输入下的可生存性，并区分可达外包与可生存核内近似。这支持本轮先核查控制权限再搜索不变证书的研究顺序；本文没有直接移植其算法或声称算出了可生存核。

[Breeden、Panagou，Robust Control Barrier Functions under High Relative Degree and Input Constraints for Satellite Trajectories](https://arxiv.org/abs/2107.04094)将输入约束、扰动界及高相对阶安全约束共同纳入构造。本文的有限时域否证是针对当前离散合同的直接比较证明，不是该论文定理的应用。本轮只用上述论文摘要核对问题定位，不声称完成全文假设审查。
