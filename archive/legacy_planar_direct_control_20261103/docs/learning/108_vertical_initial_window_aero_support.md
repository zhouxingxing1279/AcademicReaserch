# 108. 首个15步窗口的联合气动支持证书

## 1. 目标与范围

Run172排除了一个抽象端点，但没有回答其他可达组合是否仍会使竖直气动核心超过
`D*=1.36449678`。本章从配置初始集出发，依次外包`phi`、`v_x`和`v_z`，对任意允许的
推力、力矩和风历史给出首个15步窗口内的竖直气动支持上界。

## 2. 姿态投影

角动力学为

\[
\phi^+=\phi+h\omega,\qquad \omega^+=\omega+h\tau/J.
\]

由`|phi_0|<=1/200`、`|omega_0|<=1/100`、`h=1/50`、`|tau|/J<=4`，对
`k<=15`有

\[
|\phi_k|\le\frac1{200}+15\frac1{50}\frac1{100}
+\left(\frac1{50}\right)^2 4\frac{15\cdot14}{2}
=\frac{22}{125}=0.176.
\]

TDD首轮曾把角加速度累计项误算为`0.084`；精确测试暴露错误后修正为`0.168`。

## 3. 横向速度投影

先仅在气动非线性内部使用全域`|r_x|,|r_z|<=7/2`和
`sqrt(r_x^2+1/25)<351/100`，同时保留上面的姿态小界。由
`|sin(phi)|<=|phi|`、`|sin(2phi)|<=2|phi|`及`|T/g-1|<=1/2`，得到

\[
|a_x|\le\frac{222281}{50000}=4.44562.
\]

因此从`|v_{x,0}|<=0.1`归纳15步，

\[
|v_x|\le\frac{716843}{500000}=1.433686,
\qquad |r_x|\le\frac{966843}{500000}=1.933686.
\]

## 4. 竖直气动支持

Run172已有`v_z>=-90859/40000`，故负相对竖直速度的最大幅值为

\[
(-r_z)_+\le\frac12+\frac{90859}{40000}
=\frac{110859}{40000}=2.771475.
\]

精确平方验证

\[
\sqrt{(110859/40000)^2+1/25}<139/50.
\]

当`r_z>=0`时阻力项非正；当`r_z<0`时应用上式，并用`cos(phi)<=1`，得到整个首窗口

\[
a_{z,\mathrm{aero}}
\le\frac3{20}\frac{110859}{40000}\frac{139}{50}
+\frac1{50}\left(\frac{966843}{500000}\right)^2
=\frac{15381098824149}{12500000000000}
\approx1.23048791.
\]

它比Run168门槛低约`0.13400887`。因此配置初始集的首个15步窗口确实满足该局部气动核心
门槛；Run169的超限来自跨时刻独立残差外包的不可实现组合。

## 5. 尚未闭合

这不是递归tube。成功测量后的posterior可能具有不同速度中心和宽度；必须证明每个允许观测
fiber在重规划后重新进入上述小窗口合同，或构造覆盖重复5/10/15步返回周期的非线性不变族。
在完成reset闭合与终端条件前，不能宣称递归可行性或课题主线闭合。
