## 1. 本轮消除的证明缺口

03 中的候选任务原先表述为一般方向支持查询。控制主参考

- J. Köhler, M. A. Müller, F. Allgöwer, *Robust output feedback model predictive control using online estimation bounds*, 2021, https://arxiv.org/abs/2105.03427

实际将在线估计信息压缩成标量误差界：

```math
V_o(\hat x_t,x_t)\le e_t .
```

其未来误差界和 tube 尺度由该标量递推。因此，“某些多面体方向更紧”本身不构成控制收益；只有方向验证能可靠降低控制器读取的 (e_t)，才有理论意义。

本轮固定以下接口：**候选方向不再任意生成，而从观测误差度量 (V_o) 的分解直接导出。**

## 3. 从方向支持证书到标量估计界

设控制基础采用二次观测误差度量

```math
V_o(\hat x,x)=(x-\hat x)^\top P_o(x-\hat x),
\qquad P_o=L^\top L .
```

记误差 (z=x-\hat x)，(L) 的第 (r) 行为 (ell_r^\top)。对相容误差集

```math
\mathcal E_t^c=\{x-\hat x_t:x\in X_t^c\},
```

为每一行保存两侧可靠上界

```math
\ell_r^\top z\le b_{r,+},
\qquad
-\ell_r^\top z\le b_{r,-},
\qquad \forall z\in\mathcal E_t^c .
```

定义

```math
\beta_r=\max\{b_{r,+},b_{r,-}\},
\qquad
e_t^{\mathrm{cert}}=\sum_r\beta_r^2 .
```

### 引理 1：控制标量的可靠性

对任意 (z\in\mathcal E_t^c)，

```math
|\ell_r^\top z|\le\beta_r,
```

故

```math
V_o(\hat x_t,x)
=\|Lz\|_2^2
=\sum_r(\ell_r^\top z)^2
\le\sum_r\beta_r^2
=e_t^{\mathrm{cert}} .
```

所以每一个候选任务固定为验证某个 (+\ell_r) 或 (-\ell_r) 的支持上界。验证器只允许执行

```math
b_{r,\pm}^+ =
\min\{b_{r,\pm},\gamma_{r,\pm}^{\mathrm{verified}}\},
```

未完成、超时或无有效证书时保持原值。

### 推论 1：策略无关的非劣性

只要独立验证器可靠，则不论调度策略是 DP、规则、随机策略还是 OOD 后失效的神经策略：

```math
e_{t,\mathrm{after}}^{\mathrm{cert}}
\le
e_{t,\mathrm{before}}^{\mathrm{cert}},
```

且相容真值仍在证书内。

这不是完整闭环安全定理；它说明**学习策略不拥有修改安全边界的权限**。策略失效最多浪费预留给调度的计算预算，不能自行签发更小边界。

## 4. 与 homothetic tube 的控制相关性

主参考中的未来估计界具有形式

```math
e_{k|t}
=
\frac{1-\tilde\eta^k}{1-\tilde\eta}\sigma_4(\bar w)
+
\tilde\eta^k e_t ,
\qquad 0\le\tilde\eta<1.
```

若同一时刻仅把当前可靠界从 (e_t) 降到 (e_t'\le e_t)，则

```math
e_{k|t}'\le e_{k|t},\qquad \forall k.
```

tube 尺度递推形如

```math
s_{k+1|t}
=
\rho s_{k|t}
+
\gamma_{s,o}(e_{k|t})
+
\gamma_{s,w}(\bar w),
```

其中 (gamma_{s,o}) 单调，因此从相同 (s_{0|t}) 出发：

```math
s_{k|t}'\le s_{k|t}.
```

### 命题 1：条件控制非劣性

在主参考全部控制假设、终端条件和未来更新条件都满足的前提下，若两次 MPC 只在可靠当前误差界上满足 (e_t'\le e_t)，则由较小 (e_t') 构造的未来误差/tube 集合逐级嵌套于基线集合。于是：

1. 同一 nominal 决策在基线收紧下可行，则在更小不确定集合下不会因鲁棒约束而失去可行性；
2. 鲁棒可行决策集不会缩小；
3. 若优化目标相同，或其中关于误差/tube 的附加项对 (e,s) 非减，则最优目标值不会因该证书收紧而恶化。

这给出“方向验证 → 标量 (e_t) → tube 收缩 → 控制可行性非劣”的证明链。**不据此宣称实际逐轨迹跟踪误差必然下降。**

## 5. 有限调度环境

一个 episode 仍对应固定物理信息 (I_k) 下的一次计算过程，不跨越自由飞行探索。

### 状态

精确小实例使用完整有限状态：

```math
S=
\bigl(
\{b_{r,+},b_{r,-}\}_r,
m,
B_{\mathrm{rem}},
\{C_j\}_j,
q
\bigr),
```

其中 (m) 为任务完成 mask，(B_{\mathrm{rem}}) 为剩余调度预算，(C_j) 为任务成本，(q) 为验证器离散状态。规模化网络以后可以读取摘要特征，但在证明充分统计量之前不声称摘要状态严格 Markov。

### 动作

```math
a\in\{j:\text{task }j\text{ unfinished and affordable}\}\cup\{\mathrm{STOP}\}.
```

已完成任务和最坏成本超过剩余预算的任务直接 mask。动作从不包含 (T,\tau) 或任何控制输入。

### 转移

执行任务 (j) 后：

1. 独立验证器返回有效支持证书 (gamma_j) 或失败/超时；
2. 成功时只做 (b_j\leftarrow\min(b_j,\gamma_j))；
3. 失败时边界不变；
4. 扣除实测计算成本；
5. 到达硬截止即终止并返回当前已认证边界。

### 奖励

将 03 中一般集合代理替换为控制对齐指标：

```math
r_q
=
e_q^{\mathrm{cert}}-e_{q+1}^{\mathrm{cert}}
-
\lambda C_q .
```

硬预算独立存在，不能只靠成本惩罚。有限 horizon 下奖励望远镜求和：

```math
\sum_q r_q
=
e_0^{\mathrm{cert}}-e_Q^{\mathrm{cert}}
-
\lambda\sum_q C_q .
```

因此策略优化目标与控制器真正读取的估计误差界直接一致。

## 6. 精确可枚举的序列价值见证

取

```math
P_o=I_2,\qquad L=I_2,
```

真实相容误差集为

```math
\mathcal E^c=
[-1/2,1/2]\times[-1,1].
```

当前保存的可靠但保守边界为

```math
b_{1,+}=2,\quad b_{1,-}=2,
\qquad
b_{2,+}=3/2,\quad b_{2,-}=1.
```

故

```math
e_0^{\mathrm{cert}}
=
2^2+(3/2)^2
=
25/4.
```

有三个真实来源的单位成本验证任务：

- (A^+)：认证 (x_1\le1/2)；
- (A^-)：认证 (-x_1\le1/2)；
- (B^+)：认证 (x_2\le1)。

总预算为 2 次查询。

单独执行 (A^+) 或 (A^-) 时，第一行仍有另一侧边界 2，因此

```math
\beta_1=2,
```

即时收益为 0。单独执行 (B^+) 后，

```math
e=2^2+1^2=5,
```

即时收益为

```math
25/4-5=5/4.
```

因此一步即时收益贪心必先选 (B^+)。第二步任取 (A^+) 或 (A^-) 都仍不能降低第一行的 max，最终仍为

```math
e_{\mathrm{greedy}}=5.
```

而两步序列 (A^+,A^-)（或逆序）得到

```math
e_{\mathrm{opt}}
=
(1/2)^2+(3/2)^2
=
5/2,
```

总收紧收益

```math
25/4-5/2=15/4.
```

因此

```math
e_{\mathrm{greedy}}-e_{\mathrm{opt}}=5/2>0.
```

若三类查询成本都为 1，并采用上述成本惩罚，则在

```math
0\le\lambda<5/2
```

时，两次互补 (A) 查询的累计奖励仍严格大于只做 (B^+) 的方案。

这个差距来自**二次误差证书对正负两侧查询的互补性**，不是隐藏信息或人为加入无关任务。它证明了当前任务类中确实存在非空的序列规划价值。

同时，它也明确限制主张：两步精确前瞻/DP 在该小实例上就是最优，故此例**不能**证明 Double DQN 优于有限前瞻，只能证明“纯一步贪心不足、需要序列决策”。

精确枚举见：

```bash
python verification/check_scheduler_interface.py \
  --output /tmp/scheduler_interface.json
```

归档结果见 [exact_checks.json](../../results/theory_scheduler_interface_20260916/exact_checks.json)。

## 7. OOD 与失败策略的安全边界

学习策略只拥有“查询哪一个任务/是否停止”的权限。在线执行必须同时满足：

1. 候选库在控制周期开始时冻结，首版只含 (\pm\ell_r)；
2. verifier 是唯一能产生新支持上界的模块；
3. 新边界只以 `min(old, verified)` 方式接受；
4. 查询超时或求解失败时回退到旧边界；
5. 调度预算与 SMF、MPC 必需预算硬隔离；
6. 神经策略推理时间本身计入调度预算。

因此分布偏移首先影响的是**效率**：策略可能浪费预算、错失可收紧方向；它不应改变证书正确性。完整约束安全仍依赖控制基础最终通过，本节不把“策略无权破坏证书”扩大为“当前六维闭环已经安全”。
